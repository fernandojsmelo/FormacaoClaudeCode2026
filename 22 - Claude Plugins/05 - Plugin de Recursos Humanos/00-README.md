# Projeto de RH — Plugin de Recursos Humanos (Cowork)
**Cenário fictício:** TechNova Soluções, SaaS B2B, ~180 funcionários, São Paulo (modelo híbrido)
**Fio condutor:** estruturação do novo time de Dados & Analytics, da primeira vaga (Analista de Dados Pleno — Marina Alves Costa) até o ciclo de performance de 6 meses.

Este projeto usa as 9 skills do plugin `human-resources` em sequência, sobre o mesmo cenário, para exercitar o plugin de ponta a ponta.

## Documentos

| # | Arquivo | Skill usada | Conteúdo |
|---|---|---|---|
| 1 | `01-org-planning.md` | org-planning | Plano de headcount e estrutura do time de Dados & Analytics para 12 meses |
| 2 | `02-recruiting-pipeline.md` | recruiting-pipeline | Status semanal do funil de recrutamento da vaga de Analista de Dados Pleno |
| 3 | `03-interview-prep.md` | interview-prep | Kit de entrevista: competências, banco de perguntas, scorecard e debrief |
| 4 | `04-comp-analysis.md` | comp-analysis | Benchmarking salarial e análise da proposta para a candidata Marina |
| 5 | `05-draft-offer.md` | draft-offer | Carta oferta completa + orientações de negociação para o gestor |
| 6 | `06-onboarding.md` | onboarding | Checklist pré-início, Dia 1, Semana 1 e metas de 30/60/90 dias |
| 7 | `07-performance-review.md` | performance-review | Templates de autoavaliação, avaliação do gestor e calibração |
| 8 | `08-people-report.md` | people-report | Relatório de headcount e attrition da empresa (fechamento Q3 2026) |
| 9 | `09-policy-lookup.md` | policy-lookup | Explicação de política de trabalho remoto temporário |

## Observações
- Todos os dados (empresa, pessoas, números) são fictícios, criados para fins de treinamento no uso do plugin de RH.
- Os documentos foram desenhados para se conectar entre si: a vaga aberta no `org-planning` é a mesma trabalhada no `recruiting-pipeline`, `interview-prep`, `comp-analysis`, `draft-offer` e `onboarding`; o `people-report` referencia essa mesma contratação; o `performance-review` usa a candidata contratada (Marina) como exemplo de revisão de 6 meses.

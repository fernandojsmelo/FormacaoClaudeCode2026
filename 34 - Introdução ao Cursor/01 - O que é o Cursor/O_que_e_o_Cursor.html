Introdução ao Cursor · Aula 1

O que é o
Cursor

O Cursor é um editor de código com IA que virou uma plataforma de agentes de programação. Nasceu como um fork do VS Code com um autocompletar muito bom e hoje entende o seu projeto, planeja, edita vários arquivos, roda comandos, testa no navegador e trabalha em paralelo, no seu computador ou na nuvem.

Conceito01

Um editor que virou agente

A documentação oficial se apresenta assim: o Cursor é "um agente de programação para construir software ambicioso", que você usa para entender o código, planejar e construir funcionalidades, corrigir bugs, revisar mudanças e trabalhar com as ferramentas que já usa.

Você escreve

Com o Tab, a IA completa e prevê a próxima edição enquanto você digita.

Você pede

Com Ctrl+K, você seleciona um trecho e descreve a mudança em português.

Você delega

Com o Agent, você entrega a tarefa inteira: ele lê, edita, roda e verifica.

Por fora, é um editor conhecido: o Cursor é derivado do VS Code, usa os mesmos atalhos e importa suas extensões e configurações. Por dentro, a IA está em todo lugar, do cursor de texto ao terminal.

Recurso05

Tab: o autocompletar que adivinha o próximo passo

O Tab sugere código enquanto você digita, com base nas suas edições recentes, no código ao redor e nos erros do linter. A sugestão aparece em cinza à frente do cursor.

AçãoAtalho
Aceitar a sugestão inteiraTab
RecusarEsc ou continue digitando
Aceitar palavra por palavraCtrl + → (Mac: Cmd + →)
Pular para a próxima ediçãoTab de novo, depois de aceitar
  • Várias linhas: altera blocos inteiros e adiciona imports que faltam.
  • Jump-in-file: depois de aceitar, prevê onde você vai editar em seguida e leva o cursor até lá.
  • Outros arquivos: quando uma mudança exige ajustes em outro arquivo, aparece uma janelinha (portal) na parte de baixo do editor.
  • Ligar e desligar: no indicador Tab, no canto inferior direito: pausar por um tempo, desligar geral ou só para certos tipos de arquivo.
Nos planos pagos, os completamentos do Tab são ilimitados. É o recurso que mais economiza tempo no dia a dia de quem ainda escreve o código com as próprias mãos.
Recurso06

Ctrl+K: editar sem sair do lugar

A edição inline faz mudanças rápidas e localizadas sem abrir o painel do Agent. Você seleciona o código, descreve o que quer e o Cursor aplica a edição ali mesmo.

1
Selecione o trecho que quer mudar.
2
Pressione Ctrl + K (Mac: Cmd + K).
3
Escreva a instrução, por exemplo: "Converta para uma função async", e pressione Enter.
4
Para refinar, escreva outra instrução e pressione Enter de novo.
Só uma pergunta? Depois do Ctrl+K, troque para o modo pergunta com Alt + Enter (Mac: Opt + Return). Se gostar da resposta, escreva "do it" para aplicar.
Mudança grande? Para algo que envolve vários arquivos, selecione o código e use Ctrl + L: o Agent abre com a seleção como contexto.
Agente07

O Agent e os quatro modos

O Agent (Ctrl + I) busca no seu código, edita vários arquivos, roda comandos no terminal, usa o navegador e corrige erros sozinho. Ele é feito de três peças: instruções (prompt de sistema e rules), ferramentas e o modelo que você escolhe.

ModoMelhor paraEdita arquivos?
AgentConstruir funcionalidades, refatorar, corrigir bugs. É o padrãoSim
AskEntender o código e explorar a arquiteturaNão (só leitura)
PlanFuncionalidades complexas: pesquisa o código, faz perguntas e entrega um plano editávelSim, depois que você aprova o plano
DebugBugs difíceis, que precisam de evidência em tempo de execuçãoSim
Shift + Tab alterna entre os modos. Cada modo começa um contexto novo; para uma tarefa nova, abra uma conversa nova.
Ferramentas do Agent: buscar arquivos, ler (inclusive imagens), editar, terminal, navegador, busca na web, gerar imagens e fazer perguntas a você. Não há limite de chamadas de ferramenta por tarefa.
Agente08

Acompanhar, corrigir e desfazer

Diff

As edições aparecem no diff enquanto o agente trabalha. Você mantém, desfaz ou revisa cada uma.

Checkpoints

Antes de mudanças grandes, o Cursor salva o estado dos arquivos. Clique no checkpoint da conversa para ver e restaurar. Eles ficam no seu computador, separados do Git: servem para desfazer o agente, não para versionar.

Subagentes

O Agent pode criar subagentes para pesquisa, terminal ou navegador, cada um com sua própria janela de contexto.

Enquanto o agente trabalhaComo
Enfileirar o próximo pedidoEnter: espera a tarefa atual acabar
Mandar agora e redirecionarCtrl + Enter
PararBotão Stop
Perguntar algo paralelo/side ou /btw: abre uma conversa lateral
Buscar conversas antigasCtrl + K na Agents Window
Use sempre Git. O agente grava as mudanças direto no disco, e o checkpoint não substitui um commit.

Personalização10

Rules, AGENTS.md e extensões do agente

Rules são instruções permanentes para o Agent. Valem em todos os modos.

TipoOnde fica
Project Rules.cursor/rules, versionadas com o código
User RulesGlobais, no seu Cursor
Team RulesNo painel da equipe (Teams e Enterprise)
AGENTS.mdArquivo Markdown na raiz: a alternativa simples

A página Customize reúne o resto:

  • MCP: conecta ferramentas externas (bancos, APIs, Figma, Linear...).
  • Skills: pacotes de instruções e scripts para tarefas específicas.
  • Subagents e hooks: agentes especializados e scripts que rodam em eventos do agente.
  • Plugins: oficiais, da comunidade ou do marketplace interno da equipe.
Se você já usa o Claude Code, os conceitos são os mesmos: AGENTS.md faz o papel do CLAUDE.md, e MCP, skills, subagentes e hooks funcionam com a mesma ideia.
Nuvem11

Cloud Agents, Bugbot e os bots de entrega

Cloud Agents

Rodam em máquinas virtuais isoladas, com um ambiente parecido com o seu notebook: repositório clonado, dependências instaladas, segredos e acesso à rede. Desde agosto de 2026 nem precisam de GitHub para começar: o trabalho pode ser salvo num repositório do próprio Cursor (Cursor Origin). Você acompanha pela web, pelo app de iOS, Slack, GitHub ou Linear.

Bugbot

Revisa pull requests e aponta bugs, falhas de segurança e problemas de qualidade, com explicação e sugestão de correção. Nos planos individuais, é cobrado por uso.

Security Review

Aponta bugs exploráveis em cada PR (Teams e Enterprise, desde 23/09/2026).

Rollouts

Acompanha cada mudança durante o deploy e informa a saúde por ambiente (Teams e Enterprise).

Agentes na nuvem guardam o código na nuvem enquanto trabalham. Por isso, Projects não funciona com o Privacy Mode (Legacy). Avalie isso antes de usar em código sensível.
Modelos12

Quais modelos trabalham por trás

O Cursor não depende de um único fornecedor: oferece modelos da Anthropic, OpenAI, Google, SpaceXAI e outros. Nos planos Pro, Pro+ e Ultra, o uso incluído é dividido em dois "bolsos", que renovam todo mês.

Cursor Models

Composer 2.5 (modelo próprio do Cursor, voltado a tarefas longas de agente) e a família Grok 4.5, 4.6 e 4.7 (treinada em conjunto com a SpaceXAI). Têm bem mais uso incluído.

Other Models

Modelos de terceiros, cobrados ao preço da API de cada um: Claude (Sonnet 5.5, Opus 5.5, Fable 5.1), GPT-5.6 (Sol, Terra, Luna), Gemini 3.1 Pro e 3.8 Flash, entre outros.

Migração15

Vindo do VS Code

1
Abra as configurações do Cursor: Ctrl + Shift + J (Mac: Cmd + Shift + J).
2
Vá em General → Account.
3
Em VS Code Import, clique em Import: extensões, temas, configurações e atalhos vêm juntos.
Atenção às extensões: o Cursor usa o registro Open VSX, não o Marketplace da Microsoft. Muitas extensões populares estão lá, mas nem todas, e algumas podem se comportar diferente.
Os atalhos padrão são os mesmos do VS Code, e os dois programas podem conviver no mesmo computador e nos mesmos projetos.
Segurança16

Um agente com terminal e rede

Ação do agentePadrão do Cursor
Ler arquivos e buscar no códigoSem aprovação (bloqueie arquivos com .cursorignore)
Editar arquivos do projetoSem aprovação, salvo arquivos de configuração
Rodar comandos no terminalPede aprovação; os Run Modes permitem liberar comandos confiáveis
Ferramentas MCPAprovação da conexão e de cada chamada (ou lista de permitidas)

Privacy Mode (Configurações → General) garante que seu código não seja usado para treinar modelos, nem pelo Cursor nem pelos provedores. Nas equipes, vem ligado por padrão.
Prompt injection existe: um arquivo ou página pode conter instruções maliciosas. Mantenha as aprovações ligadas, use Git e desconfie de repositórios desconhecidos.

Armadilhas18

Confusões comuns de quem começa

"É só um VS Code com chat"

Hoje o centro é o agente: modos, subagentes, nuvem, Projects. O chat é só a porta de entrada.

"O plano de US$ 20 é ilimitado"

Ilimitado é o Tab. O Agent consome o uso incluído conforme o modelo escolhido.

"Checkpoint é backup"

Checkpoints desfazem o agente e ficam só no seu computador. Versionamento é com Git.

"Toda extensão do VS Code funciona"

O Cursor usa o Open VSX; confira se a extensão existe lá.

"Ask pode mexer no código"

Ask é só leitura. Para mudar arquivos, use Agent, Plan ou Debug.

"Na nuvem é igual ao local"

Cloud Agents e Projects guardam o código na nuvem enquanto rodam. Considere a privacidade do projeto.

Recapitulando

Do autocompletar
à orquestração

O Cursor é um editor derivado do VS Code que evoluiu para uma plataforma de agentes. Você escreve com o Tab, ajusta trechos com Ctrl+K e delega tarefas ao Agent nos modos Agent, Ask, Plan e Debug. Na Agents Window, orquestra vários agentes, locais ou na nuvem, e com Projects encara trabalhos longos. Rules, AGENTS.md, MCP e skills adaptam tudo ao seu projeto, com modelos de vários fornecedores e planos a partir de zero.

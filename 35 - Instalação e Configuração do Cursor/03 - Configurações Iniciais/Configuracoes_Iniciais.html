Configurações
iniciais

O Cursor funciona bem logo depois de instalado, mas alguns minutos de ajuste fazem diferença: privacidade, modelo, quanto o agente pode rodar sozinho, o terminal certo, o que a IA não deve ler, idioma, fonte e formatação. Esta aula mostra o que mexer e por quê. O passo a passo por sistema está no manual em PDF.

Onde ficam as configurações

Cursor Settings

Ctrl + Shift + J. Tudo da IA: conta, privacidade, modelos, agentes, Tab, indexação, rede, Git e PRs.

Settings do editor

Ctrl + ,. Herdado do VS Code: fonte, tema, formatação, terminal, arquivos.

Arquivos

Conta02

General: conta, privacidade e atualização

Cursor Settings › General · reprodução ilustrativa
VS Code Import

Em Account. Um clique traz extensões, temas, configurações e atalhos.

Privacy Mode

Ligado: seu código nunca é usado para treinar modelos, nem pelo Cursor nem pelos provedores.

Canal

Stable (padrão). Early Access traz novidades antes, com menos estabilidade.

IA03

Models: um ponto de partida

  • Modelo padrão em Auto: o Cursor escolhe por pedido
  • Troque durante a conversa pelo seletor ou com Ctrl + /
  • Chave de API própria (opcional): cole a chave do provedor e clique em Save
  • Um modelo sumiu da lista? Pode estar indisponível na sua região; use Auto ou outro
A próxima aula, "Models e Rules", aprofunda a escolha de modelos, os custos de cada um e as rules. Aqui, basta deixar em Auto.
Com chave própria, os pedidos são cobrados pelo provedor; o Tab continua usando os modelos do Cursor, e a retenção zero do Cursor deixa de valer para esses pedidos.
IA04

Agents: quanto o agente roda sozinho

Em Cursor Settings › Agents › Approvals & Execution você escolhe o Run Mode: como o agente executa comandos de terminal, ferramentas MCP e buscas na web.

Run ModeO que roda sem perguntarRecomendação
Auto-review (padrão)Itens da lista de permitidos; o resto vai para a sandbox quando dá; o que sobra passa por um classificadorComece por aqui
AllowlistSó o que você liberou (sandbox opcional)Quem quer aprovar mais coisas
Run EverythingTudoSó em ambientes descartáveis
# ~/.cursor/permissions.json (seu) ou .cursor/permissions.json (projeto) { "autoRun": { "block_instructions": [ "Todo comando de deploy deve pedir aprovação." ] } }
Atalho da documentação: peça ao agente "quero aprovar todo comando X" e ele mesmo edita o permissions.json.
Proteção05

A sandbox em cada sistema

A sandbox deixa o comando trabalhar no projeto, mas impede que ele leia arquivos protegidos, grave fora das pastas aprovadas ou acesse a rede livremente.

macOS

Usa o Seatbelt do próprio sistema. Precisa do Cursor 2.0 ou mais novo. Nada para configurar.

Linux

Usa Landlock e seccomp. Precisa de kernel 6.2+ e user namespaces. Sem isso, o Cursor passa a pedir aprovação antes dos comandos.

Windows

A documentação não descreve sandbox para o Windows. Mantenha Auto-review ou Allowlist e evite Run Everything.

Por padrão, dentro da sandboxComportamento
Arquivos do projetoLeitura e escrita liberadas
Caminhos protegidos.git/config, .git/hooks, .vscode, .cursorignore e configurações sensíveis do Cursor
RedeBloqueada, e liberada conforme o modo de rede e o sandbox.json
IA06

Tab, indexação e rede

Tab

Cursor Settings › Tab. Deixe ligado; desligue só para tipos de arquivo em que atrapalha. O indicador no rodapé pausa ou desliga na hora.

Indexing

Em Ignore Files, a opção Hierarchical Cursor Ignore faz o Cursor procurar .cursorignore nas pastas acima do projeto. Útil em monorepos.

Network

Run Diagnostics testa a conexão. Atrás de proxy corporativo, HTTP Compatibility Mode = HTTP/1.1 e reinicie.

Rede da empresa com lista de sites liberados? A TI precisa liberar os domínios do Cursor e, desde 30/09/2026, os do novo login (*.spacex.ai, *.x.ai). A lista completa está no manual da aula 01.
Proteção07

O que a IA não deve ler

Já ignorado por padrão

Tudo do .gitignore, arquivos de lock (package-lock.json, yarn.lock...), .env*, .git/ e vários binários e documentos (.exe, .pdf, planilhas...).

No projeto: .cursorignore

Na raiz, com a mesma sintaxe do .gitignore. ! desfaz um ignorado padrão.

dist/ *.log config/segredos.json
Em todos os projetos: lista global

Vem vazia. A documentação sugere incluir:

**/.env **/.env.* **/credentials.json **/secrets.json **/*.key **/*.pem **/id_rsa
O .cursorignore bloqueia o Agent, o Tab, o Ctrl+K e o @, mas não o terminal nem o MCP. Segredo de verdade fica fora do projeto.

Editor09

O terminal que o agente usa

O agente roda os comandos no primeiro perfil de terminal disponível. Escolha o seu com a paleta › Terminal: Select Default Profile.

WindowsPowerShell (padrão), Git Bash ou WSL. Projeto com scripts de Linux? Git Bash ou WSL
Linuxbash, zsh ou fish: o mesmo do seu dia a dia
macOSzsh (padrão do sistema)
Prompt pesado atrapalha

Temas como Powerlevel10k podem embaralhar a saída que o agente lê. O Cursor define CURSOR_AGENT nas sessões dele; use para simplificar:

# ~/.bashrc if [[ -n "$CURSOR_AGENT" ]]; then PS1='\u@\h \W \$ ' fi

Os menus herdados do VS Code passam para o português; as telas próprias do Cursor (Agent, Cursor Settings) podem continuar em inglês.

Respostas da IA

O agente responde no idioma do pedido. Para garantir, crie uma User Rule em Customize › Rules (barra lateral):

Responda sempre em português do Brasil. Mantenha nomes de código, comandos e termos técnicos no original.
User Rules valem em todos os seus projetos, no Agent (todos os modos). Não valem no Tab nem na edição inline (Ctrl+K).

Resumo12

A configuração recomendada

  • VS Code importado (se você usava)
  • Privacy Mode ligado
  • Canal Stable
  • Modelo em Auto
  • Run Mode em Auto-review
  • Sandbox ativa (macOS; Linux com kernel 6.2+) ou aprovações conferidas (Windows)
  • Tab ligado (desligado só onde atrapalha)
  • Lista global de ignorados com .env, chaves e credenciais
  • Terminal padrão escolhido e prompt simples para o agente
  • Fonte, tema, Format On Save e Auto Save
  • User Rule de idioma criada
  • Você sabe abrir o settings.json e a pasta ~/.cursor
O manual em PDF desta aula traz cada item com o caminho exato no Windows, no Linux e no macOS, mais os problemas comuns de cada sistema.

Recapitulando

Seguro, rápido
e do seu jeito

Nas Cursor Settings, importe o VS Code, ligue o Privacy Mode, deixe o modelo em Auto e o Run Mode em Auto-review. Confira a sandbox do seu sistema, proteja segredos com o .cursorignore e a lista global, escolha o terminal que o agente vai usar e ajuste fonte, formatação e idioma no editor. Cada detalhe por sistema está no manual.

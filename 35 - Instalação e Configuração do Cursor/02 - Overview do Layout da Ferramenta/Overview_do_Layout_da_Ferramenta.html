Overview do layout
da ferramenta

Um passeio guiado pela tela do Cursor: as seis áreas do editor, herdadas do VS Code, o painel do Agent, o terminal com IA, a Agents Window, a paleta de comandos e os atalhos que mostram, escondem e reorganizam cada parte. Saber onde fica cada coisa é o que faz o resto do curso fluir.

Visão geral01

Um aplicativo, duas interfaces

Editor (IDE)

O Cursor "clássico", no formato do VS Code: arquivos à esquerda, código no centro, terminal embaixo e o Agent no painel da direita. Bom para escrever e revisar código de perto, usar extensões e ver vários arquivos lado a lado.

Agents Window

A interface "agente primeiro", lançada com o Cursor 3: lista de agentes e projetos, conversa no centro e mudanças à direita. Boa para coordenar vários agentes, locais e na nuvem, em vários repositórios.

Para irFaça
Do editor para a Agents WindowPaleta (Ctrl + Shift + P) › Open Agents Window
Da Agents Window para o editorPaleta › Open IDE
Abrir um arquivo sem sair da Agents WindowCtrl + P (busca por nome) ou Ctrl + Shift + F (busca no conteúdo)
Dá para deixar as duas abertas ao mesmo tempo. O Cursor diz que vai continuar mantendo e melhorando as duas. No Mac, troque Ctrl por Cmd em todos os atalhos desta aula.

Editor03

Activity Bar e Side Bar

A Activity Bar é a fileira de ícones que troca o que aparece na Side Bar (barra lateral principal). No Cursor ela é horizontal por padrão, no topo da Side Bar, para sobrar espaço para o chat da IA. Clicar de novo no ícone ativo esconde a barra.

Editor04

A área de edição

  • Abas: cada arquivo aberto vira uma aba. Ctrl + Tab alterna entre os últimos abertos.
  • Divisões (grupos): Ctrl + \ divide o editor para ver dois arquivos lado a lado; arraste abas entre os grupos.
  • Breadcrumbs: a trilha no topo (pasta › arquivo › função) leva direto a outras partes.
  • Minimap: a miniatura do arquivo à direita; clique ou arraste para pular de trecho.
  • Ir para: Ctrl + G (linha) e Ctrl + Shift + O (símbolo do arquivo).
Onde a IA aparece no editor

As sugestões do Tab surgem em cinza à frente do cursor. Com um trecho selecionado, Ctrl + K abre a edição inline ali mesmo. As mudanças do Agent aparecem como diff no próprio arquivo, para manter ou desfazer.

Com o código selecionado: Ctrl + Shift + L manda a seleção para o chat atual; Ctrl + L, para um chat novo.
Editor05

Panel e terminal com IA

O Panel fica embaixo do editor e reúne o terminal integrado, os problemas (erros e avisos), a saída e o console de depuração. Ele pode ser movido para a esquerda ou a direita.

Mostrar/esconder o PanelCtrl + J
Abrir/fechar o terminalCtrl + `
Ver os problemasCtrl + Shift + M
IA dentro do terminal

No terminal, Ctrl + K abre uma barra para descrever o comando em português. O Cursor gera o comando; Ctrl + Enter executa e Esc aceita sem executar.

É no mesmo terminal que o Agent roda comandos (testes, instalação, build), conforme o Run Mode. Para mandar a saída para o chat, use @Terminals.
Editor06

Barra de título e Status Bar

Barra de título (topo)

Tem a caixa de busca (que abre a paleta e a busca de arquivos) e os botões que mostram ou escondem as barras laterais e o Panel. O botão Customize Layout reúne as opções de disposição da tela.

Status Bar (rodapé)

Branch do Git, contagem de erros e avisos, linha e coluna, codificação, linguagem do arquivo e o indicador Cursor Tab. Clique em cada item para agir: trocar de branch, ver os problemas, mudar a linguagem.

Indicador do Tab: no canto inferior direito. Por ele você pausa o Tab por um tempo, desliga de vez ou só para certos tipos de arquivo.
Quer esconder algo? Menu View › Appearance: Side Bar, Status Bar, Activity Bar, breadcrumbs e minimap podem ser ligados e desligados.
Agent07

O painel do Agent

Abre e fecha com Ctrl + I ou Ctrl + L. Ocupa a barra lateral secundária, à direita.

  • Topo: nova conversa, histórico e abas de conversas.
  • Meio: a conversa, com os passos do agente (buscas, edições, comandos), diffs e checkpoints.
  • Caixa de mensagem: pedido, @ para contexto, / para comandos e skills, imagens coladas.
  • Embaixo da caixa: seletor de modo (Agent, Ask, Plan, Debug), seletor de modelo, o anel de contexto e o microfone (voz).

Agents Window09

A Agents Window por dentro

Barra lateral, conversa e mudanças · reprodução ilustrativa
Barra lateral

New Agent, Projects, a lista de agentes (com status: rodando, pronto, esperando você) e os workspaces. Fixe as conversas que você mais usa no topo.

Centro

A conversa com o agente selecionado, com subagentes, terminal e artefatos (capturas, vídeos de demonstração).

Configurações11

Três telas de configuração

Cursor Settings

Ctrl + Shift + J. Tudo da IA: conta, Privacy Mode, modelos, agentes e Run Mode, Tab, rede, Git e PRs. (Próxima aula.)

Settings (do editor)

Ctrl + ,. Herdado do VS Code: fonte, tema, formatação, minimap, comportamento do editor.

Customize

Na barra lateral: plugins, servidores MCP, rules, skills e subagentes, por usuário, equipe ou projeto.

Atalhos de teclado: Ctrl + R e depois Ctrl + S, ou paleta › Keyboard Shortcuts. Todos podem ser trocados, inclusive os da IA.
O Cursor usa Ctrl + K para a edição inline. Alguns atalhos de duas teclas do VS Code que começam com Ctrl + K podem se comportar diferente; confira em Keyboard Shortcuts.
Personalizar12

Monte o layout do seu jeito

  • Arraste visões da Side Bar para a barra secundária (direita) e vice-versa
  • Mova o Panel para a esquerda ou a direita e ganhe espaço vertical
  • Customize Layout (barra de título) reúne posições e visibilidade
  • Zen Mode: Ctrl + K, depois Z (sair: Esc duas vezes) esconde tudo menos o código
  • Minimap: desligue em Settings (editor.minimap.enabled) se não usar
  • Tela cheia de foco: esconda Side Bar (Ctrl + B) e Panel (Ctrl + J)
Duas sugestões de arrumação

Escrevendo código: Explorer à esquerda, editor dividido no centro, terminal embaixo e o Agent fechado até precisar.

Delegando ao agente: Side Bar escondida, Agent aberto e largo à direita, e a Agents Window quando houver várias tarefas.

O Cursor reabre do jeito que você deixou: a pasta, o layout e os arquivos abertos são lembrados.

Prática14

Exercício: um passeio de 10 minutos

1
Abra uma pasta de teste. No Explorer, crie ola.js.
2
Comece a digitar uma função e aceite uma sugestão do Tab.
3
Selecione a função, Ctrl + K e peça "adicione comentários".
4
Abra o terminal (Ctrl + `), use Ctrl + K e peça "rode este arquivo com node".
5
Abra o Agent (Ctrl + I), troque para Ask e pergunte o que o arquivo faz.
6
Esconda a Side Bar e o Panel; depois mostre de novo.
7
Paleta › Open Agents Window, olhe a tela e volte com Open IDE.
Ao final, você terá usado as seis áreas do editor, as três formas de IA (Tab, Ctrl+K, Agent), o terminal com IA e as duas interfaces.
Errou algum atalho? Não tem problema: paleta (Ctrl + Shift + P) e o nome do que você quer fazer.

Recapitulando

Cada coisa
no seu lugar

O editor do Cursor tem as seis áreas do VS Code: Activity Bar, Side Bar, Editor, Panel, Status Bar e a barra secundária, onde mora o Agent. A IA aparece no editor (Tab, Ctrl+K, diffs), no terminal (Ctrl+K) e no painel do Agent. A Agents Window é a outra interface, para coordenar vários agentes. A paleta de comandos leva a tudo, e o layout se ajusta ao seu jeito de trabalhar.

Vale para os três sistemas. Alguns minutos aqui evitam a maioria dos problemas depois.

Você vai precisar dePor quê

O que vamos instalar

Cursor (o aplicativo)

Editor de código com IA e a Agents Window. É o que as seções 02 a 04 instalam. Versão de referência deste manual: 3.22.12.

Cursor CLI (opcional)

O agente no terminal, comando agent. Tem instalação própria, na seção 06.

Baixe só do site oficial: cursor.com/download (ou cursor.com/downloads, com todas as versões). Instaladores de outros sites, grupos ou vídeos podem estar adulterados.
⊞
WindowsWindows 10 ou mais recente · processadores x64 (Intel/AMD) ou ARM64

02Windows · verificar e escolher o arquivo

Passo 1 · Confirme a versão e o tipo do processador

1
Pressione Win + I para abrir as Configurações.
2
Vá em Sistema › Sobre.
3
Em Especificações do Windows, confira a Edição: precisa ser Windows 10 ou 11.
4
Em Tipo de sistema: "processador baseado em x64" → versão x64; "processador baseado em ARM" → versão ARM64.

Passo 2 · Escolha entre User e System

VersãoArquivo (x64)Quando usar
User (recomendada)CursorUserSetup-x64-3.22.12.exeInstala só para o seu usuário, na sua pasta pessoal. Normalmente não pede senha de administrador
SystemCursorSetup-x64-3.22.12.exeInstala para todos os usuários do computador. Pede permissão de administrador

Para ARM64, o nome troca x64 por arm64 (por exemplo, CursorUserSetup-arm64-3.22.12.exe). O instalador tem cerca de 210 MB. O número da versão muda com as atualizações.

Passo 3 · Baixe

1
Abra cursor.com/download: o site costuma detectar o Windows e oferecer o botão certo. Para escolher a variante, use cursor.com/downloads e clique em Windows (x64) (User) ou na opção que corresponde ao passo 1 e 2.
2
O arquivo vai para a pasta Downloads.

02Windows · instalar e conferir

1
Dê dois cliques no instalador que você baixou.
2
Se aparecer a tela azul do SmartScreen ("O Windows protegeu o computador"), confira se o arquivo veio do site oficial e clique em Mais informações › Executar assim mesmo.
3
Na versão System, o Controle de Conta de Usuário pergunta se o app pode fazer alterações: clique em Sim.
4
Aceite o contrato e siga o assistente. Mantenha a pasta de instalação padrão.
5
Nas tarefas adicionais, deixe marcada a opção de adicionar ao PATH (se aparecer): ela permite abrir o Cursor pelo terminal com o comando cursor. Marque o atalho na área de trabalho, se quiser.
6
Clique em Instalar e, no fim, em Concluir. O Cursor abre (ou procure "Cursor" no menu Iniciar).

As telas do assistente podem mudar entre versões; os nomes acima são os mais comuns.

Como confirmar que deu certo

  • "Cursor" aparece no menu Iniciar e abre sem erro
  • Em Configurações › Aplicativos › Aplicativos instalados, "Cursor" está na lista
  • No PowerShell, cursor --version mostra a versão (se você marcou o PATH; feche e reabra o terminal antes)

Problemas comuns no Windows

SintomaO que fazer
"Este aplicativo não pode ser executado no computador"Arquitetura errada (x64 × ARM64). Volte ao passo 1
Tela em branco ao abrirSaia do Cursor pela bandeja do sistema (perto do relógio), abra de novo; se continuar, execute como administrador (recomendação oficial)

Passo 1 · Descubra a distribuição e a arquitetura

# Qual distribuição e versão cat /etc/os-release # Qual arquitetura: x86_64 = x64 · aarch64 = ARM64 uname -m

Passo 2 · Escolha o caminho

CaminhoParaVantagem
A · repositório apt (recomendado)Ubuntu, Debian, Mint, Pop!_OSÍcone no menu, atualização automática e ferramentas de linha de comando
B · repositório dnf (recomendado)Fedora, RHEL e derivadosMesmas vantagens

A documentação oficial prefere os pacotes apt e dnf ao AppImage. Também há os arquivos .deb e .rpm avulsos em cursor.com/downloads (por exemplo, cursor_3.22.12_amd64.deb, cerca de 210 MB), mas o repositório é melhor porque traz as atualizações.

03Linux · A. Ubuntu, Debian e derivados

Copie um comando por vez no terminal (Ctrl + Alt + T). O sudo pede a sua senha.

# 1. Pré-requisitos (curl e gpg) e a pasta de chaves sudo apt update && sudo apt install -y curl gpg sudo install -m 0755 -d /etc/apt/keyrings # 2. Chave GPG do Cursor (garante que os pacotes são oficiais) curl -fsSL https://downloads.cursor.com/keys/anysphere.asc | gpg --dearmor | sudo tee /etc/apt/keyrings/cursor.gpg > /dev/null # 3. Repositório do Cursor echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/cursor.gpg] https://downloads.cursor.com/aptrepo stable main" | sudo tee /etc/apt/sources.list.d/cursor.list > /dev/null # 4. Atualizar e instalar sudo apt update sudo apt install cursor

Os comandos 2 a 4 são os da documentação oficial. O passo 1 só garante que curl, gpg e a pasta /etc/apt/keyrings existem (versões antigas do Debian e do Ubuntu podem não ter a pasta).

Como confirmar

  • "Cursor" aparece no menu de aplicativos
  • cursor --version no terminal mostra a versão
  • apt policy cursor mostra o repositório downloads.cursor.com
Daqui em diante, as atualizações chegam junto com as do sistema: sudo apt update && sudo apt upgrade.

03Linux · B. Fedora, Red Hat e derivados

# 1. Criar o arquivo do repositório sudo tee /etc/yum.repos.d/cursor.repo << 'EOF' [cursor] name=Cursor baseurl=https://downloads.cursor.com/yumrepo enabled=1 gpgcheck=1 gpgkey=https://downloads.cursor.com/keys/anysphere.asc EOF # 2. Instalar (na primeira vez, o dnf pede para aceitar a chave GPG: responda y) sudo dnf install cursor

Como confirmar

  • "Cursor" aparece no menu de aplicativos
  • cursor --version mostra a versão
  • Atualizações: sudo dnf upgrade

O pacote .rpm avulso (cursor-3.22.12.el8.x86_64.rpm) também existe em cursor.com/downloads, mas sem o repositório você precisa baixar cada atualização à mão.

03Linux · C. AppImage (qualquer distro)

1
Em cursor.com/downloads, baixe Linux AppImage (x64) ou (ARM64). O arquivo se chama, por exemplo, Cursor-3.22.12-x86_64.AppImage (cerca de 300 MB).
2
Dê permissão de execução e rode:
cd ~/Downloads chmod +x Cursor-*.AppImage ./Cursor-*.AppImage
Erro sobre FUSE ou libfuse.so.2? AppImages precisam da biblioteca FUSE 2, que nem toda distro traz. No Ubuntu 22.04: sudo apt install libfuse2; no Ubuntu 24.04 ou mais novo: sudo apt install libfuse2t64. Ou prefira o caminho A ou B.
Dica: guarde o AppImage numa pasta fixa (por exemplo, ~/Aplicativos) em vez de deixar em Downloads. A cada versão nova, baixe o novo arquivo e apague o antigo.

04macOS · verificar e baixar

Passo 1 · Confira o macOS e o processador

1
Clique no menu Apple (o ícone da maçã, no canto superior esquerdo) › Sobre Este Mac.
2
Veja a versão do macOS: precisa ser 12 (Monterey) ou mais nova.
3
Em Chip aparece "Apple M1/M2/M3/M4..." (Apple Silicon); em Processador, "Intel".

Passo 2 · Escolha o arquivo

Opção em cursor.com/downloadsArquivoPara
Mac UniversalCursor-darwin-universal.dmg (~450 MB)Qualquer Mac. Na dúvida, use esta
Mac (ARM64)Cursor-darwin-arm64.dmgApple Silicon (arquivo menor)
Mac (x64)Cursor-darwin-x64.dmgMacs com Intel

04macOS · instalar e conferir

1
Abra o .dmg baixado (dois cliques na pasta Downloads).
2
Na janela que abre, arraste o ícone do Cursor para a pasta Aplicativos.
3
Ejete o disco do instalador (botão ⏏ no Finder) e, se quiser, apague o .dmg.
4
Abra o Cursor pela pasta Aplicativos ou pelo Spotlight (Cmd + Espaço, digite "Cursor").
5
Na primeira abertura, o macOS (Gatekeeper) avisa que o app foi baixado da internet: clique em Abrir.
Rode sempre a partir de Aplicativos, nunca de dentro do .dmg: assim as atualizações automáticas funcionam.

Comando cursor no Terminal

Abra a paleta de comandos (Cmd + Shift + P), procure Shell Command: Install 'cursor' command e execute. Depois, num Terminal novo, cursor . abre a pasta atual no Cursor.

Esse comando de paleta vem do VS Code, de onde o Cursor deriva; o nome exato pode variar entre versões.

Problemas comuns no macOS

SintomaO que fazer
"Cursor está danificado"Segundo o Cursor, é um problema do macOS, não do download. Feche o Cursor e encerre os processos que sobrarem no Monitor de Atividade; espere um minuto e abra de novo. Se continuar: mova para o Lixo, esvazie, baixe de novo; em último caso, reinicie o Mac
Tela em brancoSaia com Cmd + Q e abra de novo; se persistir, apague e reinstale
Lento num Mac com Apple SiliconConfira se não instalou a versão x64 (Intel), que roda emulada. Use Universal ou ARM64

05Primeira configuração (todos os sistemas)

Passo 1 · Entrar na conta

1
Ao abrir pela primeira vez, clique para entrar: o navegador abre a página de login.
2
Entre com e-mail, Google ou GitHub (ou crie a conta). Volte ao Cursor quando o navegador pedir.
Desde 30/09/2026 a página de login do Cursor fica em accounts.spacex.ai e accounts.x.ai (antes era authenticator.cursor.sh). Ninguém é desconectado; só redes com lista de sites liberados precisam se ajustar (seção 08).

06Cursor CLI nos três sistemas

Opcional. O CLI traz o agente para o terminal (comando agent), com os modos Agent, Plan e Ask. É diferente do comando cursor, que só abre o editor.

Linux, macOS e Windows com WSL

curl https://cursor.com/install -fsS | bash # Se "agent" não for encontrado, coloque ~/.local/bin no PATH # bash: echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc source ~/.bashrc # zsh (padrão no macOS): echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc source ~/.zshrc

Windows (nativo, PowerShell)

irm 'https://cursor.com/install?win32=true' | iex

Conferir, entrar e usar

agent --version # confere a instalação agent login # entra na conta agent # sessão interativa agent update # atualiza (também atualiza sozinho)
Em servidores e CI, em vez de agent login, use a variável de ambiente CURSOR_API_KEY.

Atualizar

SistemaComo
TodosO Cursor se atualiza sozinho. Para forçar: paleta (Ctrl/Cmd + Shift + P) › Cursor: Attempt Update e reinicie quando pedir

Desinstalar

SistemaRemover o aplicativo
WindowsConfigurações › Aplicativos › Aplicativos instalados › Cursor › Desinstalar
macOSSaia do Cursor e arraste-o de Aplicativos para o Lixo
Linuxsudo apt remove cursor · sudo dnf remove cursor · ou apague o AppImage
Desinstalar o aplicativo normalmente não apaga as configurações nem o histórico de conversas. Eles ficam na pasta .cursor da sua pasta pessoal e na pasta de dados do aplicativo (por exemplo, ~/.config/Cursor no Linux, ~/Library/Application Support/Cursor no macOS, %APPDATA%\Cursor no Windows). Apague-as só se quiser começar do zero; os locais podem variar entre versões.

08Problemas comuns e checklist final

ProblemaSolução oficial
A IA não responde atrás de proxy (ex.: Zscaler)Cursor Settings › Network › HTTP Compatibility Mode = HTTP/1.1 e reinicie (alguns proxies bloqueiam HTTP/2)
Não sei se é a redeCursor Settings › Network › Run Diagnostics
Firewall da empresaPeça à TI para liberar *.cursor.sh, *.cursor-cdn.com, *.cursorapi.com, *.cursorvm.com e, para o login, *.spacex.ai e *.x.ai (no mínimo accounts.spacex.ai, accounts.x.ai, auth.x.ai)
Erros de DNS depois de usar VPNFeche o Cursor por completo e abra de novo (não basta recarregar a janela)
Mensagem de "atividade suspeita"Desligue a VPN, abra uma conversa nova, espere alguns minutos ou entre com outro método (Google ou GitHub)
Cursor lento ou pesadoTeste sem extensões: cursor --disable-extensions. Coloque pastas geradas (dist/, build/, .next/) no .cursorignore
Disco cheio por causa do CursorPaleta › Delete Old Chats… e depois GC Agent KV Blobs; ajuste a limpeza de worktrees (padrão: 25 worktrees ou 50 GB)
Uma extensão do VS Code não apareceO Cursor usa o Open VSX. Procure uma alternativa lá (ou uma versão da Anysphere)
Um modelo não aparecePode estar indisponível na sua região: use Auto ou outro modelo

Checklist final

  • Cursor instalado a partir do site oficial, na arquitetura certa
  • Abre sem erro e entrou na conta
  • Comando cursor funcionando no terminal (opcional)
  • Configurações do VS Code importadas (se você usava)
  • Privacy Mode ligado e Run Mode em Auto-review
  • Pasta de teste aberta e primeiro pedido ao Agent respondido
  • Cursor CLI instalado e agent --version funcionando (opcional)

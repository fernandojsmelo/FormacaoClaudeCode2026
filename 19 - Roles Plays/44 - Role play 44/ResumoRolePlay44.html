🔍 Por que sua busca ficou lenta? (Lista vs. Set)

Imagine que a Lista é uma fila indiana de pessoas. Se você perguntar "O Waldo está aí?", o Python precisa olhar o rosto da primeira pessoa, da segunda, da terceira... até o final. Se a lista tiver 1 milhão de itens e o Waldo for o último, o Python vai fazer 1 milhão de checagens. É por isso que ficou lento!

Já o Set (Conjunto) usa uma mágica chamada Hashtable. Imagine que o Set é um armário cheio de gavetas numeradas. Quando você joga um item lá dentro, o Python calcula exatamente em qual gaveta ele deve ficar. Para checar se o Waldo está lá, o Python vai direto na gaveta dele. Não importa se o Set tem 10 itens ou 10 milhões, a busca é instantânea.

02 — Lista em set ou como chave: unhashable
PerguntaNossa, cê explicou de um jeito que fez tudo parecer bem mais claro! Esse lance do armário cheio de gavetas para o S…

Que bom que os exemplos ajudaram a clarear as coisas! Fico muito feliz.

E você tem um excelente faro para problemas: sim, isso dá um erro clássico no Python!

Se você tentar colocar uma lista dentro de um set ou usá-la como chave de um dicionário, o Python vai travar o seu código na hora e jogar esse erro na sua tela:

TypeError: unhashable type: 'list'

🛑 Por que isso acontece? O mistério do "Unhashable"

Lembra da metáfora do Set como um armário cheio de gavetas numeradas? Para o Python saber exatamente em qual gaveta colocar um item, ele usa uma função matemática que calcula uma "identidade única" (um número fixo) para aquele item. Esse processo se chama Hash.

Para que um objeto possa ter esse número fixo (ou seja, ser hashable), ele precisa ser imutável. O Python precisa ter certeza absoluta de que o item nunca vai mudar de cara. Se ele mudasse, o cálculo do Hash mudaria, e o Python perderia o item de vista dentro do armário.

  • O problema da Lista: A lista é mutável. Você pode adicionar, remover ou alterar itens dela a qualquer momento.
  • Se o Python permitisse uma lista como chave de um dicionário ou dentro de um set, você poderia criar a lista, guardá-la lá dentro e, depois, alterar o conteúdo dela. O "endereço" da gaveta mudaria e o sistema inteiro quebraria.

🛠 Como resolver isso no seu código?

Sempre que você precisar de uma "lista" que sirva como chave de dicionário ou que vá dentro de um set, você deve usar uma Tupla ( ).

Como a tupla é imutável (não muda nunca), o Python consegue calcular o Hash dela com total segurança.

Exemplo 1: Coordenadas de um mapa (Dicionário)

Imagine que você quer mapear o nome de cidades usando as coordenadas geográficas (Latitude e Longitude) como chave:

# ❌ ERRO: Usar lista como chave dá TypeError
# locais = { [12.34, 56.78]: "São Paulo" }
# ✅ CORRETO: Usar tupla (imutável) funciona perfeitamente!
locais = {
(12.34, 56.78): "São Paulo",
(98.76, 54.32): "Teresina"
}
# Buscando a cidade pela coordenada:
print(locais[(12.34, 56.78)]) # Saída: São Paulo
Use o código com cuidado.

Exemplo 2: Histórico de combinações de jogos (Set)

Imagine que você quer registrar as combinações de números sortados na loteria para garantir que nenhuma se repita:

# ✅ CORRETO: Guardando tuplas dentro de um Set
jogos_sorteados = set()
jogo_de_hoje = (4, 8, 15, 16, 23, 42) # Tupla
jogos_sorteados.add(jogo_de_hoje) # Funciona perfeitamente!
print(jogos_sorteados)
Use o código com cuidado.

Vamos colocar a mão na massa com exemplos práticos.

Para um controle de estoque, a melhor estratégia é usar um Dicionário onde a Chave é o código do produto e o Valor são os detalhes do produto (que também podem ser outro dicionário).

O grande truque aqui é que o próprio Dicionário já resolve o seu problema de duplicatas automaticamente! Como as chaves de um dicionário precisam ser únicas, se você tentar adicionar um produto com um código que já existe, o Python apenas atualiza as informações em vez de criar um item duplicado.

Veja abaixo três exemplos práticos de como estruturar e manipular isso no seu projeto:

1. Criando o Estoque e Evitando Duplicatas (O jeito ideal)

Aqui, usamos o código do produto (uma string ou número) como a chave. Se você tentar cadastrar o mesmo código duas vezes, o segundo apenas atualiza o primeiro.

# Inicializando nosso estoque como um dicionário
estoque = {
"PROD001": {"nome": "Teclado Mecânico", "quantidade": 15, "preco": 250.00},
"PROD002": {"nome": "Mouse Gamer", "quantidade": 30, "preco": 120.00}
}
# --- TESTANDO AS DUPLICATAS ---
# Se tentarmos adicionar um novo produto com o código PROD001 (que já existe):
novo_cadastro = "PROD001"
estoque[novo_cadastro] = {"nome": "Teclado Mecânico RGB", "quantidade": 20, "preco": 280.00}
# O Python não duplica! Ele apenas atualiza as informações do PROD001:
print(estoque["PROD001"]["nome"]) # Saída: Teclado Mecânico RGB
print(f"Total de itens no estoque: {len(estoque)}") # Saída: 2 (não virou 3!)
Use o código com cuidado.

2. Buscando Dados "Pelo Código" Instantaneamente

Esqueça os loops for para procurar itens. Com o dicionário, a busca pelo código é direta e imediata.

codigo_buscado = "PROD002"
# Verificando se o código existe antes de acessar (para não dar erro no programa)

print(f"📦 Produto Encontrado!")

3. E onde o Set entraria se você quisesse usá-lo?

Você pode usar um Set em paralelo para criar filtros rápidos. Por exemplo, imagine que você quer saber, em tempo real, quais produtos estão esgotados (quantidade igual a zero) para mandar para o fornecedor:

# Estoque atualizado com um item zerado

"PROD001": {"nome": "Teclado Mecânico", "quantidade": 15},
"PROD002": {"nome": "Mouse Gamer", "quantidade": 0}, # Esgotado
"PROD003": {"nome": "Fone de Ouvido", "quantidade": 0} # Esgotado

# Criando um Set para monitorar produtos esgotados
produtos_esgotados = set()
# Alimentando o Set (percorrendo o estoque)
for codigo, info in estoque.items():
if info["quantidade"] == 0:
produtos_esgotados.add(codigo)
# Agora você tem uma lista de alertas ultra rápida e sem duplicatas
print(f"🚨 Alerta de reposição para os códigos: {produtos_esgotados}")
# Saída: {'PROD002', 'PROD003'}
Use o código com cuidado.

05 — A função adicionar_produto()
PerguntaCaramba, que completo! Esse mix de Dicionário e Set parece perfeito pro meu controle de estoque. Gostei muito dessa …

Bora, com certeza!

Vamos desenhar essa função juntos de um jeito bem profissional, mas super simples de entender.

Para a nossa função adicionar_produto(), vamos criar uma lógica inteligente:

  1. Se o código do produto já existir, ela avisa e atualiza apenas a quantidade em estoque (somando o que chegou ao que já tinha).
  2. Se o código for novo, ela cria o cadastro do zero.

Aqui está o código completo estruturado para o seu projeto:

# 1. Iniciamos o nosso estoque (Dicionário)
estoque = {
"PROD001": {"nome": "Teclado Mecânico", "quantidade": 15, "preco": 250.00},
"PROD002": {"nome": "Mouse Gamer", "quantidade": 30, "preco": 120.00}
}
# 2. Criamos a função inteligente
def adicionar_produto(codigo, nome, quantidade, preco):
# Verificamos se o código já existe no dicionário do estoque
if codigo in estoque:
# Se já existe, somamos a nova quantidade à quantidade antiga (Baixa automática de reposição)
estoque[codigo]["quantidade"] += quantidade
# Atualizamos o preço, caso tenha mudado no fornecedor
estoque[codigo]["preco"] = preco
print(f"🔄 Produto {codigo} já existia! Estoque atualizado para {estoque[codigo]['quantidade']} unidades.")
else:
# Se não existe, cria um cadastro novinho em folha
estoque[codigo] = {
"nome": nome,
"quantidade": quantidade,
"preco": preco
}
print(f"✨ Sucesso: Novo produto [{nome}] cadastrado com o código {codigo}!")
# --- HORA DE TESTAR A FUNÇÃO NO SEU PROJETO ---
print("--- Estado Inicial do Estoque ---")
print(estoque)
print("-" * 35)
# Teste 1: Cadastrando um produto totalmente novo
adicionar_produto("PROD003", "Monitor 24 Polegadas", 10, 899.90)
# Teste 2: Tentando cadastrar o PROD001 de novo (Chegaram mais 5 teclados no estoque)
adicionar_produto("PROD001", "Teclado Mecânico", 5, 260.00)
print("-" * 35)
print("--- Estado Final do Estoque ---")
# Veja como o PROD001 agora tem 20 unidades (15 anteriores + 5 novas) e o preço atualizou!
import pprint
pprint.pprint(estoque)

  • Agilidade na reposição: Quando chega caixa nova do fornecedor, você só joga a quantidade ali e o Python faz a matemática de somar sozinho.

07 — A função dar_baixa_produto()
Perguntagostaria que você me mostra-se ums exemplos

Bora!

Vamos criar a função dar_baixa_produto() (ou vender_produto()). Ela vai fazer o caminho inverso: tirar itens do estoque, checar se você realmente tem aquela quantidade para vender e, de quebra, usar o Set que planejamos para te acender um alerta vermelho caso o produto esgote!

Aqui está o exemplo prático para você copiar e rodar no seu projeto:

# 1. Nosso estoque inicial e o nosso Set de alertas de esgotados
estoque = {
"PROD001": {"nome": "Teclado Mecânico", "quantidade": 20, "preco": 260.00},
"PROD002": {"nome": "Mouse Gamer", "quantidade": 5, "preco": 120.00}
}
produtos_esgotados = set() # O Set que vai guardar os códigos zerados
# 2. Criando a função de dar baixa
def dar_baixa_produto(codigo, quantidade_vendida):
# Passo 1: O produto existe no sistema?
if codigo not in estoque:
print(f"❌ Erro: O código {codigo} não existe no estoque!")
return
produto = estoque[codigo]
quantidade_atual = produto["quantidade"]
# Passo 2: Temos estoque suficiente para essa venda?
if quantidade_vendida > quantidade_atual:
print(f"⚠ Estoque insuficiente para {produto['nome']}! Disponível: {quantidade_atual} | Tentativa: {quantidade_vendida}")
return
# Passo 3: Se der tudo certo, subtrai a quantidade
produto["quantidade"] -= quantidade_vendida
print(f"🛍 Venda realizada: {quantidade_vendida}x [{produto['nome']}]")
# Passo 4: O superpoder do Set! Se zerou, vai para a lista de alertas
if produto["quantidade"] == 0:
produtos_esgotados.add(codigo)
print(f"🚨 ATENÇÃO: O produto {produto['nome']} ({codigo}) ACABOU de esgotar!")
# --- HORA DE TESTAR NO SEU SISTEMA ---
print("--- 🛒 Simulando Vendas ---")
# Teste 1: Venda padrão (Temos 5 mouses, vamos vender 2)
dar_baixa_produto("PROD002", 2)
# Teste 2: Tentando vender mais do que tem (Temos 3 mouses restantes, tentamos vender 10)
dar_baixa_produto("PROD002", 10)
# Teste 3: Zerando o estoque (Vamos vender os 3 mouses que sobraram para ver o Set em ação)
dar_baixa_produto("PROD002", 3)
print("\n" + "-" * 40)
print("--- 📋 Painel de Controle Final ---")
print(f"Produtos no Set de Esgotados: {produtos_esgotados}")
print(f"Quantidade restante de PROD002 no estoque: {estoque['PROD002']['quantidade']} unidades.")
Use o código com cuidado.

💡 Por que esse combo de Dicionário + Set ficou perfeito?

  1. Segurança total: A função não deixa seu estoque ficar negativo (ex: -5 mouses).
  2. Painel de Alertas: O set produtos_esgotados funciona como um mural de avisos. Toda vez que você rodar seu sistema, basta olhar para esse Set para saber o que precisa comprar do fornecedor imediatamente, sem ter que caçar item por item dentro do dicionário.

Para o nosso relatório ficar bem profissional, vamos fazer ele mostrar:

Aqui está o código completo para você adicionar ao seu projeto:

# 1. Nosso estoque e conjunto de alertas atualizados
estoque = {
"PROD001": {"nome": "Teclado Mecânico", "quantidade": 20, "preco": 260.00},
"PROD002": {"nome": "Mouse Gamer", "quantidade": 0, "preco": 120.00}, # Esgotado
"PROD003": {"nome": "Monitor 24'", "quantidade": 3, "preco": 899.90} # Estoque baixo
}
# 2. Criando a função de relatório
def gerar_relatorio_estoque():
print("\n" + "=" * 55)
print("📋 RELATÓRIO GERAL DO ESTOQUE".center(55))
print("=" * 55)
print(f"{'CÓDIGO':<10} | {'PRODUTO':<20} | {'QTD':<5} | {'PREÇO':<10} | {'STATUS'}")
print("-" * 55)
valor_total_estoque = 0
# Percorremos o dicionário pegando a chave (codigo) e o valor (info)
for codigo, info in estoque.items():
nome = info["nome"]
qtd = info["quantidade"]
preco = info["preco"]
# Calculando o valor financeiro deste produto parado em estoque
valor_item = qtd * preco
valor_total_estoque += valor_item
# Definindo um status visual com base na quantidade
if qtd == 0:
status = "🚨 ESGOTADO"
elif qtd <= 3:
status = "⚠ BAIXO"
else:
status = "✅ OK"
# Exibindo a linha formatada e alinhada
print(f"{codigo:<10} | {nome:<20} | {qtd:<5} | R${preco:<8.2f} | {status}")
print("-" * 55)
print(f"💰 Valor total investido em estoque: R$ {valor_total_estoque:,.2f}")
print("=" * 55 + "\n")
# --- TESTANDO O RELATÓRIO ---
gerar_relatorio_estoque()

O Python vai tentar ( try) executar o código de conversão. Se o usuário digitar algo errado, em vez de fechar o programa, o Python vai capturar a exceção ( except) e rodar uma mensagem amigável, pedindo para tentar de novo.

Aqui estão os exemplos práticos comparando o seu jeito (com for), o jeito com map/filter, e a forma mais moderna em Python (chamada List Comprehension).

1. Transformando dados (Deixar textos em maiúsculo)

Use o map quando você quer aplicar uma função/transformação em todos os elementos da lista. O tamanho da lista final continua exatamente o mesmo.

nomes = ["ana", "bruno", "carla"]
# ❌ Como você faz hoje (Laço manual)
maiusculos_for = []
for nome in nomes:
maiusculos_for.append(nome.upper())
# 💡 Com map e lambda
# O map precisa ser envolvido por list() para virar uma lista visualizável
maiusculos_map = list(map(lambda nome: nome.upper(), nomes))
# 🐍 O jeito mais recomendado em Python (List Comprehension)
maiusculos_list_comp = [nome.upper() for nome in nomes]
print(maiusculos_map) # Resultado: ['ANA', 'BRUNO', 'CARLA']
Use o código com cuidado.

2. Filtrando dados (Pegar apenas números pares)

Use o filter quando você quer testar cada item com uma condição (que retorna True ou False). Apenas os itens que forem True entram na lista final.

numeros = [1, 2, 3, 4, 5, 6]
# ❌ Como você faz hoje (Laço manual)
pares_for = []
for num in numeros:
if num % 2 == 0:
pares_for.append(num)
# 💡 Com filter e lambda
# A função lambda aqui faz o teste lógico (num % 2 == 0)
pares_filter = list(filter(lambda num: num % 2 == 0, numeros))
# 🐍 O jeito mais recomendado em Python (List Comprehension)
pares_list_comp = [num for num in numeros if num % 2 == 0]
print(pares_filter) # Resultado: [2, 4, 6]

Direto ao ponto: no Python moderno, você quase nunca deve preferir o map em vez de uma compreensão de lista (List Comprehension).

A própria comunidade Python e o criador da linguagem (Guido van Rossum) preferem as compreensões de lista porque elas são mais legíveis, diretas e dispensam o uso de funções lambda na maioria das vezes.

No entanto, existem 3 cenários específicos onde o map se sai melhor ou é preferível. Veja quais são:

1. Quando você já tem uma função pronta (Sem usar lambda)

Se você não precisa inventar uma função na hora com o lambda e já tem uma função nativa ou criada por você, o map fica extremamente limpo.

  • 📋 Objetivo: Converter uma lista de strings numéricas em números inteiros.
strings = ["10", "20", "30"]
# 💡 Com map: Você passa a função 'int' direto, sem criar variáveis temporárias
numeros_map = list(map(int, strings))
# 🐍 Com list comprehension: Você precisa criar a variável temporária 'x'
numeros_list = [int(x) for x in strings]
Use o código com cuidado.

Nesse caso, map(int, strings) é muito elegante porque diz diretamente: "aplique a função int nesta coleção".

2. Para economizar memória com listas gigantes (Avaliação Preguiçosa)

A grande mágica oculta do map é que ele não cria uma lista nova na memória imediatamente. Ele retorna um objeto gerador (um "map object"). Ele só processa o próximo item quando você pede por ele (como em um laço for).

  • 💻 A diferença de comportamento:
# 🚨 A List Comprehension processa e joga os 10 milhões de itens na memória NA HORA
lista_gigante = [x * 2 for x in range(10_000_000)]
# ⚡ O map faz isso INSTANTANEAMENTE e gasta quase zero de memória
gerador_gigante = map(lambda x: x * 2, range(10_000_000))
Use o código com cuidado.

Se você só vai rodar um for logo em seguida para salvar esses dados em um arquivo linha por linha, usar o map (sem o list() em volta) evita que seu computador trave por falta de memória.

(Nota: Você também pode fazer isso com compreensões usando parênteses (x * 2 for x in ...), que viram "generator expressions").

3. Operações com múltiplas listas ao mesmo tempo

O map aceita receber mais de uma lista como argumento se a função que você passar aceitar mais de um parâmetro.

  • 📋 Objetivo: Somar os elementos correspondentes de duas listas diferentes.
lista_a = [1, 2, 3]
lista_b = [10, 20, 30]
# 💡 O map puxa um item de cada lista e passa para a função lambda
resultados_map = list(map(lambda x, y: x + y, lista_a, lista_b))
# 🐍 Na compreensão de lista, você seria obrigado a usar a função zip() junto
resultados_list = [x + y for x, y in zip(lista_a, lista_b)]
Use o código com cuidado.

Resumo da ópera

  • Escolha List Comprehension em 90% dos casos. Ela é o padrão visual do Python, aceita filtros (if) facilmente no mesmo comando e qualquer programador Python bate o olho e entende.
  • Escolha map() quando for aplicar uma função já existente (como int, str, len) a uma lista, ou quando estiver lidando com volumes massivos de dados onde a memória do computador é uma preocupação.

Mudar a estratégia de "deletar" para "substituir" é um cenário clássico no tratamento de dados!

A regra de ouro que você precisa decorar aqui é: quando usamos if e else juntos para substituir valores, a estrutura muda de lugar e vai toda para o começo da List Comprehension.

Veja a comparação de como a estrutura se comporta:

  • Só para filtrar (Remover): O if fica no final.
  • Para substituir (Transformar com condicional): O if/else fica no começo.

O Jeito Certo: Substituindo "NULO" por 0

Veja como fica a linha de código para resolver esse problema:

vendas_brutas = [" 150 ", "NULO", "200", " 350", "NULO", "50"]
# 💡 A estrutura lê-se: "Faça ISSO se for verdadeiro, SENÃO faça AQUILO"
vendas_limpas = [int(venda.strip()) if venda != "NULO" else 0 for venda in vendas_brutas]
print(vendas_limpas)
# Resultado: [150, 0, 200, 350, 0, 50]
Use o código com cuidado.

🧠 Por que a ordem inverteu?

Pense na List Comprehension como uma esteira de produção:

1. Quando o if está no final (Filtro): O Python decide se o item entra ou não na esteira. Se o item for "NULO", ele é jogado no lixo e nem passa pela transformação.

2. Quando o if/else está no começo (Expressão): Todos os itens entram na esteira obrigatoriamente. O Python olha para o item e diz: "Se for diferente de 'NULO', vou limpar e converter para inteiro. Caso contrário (else), vou transformar em 0". Como todos os itens geram um resultado (seja o número ou o zero), a lista final termina com exatamente o mesmo tamanho da lista original.

E dá para combinar os dois? (O "Monstro" das Compreensões)

Sim! Você pode usar um if/else no começo para transformar e OUTRO if no final para filtrar.

Imagine que você quer substituir os "NULO" por 0, mas quer deletar completamente o número 50 da lista por algum motivo de negócio:

# if/else no começo (transformação) + if no final (filtro)
[int(v) if v != "NULO" else 0 for v in vendas_brutas if v.strip() != "50"]
# Resultado: [150, 0, 200, 350, 0] -> O 50 sumiu e o NULO virou 0!
Use o código com cuidado.

O Código Prático

Vamos abrir esse arquivo de forma nativa usando o módulo csv do Python e usar a List Comprehension para calcular o faturamento potencial de cada produto (multiplicando a quantidade pelo preço).

Como temos valores "NULO", usaremos o if/else no começo para tratar esse problema e considerar a quantidade como 0 quando estiver zerada.

import csv
# 1. Abrimos o arquivo de forma segura usando o 'with'
with open("vendas.csv", mode="r", encoding="utf-8") as arquivo:
leitor = csv.reader(arquivo)
# 2. Guardamos o cabeçalho e isolamos as linhas com os dados reais
cabecalho = next(leitor)
linhas = list(leitor)
# 3. A MAGIA DA LIST COMPREHENSION:
# Cada 'linha' é uma lista de strings: [produto, quantidade, preco]
# linha[1] é a quantidade, linha[2] é o preço unitário
faturamentos = [
(int(linha[1].strip()) if linha[1].strip() != "NULO" else 0) * int(linha[2].strip())
for linha in linhas
]
print("Faturamento por produto:", faturamentos)
# Resultado esperado: [17500, 0, 1200, 2400, 0]
Use o código com cuidado.

🔍 O que está acontecendo ali dentro?

Para ficar bem fácil de ler, vamos quebrar a expressão em partes:

1. for linha in linhas: O Python passa por cada linha do CSV (ex: ['Mouse', 'NULO', '50']).

2. linha[1].strip(): Remove os espaços em branco da quantidade.

3. if linha[1].strip() != "NULO" else 0: Se for um número válido, faz a conversão para int(). Se for "NULO", o Python assume o valor 0.

4. * int(linha[2].strip()): Multiplica o resultado da quantidade (seja o número real ou o zero) pelo preço unitário convertido para inteiro.

Viu que poderoso? Em vez de criar um laço for gigante com várias condicionais indentadas, você resolveu a leitura, a limpeza, o tratamento de nulos e o cálculo matemático em um único bloco de código super enxuto.

🔍 Por que ficou tão mais simples? As 3 grandes diferenças:

1. Adeus, with open e loops: O pd.read_csv() faz todo o trabalho pesado de abrir, ler e fechar o arquivo por baixo dos panos.

2. Substituição direta (.replace()): Em vez daquele if/else complexo dentro da list comprehension, nós usamos o .replace("NULO", 0). O Pandas vai na coluna inteira e troca o que for texto "NULO" pelo número zero num piscar de olhos.

3. Contas como na planilha (Vetorização): No Python nativo, você precisa multiplicar o item da linha X pelo item da linha Y. No Pandas, você escreve coluna_A * coluna_B e ele multiplica todas as linhas correspondentes de forma automática e extremamente rápida.

A lógica é muito parecida com a forma como filtramos dados no Excel ou no SQL, mas feita com uma sintaxe bem direta. Para filtrar no Pandas, nós usamos uma técnica chamada Indexação Booleana. Parece um nome complicado, mas na prática funciona como uma "pergunta" que você faz para a tabela.

Veja como aplicar isso no código que já tínhamos:

O Código com Filtro

import pandas as pd
# 1. Carrega e trata os dados (igual ao passo anterior)
df = pd.read_csv("vendas.csv")
df["quantidade"] = df["quantidade"].str.strip().replace("NULO", 0).astype(int)
df["preco_unitario"] = df["preco_unitario"].astype(int)
df["faturamento"] = df["quantidade"] * df["preco_unitario"]
# 🎯 A MAGIA DO FILTRO EM UMA LINHA:
# Lemos isso como: "Me traga o df onde o df['faturamento'] seja maior que 0"
df_filtrado = df[df["faturamento"] > 0]
print(df_filtrado)

🧠 Como isso funciona por trás dos panos?

Se você rodar isoladamente apenas a condição dentro dos colchetes, ou seja, df["faturamento"] > 0, o Pandas cria uma série de True ou False para cada linha da sua tabela:

  • Linha 0 (Notebook): True (17500 > 0)
  • Linha 1 (Mouse): False (0 > 0)
  • Linha 2 (Teclado): True (1200 > 0)
  • ...e assim por diante.

Quando você joga essa lista de True/False dentro de df[...], o Pandas entende o recado: "Mantenha apenas as linhas que retornaram True e delete as que retornaram False". É exatamente o conceito do filter() que você aprendeu no Python puro, mas aplicado a uma tabela inteira de uma vez só!

💡 Bônus: E se eu quiser mais de uma condição?

Se você quisesse filtrar produtos com faturamento maior que zero E com preço unitário menor que 2000, bastaria usar o operador & (que significa "E") e isolar as condições entre parênteses:

df_duplo_filtro = df[(df["faturamento"] > 0) & (df["preco_unitario"] < 2000)]

Salvar os dados tratados de volta em um arquivo é o fechamento de ouro do seu processo de tratamento de dados!

O Código Completo (Leitura, Tratamento, Filtro e Exportação)

import pandas as pd
# 1. Carrega os dados
df = pd.read_csv("vendas.csv")
# 2. Trata e limpa os dados
df["quantidade"] = df["quantidade"].str.strip().replace("NULO", 0).astype(int)
df["preco_unitario"] = df["preco_unitario"].astype(int)
df["faturamento"] = df["quantidade"] * df["preco_unitario"]
# 3. Aplica o filtro
df_filtrado = df[df["faturamento"] > 0]
# 🎯 A MAGIA DA EXPORTAÇÃO EM UMA LINHA:
# Salva o resultado em um novo arquivo chamado 'vendas_limpas.csv'
df_filtrado.to_csv("vendas_limpas.csv", index=False, encoding="utf-8")
print("Arquivo salvo com sucesso!")
Use o código com cuidado.

⚠ O detalhe mais importante: O que é esse index=False?

Quando o Pandas cria um DataFrame, ele adiciona automaticamente uma coluna oculta de números à esquerda (0, 1, 2, 3...) para identificar cada linha.

  • Se você salvar usando apenas df_filtrado.to_csv("vendas_limpas.csv"), o Pandas vai colocar esses números dentro do seu novo arquivo CSV como se fossem uma coluna de dados.
  • Ao colocar o argumento index=False, você diz ao Pandas: "Gere o arquivo CSV apenas com as minhas colunas reais (produto, quantidade, preco_unitario, faturamento), sem salvar esses números de índice". Na imensa maioria das vezes, você vai querer usar o index=False.

O parâmetro encoding="utf-8" garante que acentos e caracteres especiais (como o símbolo de "Notebook" ou "Preço") não venham quebrados ou com símbolos estranhos quando você ou outra pessoa abrir o arquivo no Excel.

Hoje, as regras de frete (qual transportadora atende qual região, limites de peso, etc.) provavelmente estão na cabeça dos funcionários ou em tabelas impressas na parede. Isso gera margem para o operador olhar a linha errada e errar a transportadora.

# 1. ENTRADA: O Python abre a sua planilha do Excel diretamente
tabela_envios = pd.read_excel("envios_pendentes.xlsx")

regras_logistica = {

def classificar_pacote(linha):
peso = linha["Peso"]
regiao = linha["Regiao"]
# Estrutura de decisão com as suas faixas reais
if peso <= 10.0:
categoria = "leve"
elif 10.0 < peso <= 30.0:
categoria = "medio"
else:
categoria = "pesado"
# Retorna a transportadora correta combinando Região e Categoria

# 4. SAÍDA: Salva o resultado de volta no Excel, pronto para a expedição
tabela_envios.to_excel("envios_classificados.xlsx", index=False)

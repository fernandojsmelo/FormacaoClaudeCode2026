O que o Supabase faz pelo seu app?

Em vez de aprender códigos complexos, pense no Supabase como um combo de 4 ferramentas prontas que se conectam ao Lovable:

  • O Banco de Dados (A Memória): Sabe quando o usuário digita algo ou cria um post? O banco de dados é a planilha gigante e inteligente onde o app salva isso. É o que faz o app "lembrar" das coisas mesmo se a pessoa fechar ou desligar o celular.
  • O Login (A Portaria): É o sistema que gerencia os usuários. Ele resolve a parte de criar conta, fazer login com e-mail e senha, ou entrar com o Google.
  • O Armazenamento / Storage (O Depósito): Se o seu app precisa que o usuário envie fotos, PDFs ou áudios, o Supabase guarda esses arquivos pesados em um "depósito" seguro.
  • As Funções de Bastidor / Edge Functions (O Garçom): São pequenos scripts que rodam fora do celular do usuário para tarefas específicas (como mandar um e-mail automático ou conectar com um sistema de pagamento).

Traduzindo os termos técnicos

Quando as pessoas da área começarem a falar difícil com você, use este dicionário mental:

Termo TécnicoO que realmente significa no seu app
Back-endTudo o que acontece por trás dos panos (servidores, segurança, banco de dados).
Banco de Dados (PostgreSQL)O arquivo definitivo onde as informações ficam salvas para sempre.
RLS (Row Level Security)Segurança de Linha. É a regra que garante que o Usuário A só consiga ver e mexer nos dados dele, e não nos dados do Usuário B.
Edge FunctionsTarefas automatizadas que acontecem na nuvem (ex: calcular algo ou avisar outro sistema).

Descubra as palavras que mais aparecem em qualquer texto

Word Frequency é uma aplicação web simples que conta, ordena e visualiza a frequência de cada palavra em um bloco de texto — ou no conteúdo de uma página inteira, a partir de uma URL.

Como funciona

Três passos, sem cadastro e sem instalar nada — tudo roda direto no navegador.

1

Cole um texto

Insira até 2048 caracteres na caixa de texto — ou alterne para o modo URL e informe o endereço de uma página para analisar.

2

Clique em "Translate"

O texto é tokenizado: pontuação é removida, acentos e maiúsculas/minúsculas são normalizados antes da contagem.

3

Veja o resultado

Uma tabela ordenada por frequência decrescente aparece, junto de um gráfico com as palavras mais usadas.

Funcionalidades

Do essencial ao bônus — cada fase do projeto adicionou uma camada de funcionalidade.

Contagem de frequência

Tokenização precisa que ignora pontuação, espaços múltiplos e diferenças de maiúsculas/minúsculas.

Ordenação automática

A tabela é sempre exibida em ordem decrescente de ocorrências, sem esforço do usuário.

Validações claras

Mensagens de erro para input vazio e contador de caracteres com aviso ao se aproximar do limite.

Gráfico interativo Bônus

Visualização das palavras mais frequentes com Chart.js, adaptada ao tema claro/escuro da página.

Análise via URL Bônus

Cole o link de uma página e o backend extrai e analisa o texto do artigo automaticamente.

Feedback do usuário

Formulário integrado para enviar comentários sobre a experiência de uso da aplicação.

Stack técnica

Construído com o essencial — sem frameworks nas fases principais.

HTML CSS JavaScript vanilla Chart.js Node.js Express Cheerio

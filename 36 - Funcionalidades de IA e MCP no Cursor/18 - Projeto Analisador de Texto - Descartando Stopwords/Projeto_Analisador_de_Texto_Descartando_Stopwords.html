Conceito01

O que são stopwords

Stopwords são palavras muito frequentes que quase não carregam significado sozinhas: artigos, preposições, conjunções, pronomes e verbos auxiliares.

o · a · os · asde · do · da · em · noe · ou · masque · se · com · paraele · ela · seué · foi · ser · tem
No texto de exemplo, as stopwords somam 106 das 247 palavras: quase metade. Por isso dominavam a nuvem.
Não existe lista oficial

Cada biblioteca tem a sua, e cada projeto ajusta. "Não", por exemplo: num analisador de opiniões, "não gostei" muda tudo, então "não" não deve sair. O código de referência mantém "não" fora da lista.

Tirar stopwords serve para descobrir o assunto (nuvem, frequência). As métricas gerais (total de palavras, frases, tempo de leitura) continuam contando tudo.

analise.py
def carregar_stopwords(caminho=Path(__file__).with_name("stopwords_pt.txt")):
    """Lê o arquivo de stopwords (uma por linha; # é comentário)."""
    linhas = Path(caminho).read_text(encoding="utf-8").splitlines()
    return {l.strip().lower() for l in linhas if l.strip() and not l.startswith("#")}


def sem_stopwords(lista, stopwords):
    return [p for p in lista if p not in stopwords]
  • A lista vira um set: procurar num conjunto é instantâneo, mesmo com milhares de palavras
  • .lower() e .strip() evitam erro por maiúscula ou espaço
  • sem_stopwords é só um filtro: fácil de testar
Código04

A barra lateral e o filtro

with st.sidebar:
    st.header("Stopwords")
    remover = st.toggle("Remover stopwords", value=True)
    extras = st.text_input("Outras palavras para ignorar", placeholder="separadas por vírgula")
    stopwords = carregar_stopwords() | {p.strip().lower() for p in extras.split(",") if p.strip()}
    st.caption(f"{len(stopwords)} palavras na lista (arquivo stopwords_pt.txt + as suas).")

todas = palavras(texto)
if not todas:
    st.warning("O texto não tem palavras para analisar (só números ou símbolos).")
    st.stop()
lista = sem_stopwords(todas, stopwords) if remover else todas
dados = estatisticas(texto)
c1, c2, c3, c4, c5 = st.columns(5)
c1.metric("Palavras", dados["palavras"])
c2.metric("Únicas", dados["palavras_unicas"])
c3.metric("Frases", dados["frases"])
c4.metric("Caracteres", dados["caracteres"])
c5.metric("Leitura", f"{dados['minutos_leitura']} min")

if remover:
    st.caption(f"{len(todas) - len(lista)} ocorrências de stopwords ignoradas na nuvem e na frequência.")

if not lista:
    st.warning("Não sobrou nenhuma palavra depois de remover as stopwords.")
    st.stop()
  • | une a lista do arquivo com as palavras extras
  • todas e lista: a diferença é o que foi ignorado
  • As métricas usam o texto inteiro; a nuvem e a frequência usam lista
  • Texto sem letras, ou só com stopwords: um aviso e st.stop(), em vez de uma nuvem vazia (que daria erro na WordCloud)
O resto do app.py (abas, nuvem, download) é o da aula 17, recebendo a lista já filtrada.

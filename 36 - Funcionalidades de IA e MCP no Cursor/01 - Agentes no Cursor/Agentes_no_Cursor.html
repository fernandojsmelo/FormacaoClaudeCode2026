Agentes
no Cursor

O Agent é o assistente do Cursor que conclui tarefas de programação por conta própria: lê e busca no projeto, edita vários arquivos, roda comandos no terminal e confere o resultado. Nesta aula: do que ele é feito, que ferramentas usa, os quatro modos, como acompanhar, corrigir o rumo e desfazer o que ele fez.

Conceito01

O que é o Agent

Você descreve a tarefa em linguagem natural e o Agent decide quais arquivos ler, que mudanças fazer e como verificar o resultado. As edições aparecem na tela enquanto ele trabalha.

Como abrir

Painel lateral com Ctrl + I (Windows e Linux) ou Cmd + I (macOS). Também dá para rodar agentes pelo navegador em cursor.com/agents, com os Cloud Agents.

O que ele consegue fazer
  • Criar uma funcionalidade do zero
  • Refatorar código existente
  • Corrigir bugs a partir de um erro ou sintoma
  • Escrever testes e rodá-los
  • Executar comandos no terminal e ler a saída
Para um trabalho maior, como uma migração, o Cursor tem os Projects: um agente coordenador planeja e distribui partes do trabalho para outros agentes.
Anatomia02

Três peças fazem um agente

1 · Instruções

O system prompt do Cursor e as suas rules (do projeto, do usuário e do time). Dizem como o agente deve se comportar.

2 · Ferramentas

Editar arquivos, buscar no código, rodar o terminal, usar o navegador e outras. São as "mãos" do agente.

3 · Modelo

O modelo que você escolhe para a tarefa (ou Auto). É quem decide o próximo passo.

PedidoVocê descreve a tarefa
DecideO modelo escolhe a próxima ferramenta
ExecutaO Cursor roda a ferramenta
ObservaO resultado volta para o modelo
RepeteAté concluir e verificar
O Cursor ajusta instruções e ferramentas para cada modelo suportado. Quando sai um modelo novo, você só escolhe; a adaptação fica por conta do Cursor. Não há limite de chamadas de ferramenta numa tarefa.

Modos05

Quatro modos, quatro jeitos de trabalhar

ModoMelhor paraEdita arquivos?
AgentCriar funcionalidades, refatorar, corrigir bugs: a maioria das tarefasSim
AskEntender o código e a arquitetura (aula 03)Não, só leitura
PlanFuncionalidades complexas, quando você quer revisar a abordagem antesSim, depois que você aprova o plano
DebugBugs difíceis de reproduzir, que precisam de evidência em execuçãoSim
Trocar de modo: Shift + Tab alterna entre eles, ou use o seletor no campo do chat.
Cada modo usa o próprio contexto: trocar de modo começa uma janela de contexto nova. As rules valem em todos os modos.
Na prática06

Dando uma tarefa ao Agent

1
Abra o painel com Ctrl + I e confira o modo (Agent) e o modelo.
2
Seja específico sobre o resultado: o que mudar, onde e como saber que deu certo.
3
Envie com Enter. O agente explora o projeto e começa a editar.
4
Acompanhe as edições no diff, enquanto acontecem.
5
Revise o que ficou e rejeite o que não quiser.
Vago
Melhora o login.
Específico
Adicione um formulário de login na página inicial com campos de e-mail e senha. Valide o e-mail antes de enviar e mostre uma mensagem de erro amigável. Rode os testes no fim.
Se souber quais arquivos importam, cite com @ (por exemplo, @LoginForm.tsx). Se não souber, deixe o agente buscar.
Controle07

Revisar e desfazer

Diff

As edições são aplicadas enquanto o agente trabalha. No diff, você vê cada mudança e pode rejeitar o que não quiser.

Checkpoints

Antes de mudanças importantes, o agente salva um checkpoint dos arquivos. Clique num checkpoint da linha do tempo para ver como estavam e restaure tudo àquele ponto. Ou passe o mouse numa mensagem anterior e use Restore Checkpoint.

  • Restaurar volta só os arquivos; as mensagens continuam na conversa
  • Para encurtar a conversa, faça um fork a partir de uma mensagem anterior
  • Checkpoints ficam na sua máquina, separados do Git
Checkpoint serve para desfazer o que o agente fez. Para histórico permanente, use Git: faça commits nos pontos bons.
O botão Stop interrompe o agente no meio da tarefa, para você corrigir o rumo ou tentar outra abordagem.

Você querComoO que acontece

Além do básico10

Subagentes e revisão de código

Subagentes

O Agent pode criar subagentes para pesquisa, comandos ou navegador, em paralelo. Cada um tem a própria janela de contexto e devolve só o resultado. Os embutidos são Explore, Bash e Browser; você pode criar os seus com arquivos markdown em .cursor/agents/.

Use um subagente para achar todos os lugares onde validamos entrada do usuário.
Agent Review

Uma revisão de código dedicada às suas mudanças locais: digite /agent-review, rode pela aba Source Control (compara tudo com a branch principal) ou deixe automática após cada commit. Lê regras de arquivos BUGBOT.md.

QuickRápidaBaixoMudanças pequenas, checagem rápida

Exercício11

Sua primeira tarefa com o Agent

1
Crie uma pasta vazia, abra no Cursor e faça um git init (para ter um ponto de volta).
2
Peça ao Agent: "Crie uma página HTML com um contador de cliques e um botão para zerar".
3
Enquanto ele trabalha, coloque na fila: "Depois, deixe o botão maior e centralizado".
4
Rejeite uma das edições no diff e veja o arquivo voltar.
5
Restaure o primeiro checkpoint e compare com o estado final.
O objetivo não é o contador, e sim sentir o ciclo: pedir, acompanhar, corrigir e desfazer.
Troque para Ask com Shift + Tab e pergunte "como esse contador funciona?": repare que, nesse modo, nada é editado.
Quiz de fixação12

Teste o que ficou

1. Quais são as três peças de um agente no Cursor?

A) Editor, terminal e Git
B) Instruções, ferramentas e modelo
C) Chat, Tab e Ctrl+K
D) Rules, skills e hooks
B. O modelo decide, as ferramentas agem e as instruções orientam.

2. O que acontece ao restaurar um checkpoint?

A) Apaga a conversa
B) Os arquivos voltam; as mensagens ficam
C) Faz um commit no Git
D) Troca o modelo
B. Para encurtar a conversa, use um fork.

3. Qual modo responde sem editar nada?

A) Agent
B) Plan
C) Ask
D) Debug
C. Ask é só leitura.

4. Com o agente trabalhando, você tecla Enter numa mensagem nova. O que acontece?

A) A tarefa é cancelada
B) A mensagem vai para a fila
C) A mensagem é descartada
D) Abre um side chat
B. Para mandar já, use Ctrl + Enter.
Encerramento · Funcionalidades de IA e MCP no Cursor

Você pede,
o agente executa

O Agent junta instruções, ferramentas e um modelo para concluir tarefas: busca, edita, roda comandos e verifica. Escolha o modo certo (Agent, Ask, Plan ou Debug), acompanhe pelo diff, corrija o rumo com a fila e o Ctrl + Enter, e desfaça com checkpoints, sem esquecer do Git e dos Run Modes.

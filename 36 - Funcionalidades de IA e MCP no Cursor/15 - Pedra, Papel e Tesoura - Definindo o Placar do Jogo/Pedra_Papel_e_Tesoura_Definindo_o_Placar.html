Dados novos

Dois itens na sessão: o placar, um dicionário com três contadores, e o histórico, uma lista de rodadas com a mais recente primeiro.

placar = {"vitoria": 4, "derrota": 2, "empate": 1}
historico = [("Pedra", "Tesoura", "vitoria"), ...]
As chaves do placar são as mesmas palavras que resultado() devolve. Somar um ponto vira uma linha: placar[final] += 1.

O pedido da versão 3

Adicione um placar ao jogo: - st.session_state.placar com vitorias, derrotas e empates, usando as mesmas palavras que resultado() devolve; - mostre no topo, com st.metric: Você, Computador, Empates e Rodadas; - guarde as rodadas num histórico e mostre as 5 últimas dentro de um st.expander; - botão "Zerar placar" que limpa placar e histórico. O placar precisa mostrar o valor certo logo depois de cada jogada. Não mude o jogo.py.
"Logo depois de cada jogada" parece óbvio, mas é exatamente onde a primeira versão costuma errar. Dizer isso no pedido vira critério de teste (seção 05).
Peça ao agente para explicar a ordem em que o script desenha placar, botões e rodada. Entender a ordem é entender o Streamlit.
Código03

Placar no topo

MENSAGEM = {"vitoria": "Você venceu! 🎉", "derrota": "O computador venceu.", "empate": "Empate!"}

if "placar" not in st.session_state:
    st.session_state.placar = {"vitoria": 0, "derrota": 0, "empate": 0}
    st.session_state.historico = []  # rodadas mais recentes primeiro

placar = st.session_state.placar

# Placar no topo
c1, c2, c3, c4 = st.columns(4)
c1.metric("Você", placar["vitoria"])
c2.metric("Computador", placar["derrota"])
c3.metric("Empates", placar["empate"])
c4.metric("Rodadas", sum(placar.values()))

colunas = st.columns(3)
for coluna, opcao in zip(colunas, OPCOES):
    coluna.image(str(IMAGEM[opcao]), width="stretch")
    if coluna.button(opcao, key=f"jogar_{opcao}", width="stretch"):
        computador = jogada_do_computador()
        final = resultado(opcao, computador)
        placar[final] += 1
        st.session_state.historico.insert(0, (opcao, computador, final))
        st.rerun()
  • O placar é criado uma vez, na primeira execução
  • st.metric mostra cada número com rótulo
  • Rodadas = soma dos três contadores
  • No clique: sorteia, decide, soma o ponto, guarda no histórico
  • insert(0, …) põe a rodada nova no começo da lista
Repare no st.rerun() no fim do clique. A próxima seção mostra o que acontece sem ele.
Armadilha04

O placar que atrasa uma rodada

O Streamlit roda o script de cima para baixo a cada clique. O placar é desenhado antes dos botões:

1
Você clica em Pedra. O script recomeça.
2
Desenha o placar com os valores antigos.
3
Chega no botão, vê o clique e soma o ponto. Mas o placar já foi desenhado.
4
Sem st.rerun(), a tela mostra o placar uma rodada atrasado.
Duas soluções

A) Depois de mudar o placar, chamar st.rerun(): o script roda de novo, e agora o placar já começa com o valor novo. É a do código de referência.

B) Usar on_click no botão: a função roda antes do script, então o placar já é desenhado atualizado.

Se o agente entregar sem nenhuma das duas, o teste da seção 05 pega. Descreva o sintoma ("o placar só atualiza no clique seguinte") e peça para explicar a causa.
Testes05

Testando o placar

def test_placar():
    at = AppTest.from_file("app.py").run()
    for computador in ["Tesoura", "Papel", "Pedra", "Tesoura"]:
        with mock.patch("random.choice", return_value=computador):
            at.button(key="jogar_Pedra").click().run()
    assert at.session_state.placar == {
        "vitoria": 2, "derrota": 1, "empate": 1}
    # o que aparece na tela, logo após a última jogada
    assert [m.value for m in at.metric] == ["2", "1", "1", "4"]
O código de referência passou: Pedra contra Tesoura, Papel, Pedra e Tesoura dá 2 vitórias, 1 derrota e 1 empate, e o placar na tela mostra 2 · 1 · 1 · 4 logo depois da última jogada.
  • Confere o estado (session_state) e a tela (st.metric)
  • A segunda conferência é a que pega o "atraso de uma rodada"
  • Um teste a mais: Zerar placar volta tudo a zero e esconde o histórico
Testar só o estado não basta: ele estava certo também na versão com o atraso. O usuário vê a tela.
Código06

Histórico e zerar

historico = st.session_state.historico
if historico:
    jogador, computador, final = historico[0]
    st.divider()
    lado_a, meio, lado_b = st.columns([2, 1, 2], vertical_alignment="center")
    lado_a.image(str(IMAGEM[jogador]), caption=f"Você: {jogador}", width=160)
    meio.markdown("<h2 style='text-align:center'>×</h2>", unsafe_allow_html=True)
    lado_b.image(str(IMAGEM[computador]), caption=f"Computador: {computador}", width=160)
    {"vitoria": st.success, "derrota": st.error, "empate": st.info}[final](MENSAGEM[final])

    with st.expander("Últimas rodadas"):
        for jogador, computador, final in historico[:5]:
            st.write(f"{jogador} × {computador} → {MENSAGEM[final]}")

    if st.button("Zerar placar"):
        del st.session_state.placar
        del st.session_state.historico
        st.rerun()
  • A rodada mostrada é sempre historico[0], a mais recente
  • O dicionário escolhe a função de mensagem: st.success, st.error ou st.info
  • st.expander esconde o histórico até você abrir
  • Zerar apaga as duas chaves; na próxima execução, o placar é recriado com zeros

Por que Python + Streamlit

O Streamlit transforma um script Python num app web, sem HTML, CSS ou JavaScript. Um arquivo só já tem tela, campos e botões, e roda no navegador em localhost. É ótimo para ver o agente trabalhar sem se perder em configuração.

O que você vai praticar

Ask para entender, Plan para revisar a abordagem, Agent para construir, rules para padronizar, Browser para testar (aula 09) e checkpoints e Git para voltar atrás (aula 01).

Prefere outra tecnologia (HTML/JS, React, Flask)? O processo desta aula é o mesmo; só troque a stack no prompt e na rule.

  sem perguntar.

Por que uma rule

Ela entra em todas as conversas do projeto, em qualquer modo. Assim você não repete "em português", "sem bibliotecas novas" a cada pedido, e as aulas 11 e 12 seguem o mesmo padrão.

Com alwaysApply: true, a rule vale sempre. Rules com globs valem só para certos arquivos (módulo 35).
Também dá para pedir ao agente: "crie uma rule do projeto com estes padrões".
Plan05

Primeiro o plano

Mude para o modo Plan (Shift + Tab) e peça a abordagem antes do código. Você revisa e só depois o agente edita.

Planeje a primeira versão de um app de lista de tarefas em Streamlit, num arquivo app.py. Funcionalidades: adicionar tarefa (campo + botão), listar as tarefas com um botão Remover em cada uma, avisar se a tarefa estiver vazia, mostrar uma mensagem quando não houver tarefas e um contador. Sem banco de dados: as tarefas ficam em st.session_state. Não escreva código ainda.
O que conferir no plano
  • Usa st.session_state para guardar a lista
  • Usa um formulário que limpa o campo depois de adicionar
  • Remover usa uma chave única por botão
  • Não inventou banco, login nem bibliotecas extras
  • Cria requirements.txt
Discorda de algo? Responda no chat e peça um plano ajustado. Quando estiver bom, aprove e deixe o agente executar.
Construção06

O prompt de construção

Se preferir ir direto no modo Agent, um prompt completo faz o mesmo papel. Ele diz o que construir, o que não fazer e como verificar:

Crie a primeira versão de um app de lista de tarefas em Streamlit, no arquivo app.py: - título "Minhas tarefas"; - formulário com o campo "Nova tarefa" e o botão "Adicionar", que limpa o campo ao enviar; - avise com st.warning se a tarefa for vazia; - liste as tarefas, cada uma com um botão "Remover", e mostre quantas são; - sem tarefas, mostre uma mensagem com st.info. Resultado07

O código da versão 1

import streamlit as st

st.set_page_config(page_title="ToDo List", page_icon="✅")
st.title("✅ Minhas tarefas")

# A lista vive na sessão do navegador: some ao recarregar
# a página (v1, sem banco).
if "tarefas" not in st.session_state:
    st.session_state.tarefas = []

with st.form("nova_tarefa", clear_on_submit=True):
    col_texto, col_botao = st.columns([4, 1], vertical_alignment="bottom")
    texto = col_texto.text_input("Nova tarefa",
                                 placeholder="O que você precisa fazer?")
    adicionar = col_botao.form_submit_button("Adicionar",
                                             width="stretch")

if adicionar:
    texto = texto.strip()
    if not texto:
        st.warning("Digite uma tarefa antes de adicionar.")
    else:
        st.session_state.tarefas.append(texto)

if not st.session_state.tarefas:
    st.info("Nenhuma tarefa ainda. Adicione a primeira acima.")
else:
    st.caption(f"{len(st.session_state.tarefas)} tarefa(s)")
    for i, tarefa in enumerate(st.session_state.tarefas):
        col_tarefa, col_remover = st.columns([5, 1],
                                             vertical_alignment="center")
        col_tarefa.write(tarefa)
        if col_remover.button("Remover", key=f"remover_{i}"):
            st.session_state.tarefas.pop(i)
            st.rerun()
Como ler
  • session_state: o Streamlit roda o script de novo a cada clique; o session_state guarda a lista entre essas execuções
  • form + clear_on_submit: envia o campo e o limpa em seguida
  • strip(): trata " " como vazio
  • key única: cada botão Remover precisa de uma chave própria
  • st.rerun(): redesenha a lista logo após remover
Código de referência na pasta da aula: projeto/app.py e projeto/requirements.txt. O do seu agente pode sair diferente, e tudo bem, desde que cumpra o escopo.
Rodar08

Rodando o app

Terminal do Cursor (com a .venv ativada)
streamlit run app.py

  You can now view your Streamlit app in your browser.
  Local URL: http://localhost:8501
  • A porta padrão do Streamlit é a 8501
  • Ao salvar app.py, a página oferece Rerun para atualizar
  • Ctrl + C no terminal para parar o servidor
Deixe o agente rodar

Se você pediu "rode o app", o agente executa o comando no terminal (com aprovação) e devolve a URL. Ele também percebe quando o servidor já está rodando e reaproveita a porta em vez de abrir outro.

"streamlit: command not found": a .venv não está ativada no terminal, ou o Streamlit não foi instalado nela. Ative e rode pip install -r requirements.txt.

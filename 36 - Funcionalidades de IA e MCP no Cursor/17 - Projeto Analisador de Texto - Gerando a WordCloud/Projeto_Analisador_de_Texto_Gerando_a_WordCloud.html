Código03

A função da nuvem

def nuvem_de_palavras(frequencias, largura=900, altura=450, cor="viridis", maximo=100):
    """Gera a nuvem (imagem PIL) a partir de um dicionário {palavra: vezes}."""
    from wordcloud import WordCloud

    nuvem = WordCloud(
        width=largura,
        height=altura,
        background_color="white",
        colormap=cor,
        max_words=maximo,
        stopwords=set(),  # a v2 ainda não remove palavras: isso vem na próxima aula
        collocations=False,
    )
    return nuvem.generate_from_frequencies(frequencias).to_image()
  • generate_from_frequencies usa a contagem pronta (do Counter)
  • colormap: o nome de uma paleta do Matplotlib
  • max_words: quantas palavras cabem na nuvem
  • collocations=False: não junta pares de palavras ("agente usa")
  • stopwords=set(): nenhuma palavra descartada, de propósito
  • .to_image() devolve a imagem PIL
A WordCloud tem uma lista de stopwords em inglês embutida, usada quando você gera a partir do texto bruto (generate()). Ela não serve para português. Por isso o projeto conta as palavras antes e passa as frequências.

Abas, cores e download

if not lista:
    st.warning("O texto não tem palavras para analisar (só números ou símbolos).")
    st.stop()

aba_nuvem, aba_frequencia = st.tabs(["☁️ Nuvem de palavras", "📊 Frequência"])

with aba_nuvem:
    col_cor, col_max = st.columns(2)
    cor = col_cor.selectbox("Paleta de cores", ["viridis", "plasma", "inferno", "cividis", "Dark2", "tab10"])
    maximo = col_max.slider("Máximo de palavras na nuvem", 20, 200, 100, step=10)
    imagem = nuvem_de_palavras(Counter(lista), cor=cor, maximo=maximo)
    st.image(imagem, width="stretch")

    buffer = BytesIO()
    imagem.save(buffer, format="PNG")
    st.download_button("Baixar a nuvem (PNG)", buffer.getvalue(), "nuvem.png", "image/png")

with aba_frequencia:
    quantidade = st.slider("Quantas palavras mostrar", 5, 30, 10)
    tabela = pd.DataFrame(mais_frequentes(lista, quantidade), columns=["Palavra", "Vezes"])
  • st.tabs organiza a tela sem rolar a página
  • st.image(imagem) aceita a imagem PIL direto
  • O PNG é gravado num BytesIO (memória), sem criar arquivo no disco
  • st.download_button entrega os bytes com nome e tipo

O que a nuvem está dizendo

As maiores palavras são "o", "e", "um", "de". Elas aparecem em qualquer texto em português, sobre qualquer assunto.

  • O assunto real ("agente", "código", "pedido") fica em segundo plano

Problemas comuns08

Quando não instala ou não desenha

pip falha no Windows

Atualize o pip (python -m pip install --upgrade pip). Versões recentes da wordcloud têm pacotes prontos para Windows, sem compilar.

ModuleNotFoundError

A .venv não está ativada, ou a instalação foi em outro Python. Ative e rode pip install -r requirements.txt.

Paleta inválida

O nome precisa existir no Matplotlib (viridis, plasma, Dark2…). A lista do app evita digitar errado.

Nuvem vazia

Texto sem letras (só números) derruba a WordCloud com ValueError: We need at least 1 word. O código de referência avisa e para com st.stop() antes de gerar.

App lento

Textos grandes e nuvens de 200 palavras demoram. Peça ao agente para usar st.cache_data na geração.

Acentos estranhos

A fonte padrão da wordcloud tem acentos do português. Se usar outra fonte, confira se ela tem os caracteres.

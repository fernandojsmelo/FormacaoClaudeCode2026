Conceito01

Perguntando ao usuário

saudacao.py
nome = input("Qual é o seu nome? ")
print("Olá,", nome)
Saída (o usuário digitou "Ana")
Qual é o seu nome? Ana
Olá, Ana
1
input() mostra a pergunta (o texto entre parênteses)
2
O programa para e espera o usuário digitar e teclar Enter
3
O que foi digitado vira o valor do input(), guardado na variável
Deixe um espaço no fim da pergunta ("nome? "). Sem ele, o que a pessoa digita fica grudado no texto.
Atenção02

input() sempre devolve texto

input_e_texto.py
idade = input("Sua idade: ")
print(type(idade))       # input() SEMPRE devolve str
print(idade + idade)     # junta textos, não soma!
Saída (digitou 29)
Sua idade: 29
<class 'str'>
2929
Mesmo que o usuário digite 29, o valor é o texto "29". E "29" + "29" junta os textos: "2929".
  • Para fazer contas, converta: int() ou float()
  • Para usar como texto (nome, cidade), não precisa converter
  • Na dúvida, print(type(valor))
Conversão03

Convertendo na hora

converter.py
idade = int(input("Sua idade: "))
altura = float(input("Sua altura em metros: "))
print("Daqui a 10 anos você terá", idade + 10, "anos.")
print("Altura em centímetros:", altura * 100)
Saída (digitou 29 e 1.68)
Sua idade: 29
Sua altura em metros: 1.68
Daqui a 10 anos você terá 39 anos.
Altura em centímetros: 168.0
  • int(input(...)): pergunta e converte numa linha só
  • O Python executa de dentro para fora: primeiro o input(), depois o int()
  • Use int para idades, quantidades; float para medidas e preços
1.68 * 100 deu 168.0: o resultado de uma conta com float é float (aula 03).

Limpeza05

Espaços e vírgula decimal

strip_ex.py · digitou " Recife "
cidade = input("Cidade: ").strip()  # tira espaços das pontas
print(f"[{cidade}]")
Cidade:    Recife   
[Recife]
Os colchetes no print mostram que os espaços sumiram.
virgula.py · digitou "12,50"
preco = input("Preço (use vírgula se quiser): ")
preco = float(preco.replace(",", "."))  # aceita 12,50 e 12.50
print("Com 10% de desconto:", round(preco * 0.9, 2))
Preço (use vírgula se quiser): 12,50
Com 10% de desconto: 11.25
O Python usa ponto como separador decimal. float("12,50") dá ValueError; trocar a vírgula por ponto antes resolve.
Boas práticas06

Perguntas bem feitas

  • Pergunta clara, com a unidade: "Peso (kg): "
  • Espaço no fim da pergunta
  • .strip() em todo texto digitado
  • Converta logo na entrada e guarde já como número
  • Aceite vírgula em números decimais, se o público é brasileiro
  • Mostre o resultado com contexto: "Seu IMC é 22.9", não só "22.9"

Exercício08

Calculadora de IMC

Enunciado: pergunte nome, peso e altura (aceitando vírgula) e mostre o IMC com uma casa decimal. Fórmula: peso dividido pela altura ao quadrado.

Uma resposta possível
# Exercício: calculadora de IMC
nome = input("Nome: ").strip()
peso = float(input("Peso (kg): ").replace(",", "."))
altura = float(input("Altura (m): ").replace(",", "."))
imc = peso / altura ** 2
print(f"{nome}, seu IMC é {imc:.1f}")
Saída (digitou Bruno, 72,5 e 1,78)
Nome: Bruno
Peso (kg): 72,5
Altura (m): 1,78
Bruno, seu IMC é 22.9
  • altura ** 2: potência (aula 06)
  • {imc:.1f}: uma casa decimal (aula 05)
  • Desafio: mostre também o peso ideal mínimo, com IMC 18,5

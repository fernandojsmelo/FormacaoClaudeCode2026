Conceito01

O que é um programa

Um programa é uma lista de instruções que o computador executa de cima para baixo, uma linha de cada vez. Em Python, essas instruções ficam num arquivo de texto com a extensão .py.

Você escreveola.py
O Python lêo interpretador executa linha a linha
Resultadoaparece no terminal
Interpretador

O Python que você instalou é um programa que lê o seu arquivo e executa cada instrução. Por isso se diz que Python é uma linguagem interpretada: não há um passo separado de compilação para você rodar.

Ainda não instalou? A instalação está no capítulo 2 do Guia Completo Python (aula 01) e no módulo 35 (Cursor). Confira com python3 --version (no Windows: py --version).

Sequência04

De cima para baixo

apresentacao.py
# Um programa: instruções executadas de cima para baixo
print("Olá! Eu sou um programa em Python.")
print("Estou aprendendo a programar.")
print()  # print vazio pula uma linha
print("Fim.")
Saída
Olá! Eu sou um programa em Python.
Estou aprendendo a programar.

Fim.
  • Cada print() termina com uma quebra de linha
  • print() vazio imprime uma linha em branco
  • A ordem da saída é a ordem do código
print()05

Vários valores, sep e end

print_varios.py
# Vários valores no mesmo print: o Python separa com espaço
print("Nome:", "Ana", "| Idade:", 29)

# sep: o que vai entre os valores
# end: o que vai no final (padrão: quebra de linha)
print("2026", "10", "05", sep="-")
print("Carregando", end="...")
print(" pronto!")

# Números e contas também podem ser impressos
print(2 + 3)
print("2 + 3")
Saída
Nome: Ana | Idade: 29
2026-10-05
Carregando... pronto!
5
2 + 3
ParâmetroPadrãoMuda
sepum espaçoO que vai entre os valores
endquebra de linhaO que vai no final
Repare: print(2 + 3) mostra 5; print("2 + 3") mostra o texto. Aspas fazem toda a diferença.
Comentários06

Notas para quem lê

comentarios.py
# Linha inteira de comentário: o Python ignora

print("Isto roda")  # comentário no fim da linha

# print("Isto NÃO roda: a linha está comentada")

"""
Texto entre três aspas no começo do arquivo
costuma servir de documentação (docstring).
"""
Saída
Isto roda
  • # comenta do símbolo até o fim da linha
  • Comentário explica o porquê; o código já diz o quê
  • Comentar uma linha é um jeito rápido de "desligá-la" para testar
  • No Cursor, Ctrl + / comenta e descomenta a linha (Cmd + / no macOS)
O texto entre """ não é comentário de verdade: é uma string que o Python ignora por não ser usada. No início de arquivos e funções, ela vira documentação (docstring).
Modo interativo07

Testando linha a linha: o REPL

Digite python3 (ou py no Windows) sem nome de arquivo e o Python abre o modo interativo, o REPL: você digita uma linha, ele executa e mostra o resultado na hora.

$ python3
>>> 2 + 3
5
>>> print("Olá!")
Olá!
>>> "Python" * 2
'PythonPython'
>>> exit()
  • Ótimo para experimentar uma ideia rápida
  • No REPL, o valor aparece sem print(); num arquivo, não
  • Sair: exit() ou Ctrl + D (Linux/macOS), Ctrl + Z e Enter (Windows)
  • O que você digita no REPL se perde ao sair: programas de verdade vão para arquivos
Desde o Python 3.13, o REPL tem cores, edição de várias linhas e histórico melhor (capítulo 21 do guia).

Os primeiros erros

erro_nome.py · Print com P maiúsculo
Print("Olá, mundo!")
Traceback (most recent call last):
  File "erro_nome.py", line 1, in <module>
    Print("Olá, mundo!")
    ^^^^^
NameError: name 'Print' is not defined. Did you mean: 'print'?
Python diferencia maiúsculas de minúsculas: print existe, Print não. E repare na sugestão do próprio Python: Did you mean: 'print'?
Erros09

Lendo uma mensagem de erro

erro_recuo.py · espaço no começo da linha
print("primeira linha")
    print("segunda linha")
  File "erro_recuo.py", line 2
    print("segunda linha")
IndentationError: unexpected indent
Em Python, o recuo (espaços no começo da linha) tem significado: ele marca blocos de código. Fora de um bloco, a linha começa na coluna 1.
Parte da mensagemO que diz
File "...", line 2Arquivo e linha onde o Python percebeu o problema
A linha de códigoO trecho exato
^^^^Aponta a parte problemática
Última linhaTipo do erro e explicação: comece por ela
Ler a última linha primeiro resolve a maioria dos erros de iniciante: ela diz o que aconteceu; o resto diz onde.
Com o agente10

Aprendendo com o Cursor

Modo Ask · explicar sem resolver
Estou aprendendo Python. Rodei @erro_nome.py e apareceu NameError. Explique o que essa mensagem quer dizer, em linguagem simples, e me dê uma dica. NÃO corrija o arquivo: quero tentar sozinho.
Depois de corrigir
Corrigi o arquivo. Está certo? Tem algum outro detalhe que um iniciante costuma errar aqui?
  • Use o modo Ask (aula 03 do módulo 36): ele explica e não edita
  • Peça dica, não a resposta: quem aprende é quem digita
  • Cole o erro com @Terminals ou selecione o texto no terminal
  • Desconfie da resposta e rode de novo: o terminal é o juiz final
Pedir para o agente fazer todos os exercícios é o jeito mais rápido de não aprender. Use-o como professor particular, não como colega que faz a prova.
Exercício11

Seu cartão de visita

Enunciado: crie cartao.py que imprima seu nome, sua profissão, e-mail e telefone na mesma linha separados por " | " (use sep) e, no fim, uma linha com 30 sinais de igual.

Uma resposta possível
# Exercício 1: cartão de visita
print("Ana Souza")
print("Desenvolvedora Python")
print("ana@exemplo.com", "(81) 99999-0000", sep=" | ")
print("=" * 30)
Saída
Ana Souza
Desenvolvedora Python
ana@exemplo.com | (81) 99999-0000
==============================
  • "=" * 30 repete o texto 30 vezes (mais na aula 05)
  • Tente antes de olhar a resposta
  • Desafio: imprima o cartão dentro de uma "moldura" de asteriscos

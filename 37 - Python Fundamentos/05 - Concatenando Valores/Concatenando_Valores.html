Operador +01

Juntando textos com +

mais.py
nome = "Ana"
sobrenome = "Souza"
print(nome + sobrenome)         # sem espaço
print(nome + " " + sobrenome)   # com espaço
print("-" * 20)                 # repetir texto
Saída
AnaSouza
Ana Souza
--------------------
  • + entre textos concatena: cola um no fim do outro
  • O + não põe espaço sozinho: inclua " "
  • * com um número repete o texto: ótimo para linhas e separadores
O mesmo símbolo faz coisas diferentes conforme o tipo: 2 + 3 soma, "2" + "3" junta ("23"). Por isso o tipo importa tanto (aula 03).

f-strings03

f-strings: o jeito moderno

fstring.py
nome = "Ana"
idade = 29
preco = 49.9
print(f"{nome} tem {idade} anos.")
print(f"Ano que vem: {idade + 1}")
print(f"Preço: R$ {preco:.2f}")
print(f"{nome=}, {idade=}")   # nome e valor (bom para depurar)
Saída
Ana tem 29 anos.
Ano que vem: 30
Preço: R$ 49.90
nome='Ana', idade=29
  • Um f antes das aspas, e as variáveis entre { }
  • Converte sozinho: número entra na frase sem str()
  • Aceita contas dentro das chaves: {idade + 1}
  • {nome=} mostra o nome da variável e o valor: ótimo para depurar
O guia da aula 01 recomenda: sempre use f-strings. São as mais legíveis e as mais rápidas.
Formatação04

Casas decimais e alinhamento

Dentro das chavesResultadoPara
{49.9:.2f}49.902 casas decimais
{0.257:.1%}25.7%Porcentagem
{1234567:,}1,234,567Separador de milhar
{"oi":>6}" oi"Alinhar à direita
{"oi":<6}"oi "Alinhar à esquerda
{"oi":^6}" oi "Centralizar
{7:03}007Zeros à esquerda
A regra é {valor:formato}. Os dois-pontos separam o que mostrar de como mostrar. O mesmo formato funciona no .format().
O separador de milhar do Python é a vírgula e o decimal é o ponto, no padrão americano. Para "1.234,56" no padrão brasileiro, troque os caracteres depois de formatar, ou use o módulo locale.
valor = f"{1234.5:,.2f}"   # '1,234.50'
br = valor.replace(",", "X").replace(".", ",").replace("X", ".")
print(br)                   # 1.234,50
Outras formas05

.format(), % e .join()

outros.py
nome, idade = "Ana", 29
print("{} tem {} anos.".format(nome, idade))   # .format()
print("%s tem %d anos." % (nome, idade))       # estilo antigo
print(", ".join(["maçã", "banana", "uva"]))    # junta uma lista
Saída
Ana tem 29 anos.
Ana tem 29 anos.
maçã, banana, uva
FormaQuando aparece
f"..."Código novo: prefira esta
"...".format()Código de antes do Python 3.6; modelos de texto guardados
"%s" % valorCódigo antigo; mensagens do módulo logging
", ".join(lista)Juntar muitos textos com um separador
.join() só aceita textos: uma lista de números precisa ser convertida antes.
Acumulando06

Montando um texto aos poucos

acumular.py
mensagem = "Olá"
mensagem += ", Ana"
mensagem += "!"
print(mensagem)
Saída
Olá, Ana!
  • += junta ao que já existe: mensagem = mensagem + ", Ana"
  • Útil para montar um texto em várias etapas
  • Para juntar centenas de pedaços, guarde numa lista e use .join() no fim: é bem mais rápido

Exercício08

Um recibo formatado

Enunciado: imprima um recibo com título centralizado entre linhas de =, cliente, produto, total com 2 casas e o valor de cada parcela.

Uma resposta possível
# Exercício: recibo com f-strings
cliente = "Ana Souza"
produto = "Curso de Python"
valor = 197
parcelas = 3
print("=" * 32)
print(f"{'RECIBO':^32}")
print("=" * 32)
print(f"Cliente: {cliente}")
print(f"Produto: {produto}")
print(f"Total:   R$ {valor:.2f}")
print(f"{parcelas}x de R$ {valor / parcelas:.2f}")
Saída
================================
             RECIBO             
================================
Cliente: Ana Souza
Produto: Curso de Python
Total:   R$ 197.00
3x de R$ 65.67
  • {'RECIBO':^32} centraliza em 32 posições
  • A conta da parcela fica dentro da f-string
  • Desafio: mostre o total no padrão brasileiro, com vírgula

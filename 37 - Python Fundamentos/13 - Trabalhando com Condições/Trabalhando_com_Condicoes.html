if01

Executar só se...

if_simples.py
idade = int(input("Idade: "))
if idade >= 18:
    print("Pode tirar a carteira de motorista.")
    print("(Esta linha também está dentro do if.)")
print("Fim do programa.")   # fora do if: sempre roda
Saída (digitou 20)
Idade: 20
Pode tirar a carteira de motorista.
(Esta linha também está dentro do if.)
Fim do programa.
  • if condição: com dois-pontos no fim
  • O bloco do if são as linhas com recuo (4 espaços)
  • A condição é qualquer coisa que dê True/False (aula 06)
  • A linha sem recuo volta ao fluxo normal: roda sempre
Com 15, o programa mostraria só "Fim do programa.": o bloco inteiro é pulado.
else e elif02

Senão, senão se

if_else.py · digitou 15
idade = int(input("Idade: "))
if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
Idade: 15
Menor de idade
else pega todos os outros casos. Nunca tem condição.
elif.py · digitou 7.5
nota = float(input("Nota: "))
if nota >= 9:
    conceito = "A"
elif nota >= 7:
    conceito = "B"
elif nota >= 5:
    conceito = "C"
else:
    conceito = "D"
print("Conceito:", conceito)
Nota: 7.5
Conceito: B
O Python testa de cima para baixo e para no primeiro verdadeiro. Por isso a ordem importa: com nota >= 5 primeiro, uma nota 9,5 viraria "C".
Combinando03

Condições combinadas

combinadas.py
idade = 20
tem_ingresso = True
if idade >= 18 and tem_ingresso:
    print("Pode entrar")
dia = "sábado"
if dia == "sábado" or dia == "domingo":
    print("Fim de semana")
if dia in ("sábado", "domingo"):   # o mesmo, mais curto
    print("Fim de semana (com in)")
Saída
Pode entrar
Fim de semana
Fim de semana (com in)
  • and: as duas precisam ser verdadeiras; or: basta uma (aula 06)
  • in com uma tupla substitui vários or
  • 18 <= idade < 60: comparação encadeada, como na matemática
Armadilha: if dia == "sábado" or "domingo": é sempre verdadeiro, porque o texto "domingo" sozinho conta como True. Compare cada um, ou use in.

nome = input("Nome (pode deixar vazio): ").strip()
if nome:                      # texto vazio é False
    print(f"Olá, {nome}!")
else:

Olá, visitante!

Atalhos05

Ternário e match

ternario.py
idade = 16
status = "adulto" if idade >= 18 else "menor"
print(status)
menor
valor_se_sim if condição else valor_se_não: um if numa linha, que devolve um valor. Bom para escolhas simples.
match.py · digitou "parar"
comando = input("Comando: ").strip().lower()
match comando:
    case "iniciar":
        print("Iniciando...")
    case "pausar" | "parar":
        print("Pausando...")
    case _:
        print("Comando desconhecido")
Comando: parar
Pausando...
match (Python 3.10+) compara um valor com vários casos. | junta opções; case _: é o "qualquer outro".

  • Depois de if ...:, o Python espera um bloco com recuo

  • Padrão: 4 espaços. O Cursor coloca sozinho ao teclar Enter depois dos dois-pontos

Exercício07

Classificando o IMC

Enunciado: peça um IMC (aceitando vírgula) e mostre a faixa: abaixo de 18,5 "abaixo do peso"; até 25 "peso normal"; até 30 "sobrepeso"; acima "obesidade".

Uma resposta possível
# Exercício: classificação do IMC
imc = float(input("IMC: ").replace(",", "."))
if imc < 18.5:
    faixa = "abaixo do peso"
elif imc < 25:
    faixa = "peso normal"
elif imc < 30:
    faixa = "sobrepeso"
else:
    faixa = "obesidade"
print(f"IMC {imc:.1f}: {faixa}")
Saída (digitou 27,3)
IMC: 27,3
IMC 27.3: sobrepeso
  • Cada elif só precisa do limite de cima: os de baixo já foram descartados
  • Teste os limites: 18.5, 25 e 30 caem na faixa certa?
  • Desafio: junte com a calculadora de IMC da aula 04

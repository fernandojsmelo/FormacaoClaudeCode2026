Conceito01

O que é um método

Um método é uma função que pertence a um tipo. Chama-se com texto.metodo(). Como strings são imutáveis (aula 07), todo método de string devolve uma string nova e deixa a original como estava.

nome = "ana"
nome.upper()          # cria "ANA", mas ninguém guardou
print(nome)           # ana
nome = nome.upper()   # guarde o resultado
print(nome)           # ANA
  • Os parênteses são obrigatórios, mesmo vazios: .upper()
  • Métodos podem ser encadeados: texto.strip().lower()
  • No Cursor, digite o ponto depois de uma string e a lista de métodos aparece
  • No REPL, help(str.replace) mostra a documentação
Esquecer de guardar o resultado é o erro número 1 com métodos de string.

Limpeza03

Tirando o que sobra

limpar.py
email = "   Ana.Souza@Exemplo.com  \n"
print(repr(email.strip()))           # tira espaços das pontas
print(repr(email.lstrip()))          # só da esquerda
print(email.strip().lower())         # encadeando métodos
print("---olá---".strip("-"))        # tira outros caracteres
Saída
'Ana.Souza@Exemplo.com'
'Ana.Souza@Exemplo.com  \n'
ana.souza@exemplo.com
olá
  • .strip() tira espaços, tabulações e quebras de linha das pontas
  • .lstrip() e .rstrip(): só esquerda ou só direita
  • Com argumento, tira outros caracteres: .strip("-")
  • repr() mostra o texto com as aspas e os \n visíveis: ótimo para ver espaços escondidos

Substituir05

Trocando trechos

trocar.py
frase = "Eu gosto de Java. Java é legal."
print(frase.replace("Java", "Python"))      # troca todas
print(frase.replace("Java", "Python", 1))   # só a primeira
print(frase)          # a original não muda
Saída
Eu gosto de Python. Python é legal.
Eu gosto de Python. Java é legal.
Eu gosto de Java. Java é legal.
  • .replace(velho, novo) troca todas as ocorrências
  • O terceiro argumento limita quantas
  • Diferencia maiúsculas: "java" não troca "Java"
  • Trocar por "" apaga: cpf.replace(".", "")
Encadear vários .replace() resolve muita limpeza de dados, como na validação de CPF da seção 09.
Dividir e juntar06

split() e join()

dividir_juntar.py
linha = "Ana;29;Recife"
partes = linha.split(";")
print(partes)              # ['Ana', '29', 'Recife']
print(partes[0])
print("o rato roeu a roupa".split())   # sem argumento: espaços
print(" - ".join(partes))              # o contrário do split
Saída
['Ana', '29', 'Recife']
Ana
['o', 'rato', 'roeu', 'a', 'roupa']
Ana - 29 - Recife
  • .split(sep) quebra o texto e devolve uma lista (aula 09)
  • Sem argumento, separa em qualquer espaço e ignora espaços repetidos
  • sep.join(lista) faz o caminho inverso
  • Os pedaços continuam sendo texto: '29', não 29
Linhas de arquivos CSV, como "Ana;29;Recife", são lidas assim: .split(";") e cada campo pela posição.

Juntando tudo09

Validando o formato de um CPF

validar_cpf_simples.py
cpf = input("CPF: ").strip().replace(".", "").replace("-", "")
if cpf.isdigit() and len(cpf) == 11:
    formatado = f"{cpf[:3]}.{cpf[3:6]}.{cpf[6:9]}-{cpf[9:]}"
    print("Formato válido:", formatado)
else:
    print("Formato inválido")
Saída (digitou " 123.456.789-09 ")
CPF:  123.456.789-09 
Formato válido: 123.456.789-09
  1. .strip() tira os espaços
  2. Dois .replace() tiram pontos e traço
  3. .isdigit() e len() conferem 11 dígitos
  4. Fatias remontam no formato padrão
Isso confere só o formato. Um CPF válido de verdade também precisa dos dígitos verificadores, que pedem contas com repetição (aulas 14 e 17). O if/else é o assunto da aula 13.
Exercício10

Arrumando um nome digitado

Enunciado: peça um nome (que pode vir com espaços e letras misturadas), arrume com .strip().title() e mostre o primeiro nome, o último, as iniciais e quantas letras "a" ele tem.

Uma resposta possível
# Exercício: arrumar e analisar um nome digitado
nome = input("Nome: ").strip().title()
partes = nome.split()
print("Nome arrumado:", nome)
print("Primeiro nome:", partes[0])
print("Último nome:", partes[-1])
print("Iniciais:", partes[0][0] + partes[-1][0])
print("Quantas letras 'a':", nome.lower().count("a"))
Saída (digitou " maria DA silva ")
Nome:    maria DA silva   
Nome arrumado: Maria Da Silva
Primeiro nome: Maria
Último nome: Silva
Iniciais: MS
Quantas letras 'a': 4
  • partes[0][0]: primeira letra do primeiro nome
  • Repare em "Da": o .title() não conhece as regras do português
  • Desafio: deixe "da", "de", "do" em minúsculas

Uma função é um bloco de código com nome, que você escreve uma vez e usa quantas vezes quiser. Funções evitam repetição, dão nome às ideias e deixam o programa fácil de testar. Nesta aula: def, chamar, parâmetros, return, a diferença entre print e return, escopo, docstring e dicas de tipo.

def01

Definir e chamar

definir.py
def saudar():
    print("Olá!")
    print("Bem-vindo ao curso.")

saudar()        # chama a função
saudar()        # e de novo
Saída
Olá!
Bem-vindo ao curso.
Olá!
Bem-vindo ao curso.
  • def nome(): com dois-pontos; o corpo vai com recuo
  • Definir não executa nada: só ensina ao Python o que a função faz
  • Chamar é nome(), com parênteses
  • A função precisa estar definida antes da chamada
  • Nome em snake_case, de preferência um verbo: calcular_total

Atenção03

print não é return

print_vs_return.py
def soma_print(a, b):
    print(a + b)

def soma_return(a, b):
    return a + b

x = soma_print(2, 3)     # mostra 5, mas devolve None
y = soma_return(2, 3)    # não mostra nada, devolve 5
print("x =", x, "| y =", y)
Saída
5
x = None | y = 5
  • print mostra na tela; o valor se perde
  • return devolve o valor para o programa usar
  • Função sem return devolve None
Regra prática: funções calculam e devolvem; quem mostra é o código que chama. Assim a mesma função serve para tela, arquivo ou teste.
return04

return encerra a função

varios_retornos.py
def classificar(nota):
    if nota >= 7:
        return "aprovado"     # return encerra a função aqui
    return "reprovado"

for nota in [8.0, 5.5]:
    print(nota, classificar(nota))
Saída
8.0 aprovado
5.5 reprovado
  • Ao chegar num return, a função termina na hora
  • Por isso não precisa de else depois de um if com return
  • Para devolver vários valores, devolva uma tupla (aula 10): return menor, maior
Escopo05

Variáveis locais e globais

escopo.py
taxa = 0.1           # variável global

def com_desconto(preco):
    desconto = preco * taxa   # local: só existe aqui dentro
    return preco - desconto

print(com_desconto(200))
print(taxa)
print(desconto)
180.0
0.1
Traceback (most recent call last):
  File "escopo.py", line 9, in <module>
    print(desconto)
          ^^^^^^^^
NameError: name 'desconto' is not defined
  • Variáveis criadas dentro da função (e os parâmetros) são locais: somem quando ela termina
  • Por isso desconto dá NameError fora da função
  • A função consegue ler variáveis globais (taxa)
Evite depender de globais: passe tudo o que a função precisa como parâmetro. Ela fica previsível e fácil de testar.
Documentar06

Docstring e dicas de tipo

docstring.py
def area_retangulo(base: float, altura: float) -> float:
    """Calcula a área de um retângulo."""
    return base * altura

print(area_retangulo(3, 4.5))
print(area_retangulo.__doc__)
Saída
13.5
Calcula a área de um retângulo.
  • """...""" logo abaixo do def é a docstring: o Cursor mostra ao passar o mouse
  • base: float e -> float são dicas de tipo: documentam, não obrigam (capítulo 17 do guia)
  • help(area_retangulo) no REPL mostra a documentação
Dica do guia (cap. 7): funções devem fazer uma coisa e fazer bem. Passou de 20 linhas, considere dividir.

Exercício08

Funções que se combinam

Enunciado: crie media(notas) e situacao(valor) (aprovado a partir de 7, senão recuperação) e use as duas para mostrar o resultado de uma lista de notas.

Uma resposta possível
# Exercício: funções pequenas que se combinam
def media(notas):
    return sum(notas) / len(notas)

def situacao(valor):
    return "aprovado" if valor >= 7 else "recuperação"

notas = [7.5, 8.0, 6.5]
m = media(notas)
print(f"Média {m:.2f}: {situacao(m)}")
Saída
Média 7.33: aprovado
  • Cada função faz uma coisa: calcular; classificar
  • Nenhuma das duas usa print: quem mostra é o código de fora
  • Desafio: o que acontece com media([])? Trate esse caso

def cria a função, a chamada a executa. Parâmetros recebem os argumentos; return devolve um valor e encerra a função (sem ele, None). Variáveis de dentro são locais. Docstring e dicas de tipo documentam, e funções pequenas que devolvem valor são as mais fáceis de reusar e testar.

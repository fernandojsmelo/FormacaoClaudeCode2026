and, or e not

Atribuição06

Atribuição composta

atribuicao.py
saldo = 100
saldo += 50    # saldo = saldo + 50
saldo -= 30    # saldo = saldo - 30
saldo *= 2     # saldo = saldo * 2
print(saldo)
x = y = 0      # mesmo valor para duas variáveis
a, b = 1, 2    # dois valores de uma vez
a, b = b, a    # troca os valores
print(x, y, a, b)
Saída
240
0 0 2 1
  • x += 5 é o mesmo que x = x + 5; vale para -= *= /= //= %= **=
  • 100 + 50 − 30 = 120, vezes 2 = 240
  • a, b = b, a troca dois valores sem variável auxiliar (as tuplas da aula 10 explicam por quê)
Python não tem x++ nem x--. Use x += 1.
in e is07

Pertinência e identidade

pertinencia.py
print("py" in "Python")        # False: diferencia maiúsculas
print("Py" in "Python")        # True
print(3 in [1, 2, 3])          # True
print("x" not in "Python")     # True
valor = None
print(valor is None)           # "is": só para None

True
True

True
  • in pergunta "está dentro?": em textos, listas, tuplas
  • not in é o contrário
  • is pergunta "é o mesmo objeto?", não "tem o mesmo valor?"
Regra prática do guia (cap. 3): para comparar valores, ==; is só com None (x is None).
Exercício08

Segundos em h, min e s

Enunciado: peça um total de segundos e mostre em horas, minutos e segundos, usando só // e %.

Uma resposta possível
# Exercício: segundos em horas, minutos e segundos
total = int(input("Segundos: "))
horas = total // 3600
minutos = total % 3600 // 60
segundos = total % 60
print(f"{horas}h {minutos}min {segundos}s")
Saída (digitou 7384)
Segundos: 7384
2h 3min 4s
  • 7384 // 3600 = 2 horas
  • 7384 % 3600 = 184 s → 184 // 60 = 3 minutos
  • 7384 % 60 = 4 segundos
  • Desafio: aceite também dias

Todo valor em Python tem um tipo: texto, número inteiro, número decimal, verdadeiro ou falso, "nada". O tipo decide o que dá para fazer com o valor. Nesta aula: variáveis, os cinco tipos básicos, type(), as surpresas do float, conversões entre tipos e o que acontece quando uma conversão falha.

Conceito01

Variáveis: nomes para valores

Uma variável é um nome que aponta para um valor. Você cria com = (atribuição) e pode trocar o valor depois. Em Python não se declara o tipo: ele vem do valor.

idade = 29          # cria a variável
idade = idade + 1   # usa e troca o valor
print(idade)        # 30
O = não é "igual" da matemática: é "guarde este valor neste nome". Para comparar, usa-se == (aula 06).
Regra de nomeExemplo
Letras, números e _nota_final, aluno2
Não começa com número2aluno é erro
Sem espaço nem hífennota-final é erro
Maiúscula ≠ minúsculaIdade e idade são diferentes
Não use palavras do Pythonif, for, class…
Convenção do Python (PEP 8): snake_case, minúsculas com _. Nomes que dizem o que guardam: preco_total, não x.

Números03

int, float e suas surpresas

numeros.py
# int não tem limite de tamanho
print(2 ** 100)

# float é aproximado: alguns decimais não são exatos
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))

# Divisão com / sempre dá float, mesmo quando é exata
print(10 / 2)
print(type(10 / 2))

# Separador de milhar com _ (só para leitura)
populacao = 203_080_756
print(populacao)
Saída
1267650600228229401496703205376
0.30000000000000004
0.3
5.0
<class 'float'>
203080756
  • int não estoura: 2 ** 100 sai inteiro
  • 0.1 + 0.2 dá 0.30000000000000004: o float é guardado em binário e alguns decimais não são exatos
  • Para dinheiro, arredonde ao mostrar (round, ou :.2f na aula 05)
  • / sempre devolve float
Não é bug do Python: quase todas as linguagens se comportam assim com ponto flutuante. Contas financeiras exatas usam o módulo decimal.

Erros05

Quando a conversão falha

erro_conversao.py
idade = int("vinte")
Traceback (most recent call last):
  File "erro_conversao.py", line 1, in <module>
    idade = int("vinte")
ValueError: invalid literal for int() with base 10: 'vinte'
  • ValueError: o tipo está certo (é um texto), mas o valor não serve
  • int("42") funciona; int("vinte") e int("4.5") não
  • Para "4.5", converta com float()
Esse erro vai aparecer muito na próxima aula: tudo o que vem do teclado é texto, e o usuário pode digitar qualquer coisa. Tratar o erro é assunto do capítulo 12 do guia.
Verificando06

type() e isinstance()

isinstance_ex.py
valor = 3.14
print(isinstance(valor, float))         # True
print(isinstance(valor, int))           # False
print(isinstance(valor, (int, float)))  # True: é um dos dois
Saída
True
False
True
  • type(x) mostra o tipo: ótimo para investigar no REPL
  • isinstance(x, tipo) responde True ou False: melhor para decisões no código
  • Aceita uma tupla de tipos: "é int ou float?"
Detalhe curioso: bool é um tipo especial de int. True vale 1 e False vale 0, por isso True + 1 dá 2.

Exercício09

Descubra e converta

Enunciado: numa lista com "42", 3.7, True e "2.5", mostre o tipo dos três primeiros; depois dobre o "42" como número, converta 3.7 em inteiro, some 1 a "2.5" e a True.

Uma resposta possível
# Exercício: descubra o tipo e converta
valores = ["42", 3.7, True, "2.5"]
print(type(valores[0]), type(valores[1]), type(valores[2]))
print(int(valores[0]) * 2)       # "42" -> 42
print(int(valores[1]))           # 3.7 -> 3
print(float(valores[3]) + 1)     # "2.5" -> 3.5
print(int(valores[2]) + 1)       # True vale 1
Saída
<class 'str'> <class 'float'> <class 'bool'>
84
3
3.5
2
valores[0] pega o primeiro item da lista. Listas são o assunto da aula 09; por ora, basta saber que a posição começa em 0.
Quiz de fixação10

Teste o que ficou

1. Qual é o tipo de 10 / 2?

A) int
B) float
C) str
D) bool

A) 10
B) 9
C) 9.99

3. int("vinte") gera qual erro?

A) TypeError
B) NameError
C) ValueError

4. Qual destes é False?

A) bool(" ")

D) bool(-1)
C. " " e "0" são textos não vazios.

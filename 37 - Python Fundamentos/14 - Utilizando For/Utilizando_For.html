for

O for repete um bloco para cada item de uma coleção: cada letra de um texto, cada item de uma lista, cada par de um dicionário. Nesta aula: percorrer coleções, range(), acumular resultados, enumerate() e zip(), break e continue, laços dentro de laços e percorrer dicionários.

for01

Para cada item, faça

percorrer.py
frutas = ["maçã", "banana", "uva"]
for fruta in frutas:
    print("Eu gosto de", fruta)
print("Acabou o for")
Saída
Eu gosto de maçã
Eu gosto de banana
Eu gosto de uva
Acabou o for
  • A cada volta, a variável (fruta) recebe o próximo item
  • O bloco com recuo roda uma vez por item
  • Funciona com strings, listas, tuplas, sets e dicionários
  • Nome no singular para o item, plural para a coleção: for fruta in frutas

Acumular03

Somando e procurando o maior

acumular.py
notas = [8.5, 6.0, 9.5, 7.0]
soma = 0
for nota in notas:
    soma += nota
print("Soma:", soma, "| Média:", soma / len(notas))

maior = notas[0]
for nota in notas:
    if nota > maior:
        maior = nota
print("Maior:", maior)
Saída
Soma: 31.0 | Média: 7.75
Maior: 9.5
  • Acumulador: variável criada antes do for e atualizada dentro
  • Soma começa em 0; produto começaria em 1; lista em []
  • Para o maior: começa com o primeiro e troca quando acha um maior
O Python já tem sum() e max() prontos, mas o padrão do acumulador serve para tudo que não tem função pronta.
Posição e pares04

enumerate() e zip()

enumerate_zip.py
nomes = ["Ana", "Bia", "Caio"]
notas = [9.0, 7.5, 8.0]
for i, nome in enumerate(nomes, start=1):
    print(f"{i}º {nome}")
for nome, nota in zip(nomes, notas):
    print(f"{nome}: {nota}")
Saída
1º Ana
2º Bia
3º Caio
Ana: 9.0
Bia: 7.5
Caio: 8.0
  • enumerate() entrega posição e item; start=1 começa a contar do 1
  • zip() anda em duas listas juntas, par a par
  • Os dois devolvem tuplas, desempacotadas no for (aula 10)
Dica do guia (cap. 6): prefira for item in lista a for i in range(len(lista)). Se precisar da posição, enumerate().
Controle05

break e continue

break_continue.py
numeros = [4, 7, -1, 12, 0, 9]
for n in numeros:
    if n < 0:
        continue          # pula este e segue
    if n == 0:
        print("achou zero, parando")
        break             # sai do for
    print(n)
Saída
4
7
12
achou zero, parando
  • continue: pula o resto desta volta e vai para o próximo item (o -1 não apareceu)
  • break: sai do for na hora (o 9 nunca foi visto)
  • Úteis para ignorar dados ruins e parar quando achar o que procurava
Aninhados06

for dentro de for

aninhado.py · mini tabuada
for linha in range(1, 4):
    for coluna in range(1, 4):
        print(linha * coluna, end="\t")
    print()
1	2	3	
2	4	6	
3	6	9
Para cada linha, o for de dentro roda todas as colunas. 3 × 3 = 9 voltas no total.
dict_for.py · percorrer um dicionário com if
estoque = {"maçã": 12, "banana": 0, "uva": 5}
for fruta, qtd in estoque.items():
    if qtd == 0:
        print(f"{fruta}: ESGOTADO")
    else:
        print(f"{fruta}: {qtd}")
maçã: 12
banana: ESGOTADO
uva: 5
Não adicione nem remova itens da coleção que está sendo percorrida: percorra uma cópia ou monte uma coleção nova.
Exercício07

A tabuada

Enunciado: peça um número e mostre a tabuada dele de 1 a 10, com os números alinhados.

Uma resposta possível

n = int(input("Tabuada do: "))

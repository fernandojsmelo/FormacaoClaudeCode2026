Utilizando
while

O while repete enquanto uma condição for verdadeira, sem saber de antemão quantas voltas vai dar. É o laço certo para pedir de novo até a resposta ser válida, para menus e para "até o usuário teclar Enter". Nesta aula: contador, validação de entrada, sentinela, while True com break, o else do laço e o laço infinito.

while01

Enquanto for verdade

contador.py
contador = 1
while contador <= 5:
    print("Volta", contador)
    contador += 1        # sem isso, o loop nunca termina
print("Fim, contador =", contador)
Saída
Volta 1
Volta 2
Volta 3
Volta 4
Volta 5
Fim, contador = 6
  • Antes de cada volta, o Python testa a condição
  • Verdadeira: roda o bloco e testa de novo. Falsa: segue depois do laço
  • Algo dentro do bloco precisa mudar a condição, senão nunca termina
  • O contador termina em 6: foi o valor que fez a condição ficar falsa
Para "repita 5 vezes", o for i in range(5) (aula 14) é mais simples. O while brilha quando não se sabe quantas vezes.
Validar02

Perguntar até acertar

validar.py
idade = input("Idade: ")
while not idade.isdigit():
    print("Digite só números.")
    idade = input("Idade: ")
print("Idade válida:", int(idade))
Saída (digitou "vinte", "2O" e 29)
Idade: vinte
Digite só números.
Idade: 2O
Digite só números.
Idade: 29
Idade válida: 29
  • Resolve o ValueError da aula 04: só converte quando já sabe que é número
  • .isdigit() (aula 08) é a condição
  • "2O" tem a letra O no lugar do zero: o laço pegou
Para aceitar decimais e negativos, a forma completa usa try/except dentro do while (capítulo 12 do guia).
Sentinela03

Até teclar Enter

sentinela.py
compras = []
item = input("Item (ENTER para terminar): ").strip()
while item:                       # texto vazio é False
    compras.append(item)
    item = input("Item (ENTER para terminar): ").strip()
print(f"{len(compras)} itens:", ", ".join(compras))
Saída (pão, arroz, leite e Enter)
Item (ENTER para terminar): pão
Item (ENTER para terminar): arroz
Item (ENTER para terminar): leite
Item (ENTER para terminar): 
3 itens: pão, arroz, leite
  • Sentinela: um valor especial que avisa "acabou" (aqui, o texto vazio)
  • while item: usa o "texto vazio é falso" da aula 13
  • Pergunta antes do laço e de novo no fim de cada volta
É a lista de compras da aula 09, agora aceitando quantos itens o usuário quiser.
while True04

Laço "infinito" com saída

while_true.py
while True:
    senha = input("Senha: ")
    if senha == "python123":
        print("Acesso liberado")
        break
    print("Senha errada, tente de novo")
Saída (abc, 123, python123)
Senha: abc
Senha errada, tente de novo
Senha: 123
Senha errada, tente de novo
Senha: python123
Acesso liberado
  • while True nunca para sozinho: a saída é o break
  • Evita repetir o input() antes e dentro do laço
  • Padrão comum em menus (exercício da seção 07)
Laço infinito sem querer? Ctrl + C no terminal interrompe o programa (KeyboardInterrupt).
else05

O else do laço

tentativas.py
SEGREDO = 7
tentativas = 0
while tentativas < 3:
    palpite = int(input("Palpite (1 a 10): "))
    tentativas += 1
    if palpite == SEGREDO:
        print(f"Acertou em {tentativas} tentativa(s)!")
        break
    print("Maior" if palpite < SEGREDO else "Menor")
else:
    print("Acabaram as tentativas. Era", SEGREDO)
Saída (palpites 5, 9 e 6)
Palpite (1 a 10): 5
Maior
Palpite (1 a 10): 9
Menor
Palpite (1 a 10): 6
Maior
Acabaram as tentativas. Era 7
  • O else do while roda quando o laço termina sem break
  • Aqui: acabaram as 3 tentativas sem acertar
  • Se acertar, o break pula o else
  • O for também tem else, com a mesma regra
Pouco conhecido e às vezes confuso: use com um comentário. Uma variável acertou = False faz o mesmo de forma explícita.
Simulação06

Até atingir um objetivo

juros.py
saldo = 1000.0
meses = 0
while saldo < 2000:
    saldo *= 1.01        # 1% ao mês
    meses += 1
print(f"{meses} meses para dobrar: R$ {saldo:.2f}")
70 meses para dobrar: R$ 2006.76
  • Não se sabe quantos meses serão: perfeito para while
  • A condição é o objetivo (saldo < 2000) ao contrário: repete enquanto não chegou
  • A 1% ao mês, o dinheiro dobra em 70 meses
Use for quandoUse while quando
Percorre uma coleçãoDepende do usuário
Sabe quantas voltasRepete até uma condição mudar
Exercício07

Um menu que repete

Enunciado: um menu com depositar, ver saldo e sair, que repete até a pessoa escolher 0 e avisa quando a opção não existe.

Uma resposta possível
# Exercício: menu que repete até sair
saldo = 0
while True:
    opcao = input("[1] Depositar [2] Ver saldo [0] Sair: ")
    if opcao == "1":
        saldo += float(input("Valor: "))
    elif opcao == "2":
        print(f"Saldo: R$ {saldo:.2f}")
    elif opcao == "0":
        print("Até logo!")
        break
    else:
        print("Opção inválida")
Saída (deposita 150 e 49.9, vê o saldo, tenta 7, sai)
[1] Depositar [2] Ver saldo [0] Sair: 1
Valor: 150
[1] Depositar [2] Ver saldo [0] Sair: 1
Valor: 49.9
[1] Depositar [2] Ver saldo [0] Sair: 2
Saldo: R$ 199.90
[1] Depositar [2] Ver saldo [0] Sair: 7
Opção inválida
[1] Depositar [2] Ver saldo [0] Sair: 0
Até logo!
  • while True + break na opção 0
  • if/elif/else (aula 13) escolhem a ação
  • Desafio: inclua sacar, sem deixar o saldo ficar negativo

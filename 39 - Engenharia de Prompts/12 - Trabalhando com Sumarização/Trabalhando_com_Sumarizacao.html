Armadilha06

Parece JSON, mas o Python não lê

  • A resposta começa com ```json e termina com ```: as cercas de bloco de código do Markdown
  • O notebook só imprime o texto, então ninguém percebe
  • Mas, se o próximo passo for json.loads(resposta_json), o programa quebra
json.loads numa resposta com cercas · saída real
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)

Gerado com o mesmo formato de resposta, cercas incluídas.

Duas correções
response = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": json_prompt}],
    response_format={"type": "json_object"},  # JSON válido
)
dados = json.loads(response.choices[0].message.content)
Ou peça no prompt "responda só com o JSON, sem crases" e remova as cercas no código antes do json.loads. O response_format (aula 07) é a forma garantida.
Fidelidade07

Como pedir um resumo que não invente

1

Diga o tamanho

Proporção (1/3), frases (2-3) ou palavras (até 60). Confira contando.

2

Proíba acréscimos

"Use só informações do texto; não acrescente números nem fatos."

3

Trate o que falta

"Se uma métrica pedida não existir, escreva 'sem dado'."

4

Temperatura baixa

O notebook usa 0.15 a 0.25 para os resumos factuais.

Encerramento · Engenharia de Prompts

Menor,
mas verdadeiro

Um bom resumo tem tamanho definido, público definido e nenhuma informação nova. Diga o tamanho, proíba acréscimos, trate o que falta e use temperatura baixa. Para resumos que vão para outro programa, garanta o JSON com response_format.

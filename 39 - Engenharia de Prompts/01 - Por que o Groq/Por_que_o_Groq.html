Engenharia de prompt se aprende testando: escrever, rodar, comparar e ajustar, muitas vezes. Para isso, o módulo usa a API do Groq, uma nuvem de inferência rápida, com plano gratuito para começar e modelos de pesos abertos, como o openai/gpt-oss-120b, usado em todos os notebooks. Nesta aula: o que é o Groq, o que o torna rápido, os modelos, os limites de uso e como ele se encaixa no resto do módulo.

O que é01

Groq: uma nuvem feita para rodar modelos

  • O Groq não cria os modelos: ele hospeda modelos de terceiros (OpenAI gpt-oss, Llama, Qwen, Whisper…) e os executa para você
  • Você acessa pela GroqCloud: console em console.groq.com, chave de API e biblioteca Python groq
  • Rodar um modelo já treinado para responder a pedidos se chama inferência, e é nisso que o Groq se especializou

Treino × inferência: treinar um modelo leva semanas em milhares de chips; a inferência acontece a cada pergunta e precisa ser rápida e barata.
Velocidade02

O LPU: um chip só para inferência

  • LPU (Language Processing Unit) é o processador que o Groq desenvolveu para executar modelos de linguagem
  • A ideia central: guardar os dados em memória SRAM dentro do próprio chip, em vez de buscá-los numa memória separada a cada passo
  • Resultado: muitos tokens por segundo e pouca espera, o que o Groq chama de baixa latência

O modelo do módulo04

gpt-oss-120b: pesos abertos e raciocínio

  • Modelo de pesos abertos da OpenAI, com 120 bilhões de parâmetros
  • É um modelo de raciocínio: pensa antes de responder, e esse raciocínio também conta como tokens de saída
  • O parâmetro reasoning_effort aceita low, medium (padrão) e high
  • Janela de 131.072 tokens: cabem textos longos no prompt
A chamada que se repete em todo o módulo
chat_completion = client.chat.completions.create(
    messages=[
        {"role": "user",
         "content": "Me explique de forma reduzida o que são as LLMs"},
    ],
    model="openai/gpt-oss-120b",
)
print(chat_completion.choices[0].message.content)

* Tabela de limites de base da página Rate Limits, em outubro de 2026. Os da sua conta aparecem em console.groq.com/settings/limits.

  • Os limites valem para a organização, não por pessoa
  • Vale o que estourar primeiro: 30 pedidos pequenos em um minuto já batem no RPM
  • Ao estourar, a API responde 429 Too Many Requests e o cabeçalho retry-after diz quantos segundos esperar
  • Planos pagos (Developer) liberam limites maiores
Para os notebooks do módulo, o plano gratuito sobra, desde que você não rode as células em laço.
Compatível06

A mesma API de todo mundo

SDK do Groq (o que o módulo usa)
from groq import Groq
client = Groq(api_key=...)
SDK da OpenAI apontando para o Groq
import openai
client = openai.OpenAI(
    base_url="https://api.groq.com/openai/v1",
    api_key=...,
)
  • A API do Groq é "quase toda" compatível com a da OpenAI: mesma estrutura de messages, choices e parâmetros
  • O que você aprender aqui (roles, temperatura, few shot…) vale para outras APIs de chat
  • Diferenças documentadas: só n=1; logprobs e logit_bias não são aceitos; temperature=0 vira 1e-8
Por que aqui07

Por que o Groq neste módulo

Rápido

Respostas em segundos deixam o ciclo escrever → rodar → comparar curto. É assim que se aprende prompt.

Gratuito para começar

Os limites do plano gratuito cobrem os exercícios do módulo.

Modelos abertos

gpt-oss, Llama e Qwen: técnicas testadas aqui funcionam com modelos que você também pode rodar em outros lugares.

API padrão

Formato compatível com o da OpenAI: o código muda pouco se você trocar de provedor depois.

O foco do módulo é a engenharia de prompt. O Groq é o laboratório; as técnicas valem para qualquer LLM.

Um laboratório
rápido e gratuito

Passo 102

Crie a sua chave da API

1

Entre no console

Acesse console.groq.com e crie uma conta (ou entre com a sua).

2

Abra API Keys

Página console.groq.com/keys.

3

Create API Key

Dê um nome (ex.: "curso-prompts") e copie a chave gerada.

4

Guarde num lugar seguro

Ela vai para o arquivo .env no passo 4.

A chave é uma senha. Quem a tiver usa a sua cota. Não cole em código, prints, e-mails ou repositórios públicos. Se vazar, apague-a no console e crie outra.
A documentação do Groq recomenda guardar a chave numa variável de ambiente, em vez de escrevê-la no código. É o que o .env faz.

  • Uma linha, sem aspas e sem espaços em volta do =
  • O nome do arquivo é só .env (começa com ponto, sem extensão)
  • load_dotenv() procura o .env a partir da pasta onde o código roda
Atenção ao nome: os notebooks usam GROQ_API. O SDK, sozinho, procura GROQ_API_KEY. Por isso o código passa api_key=os.environ.get("GROQ_API"); sem isso, a chave não é encontrada.
Passo 506

Teste a conexão

exemplos/teste_groq.py
from dotenv import load_dotenv
from groq import Groq
import os

load_dotenv()  # lê o arquivo .env da pasta atual
chave = os.environ.get("GROQ_API")
print("Chave carregada?", "sim" if chave else "não")

client = Groq(api_key=chave)
resposta = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": "Diga olá em uma frase."}],
)
print(resposta.choices[0].message.content)
Rodando
python teste_groq.py
  • Deu certo: aparece Chave carregada? sim e, em seguida, uma frase de saudação do modelo
  • É a mesma estrutura da primeira célula de todos os notebooks
  • Se aparecer erro, veja a próxima seção
Problemas07

Os dois erros mais comuns

Sem o .env (ou com o nome da variável errado) · saída real
Chave carregada? não
Traceback (most recent call last):
  …
groq.GroqError: The api_key client option must be set either by passing api_key to the client or by setting the GROQ_API_KEY environment variable

O SDK cita GROQ_API_KEY porque é o nome padrão dele; no curso, confira GROQ_API no .env.

Chave errada ou apagada no console · saída real
Chave carregada? sim
Traceback (most recent call last):
  …
groq.AuthenticationError: Error code: 401 - {'error': {'message': 'Invalid API Key', 'type': 'invalid_request_error', 'code': 'invalid_api_key'}}

Gerado com uma chave falsa de propósito. Copie a chave de novo ou crie outra.

ModuleNotFoundError: No module named 'groq': o venv não está ativado, ou o pip install rodou fora dele.
Error code: 429: limite do plano estourado (aula 01). Espere os segundos indicados em retry-after.

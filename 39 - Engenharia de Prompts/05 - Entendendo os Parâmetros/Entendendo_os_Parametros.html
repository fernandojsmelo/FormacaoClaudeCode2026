Os três01

O que cada parâmetro controla

ParâmetroControlaFaixa na API do GroqPadrão
temperatureAleatoriedade: baixa = respostas mais previsíveis; alta = mais variadas0 a 21
top_p"Nucleus sampling": só os tokens que somam essa fração da probabilidade entram no sorteio0 a 11
max_completion_tokensMáximo de tokens que a resposta pode ter; substitui o max_tokens, que está obsoletoaté o limite do modelo (65.536 no gpt-oss-120b)—
O notebook diz que temperature aceita 0.0 a 1.0, mas a documentação aceita 0 a 2, e o próprio notebook usa 1.5 logo depois.
No Groq, temperature=0 é convertido para 1e-8. A documentação recomenda mexer em temperature ou em top_p, não nos dois.

Leitura crítica04

O que este experimento prova (e não prova)

Duas variáveis mudaram

Além da temperatura, cada célula troca o system: poeta minimalista (0.0), clássico (0.7) e surrealista (1.5). Parte da diferença entre as frases vem da persona, não só do parâmetro.

O modelo copiou um erro de digitação

O prompt diz "anoitcer" (falta o "e"), e a resposta a 1.5 repete "anoitcer". O modelo trabalha com o texto que recebe, inclusive com os erros.

Para comparar um parâmetro, mude só ele. Mantenha o mesmo system e o mesmo prompt e rode cada valor mais de uma vez: com temperatura alta, duas execuções iguais já dão textos diferentes.
Experimento justo
for t in [0.0, 0.7, 1.5]:
    r = client.chat.completions.create(
        model="openai/gpt-oss-120b",
        messages=[{"role": "user", "content": prompt}],
        temperature=t,
    )
    print(t, r.choices[0].message.content)

Tamanho07

max_completion_tokens: um teto, não um resumo

  • Limita quantos tokens a resposta pode ter; ao chegar lá, a geração para no meio
  • O modelo não "encurta" o texto para caber: ele simplesmente é cortado
  • Entrada + saída ainda precisam caber na janela de contexto do modelo (131.072 tokens no gpt-oss-120b)
  • No gpt-oss-120b o raciocínio interno também gasta tokens de saída
Quer respostas curtas? Peça no prompt ("em até 3 linhas"). Use o limite como proteção de custo e tempo.
Como aparece na aula 06
response = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[...],
    temperature=0.7,
    max_completion_tokens=400
)

Na aula 06, várias respostas com limite de 400 tokens terminam no meio de uma frase.

mais controle

temperature (0 a 2) e top_p (0 a 1) controlam o quanto o modelo arrisca; ajuste um dos dois. max_completion_tokens corta a resposta quando chega ao teto. Para comparar valores, mude um parâmetro por vez e rode mais de uma vez.

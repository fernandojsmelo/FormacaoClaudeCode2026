Engenharia de Prompts · Aula 06

Boas práticas
em prompts

Quatro hábitos que mudam a qualidade da resposta: ser específico, dar instruções detalhadas, controlar o formato e separar os dados com delimitadores. Nesta aula, com o notebook 03-boas_praticas.ipynb, cada prática aparece em dupla: o prompt fraco e o prompt melhorado, com as respostas reais do modelo.

Visão geral01

As quatro práticas do notebook

1 · Seja específico

Diga exatamente o que quer: "Liste e explique 3 métodos…" em vez de "Fale sobre…".

2 · Detalhe a instrução

Quantidade, partes, critérios: "roteiro de 5 dias, cada dia com (1)…, (2)…, (3)…".

3 · Controle o formato

Mostre o molde da resposta: "Use o formato: - [Nome]: [1 benefício]".

4 · Use delimitadores

Separe dados de instruções com marcas como --- DADOS --- e --- FIM DADOS ---.

Em todas as duplas, o system, o modelo e os parâmetros são iguais. Só o prompt do user muda, então a diferença nas respostas vem dele.

  • --- DADOS --- e --- FIM DADOS --- mostram onde os dados começam e terminam
  • TAREFA: deixa a instrução separada, e mais específica: "ritmo de crescimento e 2 estratégias"
  • O system reforça: "considerar apenas os dados entre os delimitadores"

Pratique09

Conserte um prompt fraco

Exercício: reescreva o prompt abaixo aplicando as quatro práticas e compare as respostas.

Prompt fraco
prompt = "Me ajuda com o currículo"
Esqueleto sugerido
prompt = """
TAREFA: ...

--- DADOS ---
Cargo desejado: ...
Experiência: ...
--- FIM DADOS ---

FORMATO DA RESPOSTA:
1. ...
"""
  • Específico: o que exatamente melhorar (resumo? lista de experiências?)
  • Detalhado: para qual vaga, que tom, quantas linhas
  • Formato: seções e tamanho de cada uma
  • Delimitadores: os seus dados dentro do bloco
Não envie dados pessoais reais (CPF, telefone, endereço) para uma API de teste.

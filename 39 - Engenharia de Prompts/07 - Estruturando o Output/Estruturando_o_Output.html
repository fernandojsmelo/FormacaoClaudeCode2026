Para programas07

Quando a saída vai para outro programa

  • Os formatos desta aula são ótimos para pessoas lerem
  • Para um programa ler, o formato precisa ser garantido: um campo fora do lugar quebra o código
  • A API do Groq tem o parâmetro response_format:
    {"type": "json_object"} garante JSON válido;
    {"type": "json_schema", ...} (Structured Outputs) segue um esquema que você define
  • A documentação prefere json_schema nos modelos que o suportam
Formato do parâmetro (não está no notebook)
resp = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[...],
    response_format={"type": "json_object"},
)
dados = json.loads(resp.choices[0].message.content)
Confira em console.groq.com/docs/structured-outputs quais modelos aceitam json_schema antes de usar.

Encerramento · Engenharia de Prompts

Mostre o molde,
receba o formato

Um molde no system, com rótulos, marcadores e quantidade de itens, faz o modelo devolver sempre a mesma estrutura. Molde vago deixa o formato por conta do modelo. Para programas, garanta a estrutura com response_format.

Expressões regulares descrevem padrões de texto: "quatro dígitos", "uma palavra depois de #", "uma data no formato DD/MM/AAAA". No Python, elas ficam no módulo re. Buscar01

search, match e fullmatch

buscar.py
import re

texto = "Pedido 4821 enviado em 05/10/2026"

print(re.search(r"\d+", texto))         # primeira ocorrência
print(re.search(r"\d+", texto).group())
print(re.match(r"\d+", texto))          # só no começo: None
print(re.fullmatch(r"\d{4}", "4821"))   # a string inteira
print(bool(re.fullmatch(r"\d{4}", "48210")))
Saída
<re.Match object; span=(7, 11), match='4821'>
4821
None
<re.Match object; span=(0, 4), match='4821'>
False
FunçãoProcura
re.searcha primeira ocorrência, em qualquer lugar
re.matchsó no começo da string
re.fullmatcha string inteira tem de casar
  • Se acha, devolve um objeto Match; senão, None
  • .group() pega o texto encontrado; span diz onde estava

Extrair03

findall: todas as ocorrências

todos.py
import re

post = "Lançou! #python #regex custa R$ 49,90 ou 3x de 18,00"

print(re.findall(r"#\w+", post))               # hashtags
print(re.findall(r"\d+,\d{2}", post))          # preços
print(re.findall(r"\b\d+x\b", post))           # parcelas
Saída
['#python', '#regex']
['49,90', '18,00']
['3x']
  • findall devolve uma lista com cada texto encontrado
  • #\w+: o caractere # seguido de uma ou mais letras
  • \d+,\d{2}: dígitos, vírgula e exatamente dois dígitos
  • \b evita pegar o "3x" no meio de uma palavra maior
Grupos04

Capturando as partes

grupos.py
import re

agenda = "Prova 12/11/2026, entrega 03/12/2026"
padrao = r"(?P<dia>\d{2})/(?P<mes>\d{2})/(?P<ano>\d{4})"

for m in re.finditer(padrao, agenda):
    print(m.group(), "->", m["dia"], m["mes"], m["ano"])

primeira = re.search(padrao, agenda)
print(primeira.groupdict())
print(re.findall(padrao, agenda))   # com grupos: tuplas
Saída
12/11/2026 -> 12 11 2026
03/12/2026 -> 03 12 2026
{'dia': '12', 'mes': '11', 'ano': '2026'}
[('12', '11', '2026'), ('03', '12', '2026')]
  • (?P<nome>...) cria um grupo com nome: m["dia"]
  • finditer é um iterador de objetos Match (aulas 01 e 02)
  • groupdict() devolve os grupos nomeados como dicionário
  • Com grupos, findall devolve tuplas com as partes
Substituir05

re.sub: trocar pelo padrão

substituir.py
import re

ficha = "CPF 123.456.789-09   tel  (11) 98765-4321"

print(re.sub(r"\s+", " ", ficha))          # espaços extras
print(re.sub(r"\d{3}\.\d{3}\.\d{3}-\d{2}", "***", ficha))
print(re.sub(r"\d", "#", "senha 2026"))

# Grupo na troca: inverte data de AAAA-MM-DD para DD/MM/AAAA
print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3/\2/\1",
             "2026-10-05"))
Saída
CPF 123.456.789-09 tel (11) 98765-4321
CPF ***   tel  (11) 98765-4321
senha ####
05/10/2026
  • re.sub(padrão, troca, texto) troca todas as ocorrências
  • \s+ por " " junta espaços repetidos
  • Na troca, \1, \2... repetem os grupos capturados: dá para reordenar partes
O CPF e o telefone são números de exemplo.
Flags · compile · split06

Ajustes do dia a dia

flags_compile.py
import re

nomes = ["Ana", "ana", "ANA", "Mariana"]
ana = re.compile(r"^ana$", re.IGNORECASE)   # compila uma vez
print([n for n in nomes if ana.search(n)])

print(re.split(r"\s*[;,]\s*", "maçã; uva,kiwi ,  pera"))
['Ana', 'ana', 'ANA']
['maçã', 'uva', 'kiwi', 'pera']
crua.py
print(len("\b"), len(r"\b"))   # \b vira 1 caractere sem o r
print(r"C:\novo\texto")        # o r guarda a barra como está
1 2
C:\novo\texto
  • re.IGNORECASE ignora maiúsculas e minúsculas
  • re.compile prepara o padrão uma vez para usar muitas
  • re.split divide por um padrão, não por um texto fixo
  • Sem o r, "\b" vira o caractere de "voltar" e o padrão quebra; com r"\b", a barra chega ao re
Regra prática: escreva sempre os padrões como r"...".
Exercício07

Padronizar telefones

Enunciado: extraia os telefones de um texto bagunçado (com ou sem parênteses e espaços) e mostre todos no formato (DD) NNNNN-NNNN.

Uma resposta possível
import re

contatos = """Ana: 11 98765-4321
Bia (21)3456-7890 | Caio: (31) 99999-0000
Dani: 1234"""

padrao = r"\(?(\d{2})\)?\s*(\d{4,5})-(\d{4})"
for ddd, parte1, parte2 in re.findall(padrao, contatos):
    print(f"({ddd}) {parte1}-{parte2}")
Saída
(11) 98765-4321
(21) 3456-7890
(31) 99999-0000
  • \(? e \)?: parênteses opcionais
  • \d{4,5} aceita fixo e celular
  • "1234" não tem o formato e fica de fora

Encerramento · Python Intermediário

Padrões no lugar
de if e split

search acha a primeira ocorrência, match olha o começo e fullmatch exige a string inteira. findall e finditer extraem tudo, grupos capturam as partes, sub troca e split divide. Escreva os padrões como r"..." e comece simples: regex boa é a que outra pessoa consegue ler.

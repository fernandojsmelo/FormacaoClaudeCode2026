Usando um
gerador

Um gerador é o jeito curto de criar um iterador: uma função comum com yield no lugar de return. Ela entrega um valor, pausa e continua de onde parou no próximo pedido. Nesta aula: yield, a pausa entre os next(), o gerador como iterador pronto, as expressões geradoras e por que elas economizam memória.

yield01

Uma função que entrega aos poucos

primeiro.py
def contagem(n):
    while n > 0:
        yield n          # entrega um valor e pausa aqui
        n -= 1


g = contagem(3)
print(type(g).__name__)
print(list(g))
for x in contagem(2):
    print("for:", x)
Saída
generator
[3, 2, 1]
for: 2
for: 1
  • Basta um yield no corpo para a função virar uma função geradora
  • Chamá-la não executa o código: devolve um objeto generator
  • O gerador funciona em for, list(), sum()... como qualquer iterador
Pausa e retomada02

Roda até o próximo yield

pausa.py
def passos():
    print("  começou")
    yield 1
    print("  voltou depois do 1")
    yield 2
    print("  terminou")


g = passos()             # nada roda ainda
print("criado")
print(next(g))
print(next(g))
try:
    next(g)
except StopIteration:
    print("StopIteration")

Gerador × classe03

O iterador sem a classe

classe_vs_gerador.py
# Aula 01: uma classe com __iter__ e __next__
# Com gerador, o Python cria esses métodos para você:
def contagem(n):
    while n >= 1:
        yield n
        n -= 1


g = contagem(3)
print(iter(g) is g)        # é seu próprio iterador
print(hasattr(g, "__next__"))
print(list(g), list(g))        # e também se esgota

Expressão geradora04

A list comprehension com parênteses

expressao.py
quadrados = (n * n for n in range(1, 6))   # parênteses
print(quadrados)
print(list(quadrados))

# Dentro de uma função, nem precisa dos parênteses extras
print(sum(n * n for n in range(1, 6)))
print(max(len(p) for p in ["sol", "lua", "estrela"]))
Saída
<generator object <genexpr> at 0x7e15ba016810>
[1, 4, 9, 16, 25]
55
7
  • [...] monta a lista inteira; (...) cria um gerador
  • Como único argumento de uma função, os parênteses da chamada bastam: sum(n * n for n in ...)
  • Ideal quando o resultado vai direto para sum, max, any, "".join...
Memória05

Um milhão de itens em 208 bytes

memoria.py
import sys

lista = [n * 2 for n in range(1_000_000)]
gerador = (n * 2 for n in range(1_000_000))

print("lista:  ", sys.getsizeof(lista), "bytes")
print("gerador:", sys.getsizeof(gerador), "bytes")
print(sum(gerador) == sum(lista))
Saída
lista:   8448728 bytes
gerador: 208 bytes
True
  • A lista guarda o milhão de números de uma vez
  • O gerador guarda só a "receita" e o ponto atual: o tamanho não muda com a quantidade
  • O resultado da soma é o mesmo
O preço: o gerador não tem len(), não aceita índice e só pode ser percorrido uma vez. Precisou disso, use lista.
Exercício06

Gerador de múltiplos

Enunciado: escreva multiplos(numero, limite), um gerador que entrega os múltiplos de numero até limite.

Uma resposta possível
def multiplos(numero, limite):
    """Gera os múltiplos de numero até limite."""
    atual = numero
    while atual <= limite:
        yield atual
        atual += numero


print(list(multiplos(7, 50)))
print(sum(multiplos(3, 30)))
print(next(multiplos(9, 100)))
Saída
[7, 14, 21, 28, 35, 42, 49]
165
9
  • next(multiplos(9, 100)) calcula só o primeiro valor
  • Desafio: refaça com uma expressão geradora e range

Encerramento · Python Intermediário

Entrega, pausa
e continua

Um yield transforma a função num gerador: chamar não roda nada, e cada next() avança até o próximo yield, guardando o estado. É um iterador pronto, sem classe. Com parênteses, a expressão geradora faz o mesmo em uma linha e ocupa quase nada de memória, mas só pode ser percorrida uma vez.

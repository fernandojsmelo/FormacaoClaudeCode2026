Iteradores
default

Você raramente precisa escrever um iterador do zero: o Python já traz vários prontos. Listas, strings, tuplas, dicionários e conjuntos entregam iteradores com iter(); enumerate, zip, reversed e map devolvem iteradores preguiçosos; e o módulo itertools tem ferramentas para contar, repetir e encadear. Nesta aula: os iteradores que já vêm com a linguagem e quando cada um se esgota.

Tipos padrão01

Cada coleção tem o seu iterador

embutidos.py
for valor in ["ab", (1, 2), {"x": 1}, {7}]:
    it = iter(valor)
    print(type(it).__name__, "->", next(it))
Saída
str_ascii_iterator -> a
tuple_iterator -> 1
dict_keyiterator -> x
set_iterator -> 7
  • String, tupla, dicionário e set são iteráveis: iter() devolve um iterador próprio de cada tipo
  • O iterador de dicionário entrega as chaves
  • O set não garante ordem: não conte com a posição dos itens
Os nomes (tuple_iterator, set_iterator...) são detalhes internos: o que importa é que todos respondem a next().
Preguiçosos02

enumerate, zip e reversed não são listas

preguicosos.py
nums = [3, 1, 2]
pares = enumerate(nums)
print(pares)              # um objeto, não uma lista
print(list(pares))        # materializa os itens
print(list(pares))        # e ele já se esgotou
print(list(reversed(nums)))
print(list(zip("abc", nums)))
Saída
<enumerate object at 0x792435926160>
[(0, 3), (1, 1), (2, 2)]
[]
[2, 1, 3]
[('a', 3), ('b', 1), ('c', 2)]
  • Eles devolvem iteradores: calculam cada item só quando você pede
  • Imprimir mostra só o objeto; list() materializa os itens
  • Como todo iterador, se esgotam depois de uma volta
O endereço 0x… muda a cada execução: é só a posição do objeto na memória.
range03

range: iterável que não se esgota

range_reusa.py
r = range(0, 10, 3)
print(list(r))
print(list(r))       # range é iterável: recomeça
print(6 in r, 7 in r)
print(len(r), r[-1])
Saída
[0, 3, 6, 9]
[0, 3, 6, 9]
True False
4 9
  • range é uma sequência, não um iterador: percorre quantas vezes quiser
  • Não guarda os números: calcula na hora, então range(10**9) ocupa pouca memória
  • Aceita in, len() e índice, como uma lista
Dicionários04

Chaves, valores e pares

dicionario.py
estoque = {"maçã": 4, "uva": 0, "kiwi": 7}
print(list(estoque))            # chaves
print(list(estoque.values()))
for fruta, qtd in estoque.items():
    if qtd == 0:
        print(fruta, "esgotou")
Saída
['maçã', 'uva', 'kiwi']
[4, 0, 7]
uva esgotou
Você escreveRecebe a cada volta
for k in da chave
d.keys()a chave
d.values()o valor
d.items()a tupla (chave, valor)
São views: refletem o dicionário atual. Não altere o tamanho do dicionário enquanto percorre um deles.
iter com sentinela05

iter(função, sentinela)

iter_sentinela.py
from functools import partial
import io

texto = io.StringIO("abcdefgh")
ler4 = partial(texto.read, 4)

# iter(função, sentinela): chama até receber ""
for bloco in iter(ler4, ""):
    print(bloco)
Saída
abcd
efgh
  • Com dois argumentos, iter() chama a função sem argumentos até ela devolver o valor sentinela
  • partial(texto.read, 4) fixa o argumento: cada chamada lê 4 caracteres
  • É o jeito clássico de ler um arquivo em blocos de tamanho fixo
io.StringIO faz uma string se comportar como arquivo. Num arquivo real, a ideia é a mesma.
itertools06

Contar, repetir e encadear

ferramentas.py
from itertools import count, cycle, islice, chain

print(list(islice(count(10, 5), 4)))     # 10, 15, 20, 25
print(list(islice(cycle("AB"), 5)))      # A B A B A
print(list(chain([1, 2], (3,), "45")))   # junta iteráveis
Saída
[10, 15, 20, 25]
['A', 'B', 'A', 'B', 'A']
[1, 2, 3, '4', '5']
FerramentaO que faz
count(início, passo)conta sem fim
cycle(iterável)repete o iterável sem fim
islice(it, n)corta os primeiros n itens
chain(a, b, ...)percorre um iterável depois do outro
count e cycle são infinitos: nunca faça list(count()) sem limitar com islice.
Exercício07

Escala de turnos

Enunciado: distribua os dias da semana entre três pessoas, em rodízio, sem usar índices nem %.

Uma resposta possível
from itertools import cycle

pessoas = ["Ana", "Bia", "Caio"]
dias = ["seg", "ter", "qua", "qui", "sex"]

for dia, pessoa in zip(dias, cycle(pessoas)):
    print(f"{dia}: {pessoa}")
Saída
seg: Ana
ter: Bia
qua: Caio
qui: Ana
sex: Bia
  • cycle(pessoas) é infinito, mas o zip para no menor iterável (os dias)
  • Desafio: numere os dias com enumerate(..., start=1)

Encerramento · Python Intermediário

Iteradores prontos
para usar

As coleções do Python já entregam iteradores com iter(). enumerate, zip e reversed são iteradores preguiçosos e se esgotam; range e as views do dicionário não. iter(função, sentinela) repete uma chamada até um valor de parada, e o itertools conta, repete e encadeia sem montar listas.

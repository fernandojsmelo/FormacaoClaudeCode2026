Conceito01

O Codex ao lado do código

A extensão coloca o agente do Codex numa barra lateral do editor. A vantagem sobre o app e a web é que o contexto já está aberto: os arquivos, a seleção e os chats recentes entram no prompt sem você precisar explicar tudo de novo.

Contexto

Use o que está aberto

Referencie arquivos abertos, o trecho selecionado e chats recentes direto no composer. O Codex começa pelo código que você já está vendo.

Revisão

Mudanças ao lado do código

Leia o resumo e o diff focado, mantenha só as edições que quiser e peça ajustes no mesmo chat.

Delegação

Quando a tarefa cresce

Itere localmente no que é rápido e mande para a nuvem (Codex web) o que precisa de mais tempo. O resultado volta para o mesmo editor.

Use a extensão quando…

  • Você está fazendo edições focadas e quer os arquivos e o Codex na mesma tela.
  • Você está aprendendo um código desconhecido e quer perguntar sobre os arquivos e símbolos abertos.
  • Você quer revisar mudanças no lugar, aplicando edições junto ao código-fonte.
  • Você quer delegar uma tarefa maior para a nuvem sem sair do editor.
Instalação02

Instalando a extensão

A mesma extensão, openai.chatgpt no Marketplace, funciona no VS Code, VS Code Insiders, Cursor e Windsurf. Xcode e as IDEs JetBrains têm integrações próprias.

1

Instale

Procure por "Codex" na aba de extensões (Ctrl+Shift+X) ou use a linha de comando ao lado.

2

Abra o Codex

Clique no ícone do Codex. Se ele não aparecer, rode Codex: Open Codex Sidebar na Command Palette.

3

Faça login

Entre com a conta do ChatGPT. Com uma chave de API a extensão funciona, mas sem os recursos de nuvem.

4

Primeiro chat

Com o projeto aberto, peça para explicar o código, fazer uma mudança focada ou depurar um problema.

Instalação pelo terminal
code --install-extension openai.chatgpt
Boa prática da documentação: crie checkpoints no Git (commit) antes e depois de cada tarefa. Assim fica fácil reverter o que o agente mudou.
Windows: se os seus repositórios estão no WSL2, ative chatgpt.runCodexInWindowsSubsystemForLinux. O agente passa a rodar no WSL2, com o sandbox do Linux. No Linux, o sandbox precisa do bubblewrap, como vimos na aula 2.
Contexto03

Usando o contexto do editor

O grande diferencial da extensão é passar o código certo para o agente com poucos cliques.

ComoO que faz
Contexto automáticoArquivos abertos e a seleção atual acompanham o prompt. Ligue ou desligue com /ide-context.
chatgpt.addToThreadAdiciona o trecho selecionado como contexto do chat atual.
chatgpt.addFileToThreadAdiciona o arquivo inteiro como contexto do chat atual.
CodeLens em TODOMostra um atalho acima dos comentários TODO para o Codex resolvê-los.
Exemplo de prompt com a seleção ativa
# com a função parse_date() selecionada no editor
Explique o que este trecho faz e por que ele
falha com datas no formato "28/09/2026".
Corrija sem mudar a assinatura da função e
adicione um teste para o caso.
Com a seleção como contexto, você não precisa colar o código nem dizer o caminho do arquivo. Foque o prompt no resultado esperado e em como validar.
Onde roda04

Local, Worktree ou Cloud pelo editor

Os mesmos três lugares de execução do app (aula 2) estão disponíveis na extensão. Você troca com slash commands digitados no composer.

/local

Workspace local

Roda na pasta aberta no editor. É o modo para iteração rápida e prática.

/worktree

Nova worktree Git

Roda numa cópia isolada do repositório, sem mexer nos arquivos que você está editando.

/cloud

Nuvem

Envia o chat para o Codex web, quando a execução em nuvem está disponível. Ideal para tarefas longas.

/cloud-environment

Escolher o environment

Define qual environment da nuvem (aula 1) o chat vai usar.

Permissões

O controle fica abaixo do composer, como no app. O sandbox define até onde o agente vai sozinho, e as aprovações definem quando ele para e pede permissão. O comando /approve aprova uma nova tentativa depois de uma recusa do revisor automático.

A extensão e a CLI usam o mesmo agente e a mesma configuração. Um chat em nuvem iniciado no editor aparece no Codex web e pode ser revisado lá, e vice-versa.
Composer05

Slash commands essenciais

Digite / no composer, filtre (ex.: /status) e pressione Enter. Os principais:

/initGera um AGENTS.md inicial para o projeto
/planLiga ou desliga o modo de planejamento em várias etapas
/goalDefine um objetivo persistente para o Codex perseguir
/reviewCode review das mudanças não commitadas ou em relação a um branch base
/model · /reasoningEscolhe o modelo e o esforço de raciocínio do chat
ComandoPara quê
/statusMostra o ID do chat, o uso de contexto e os limites de uso
/compactCompacta o contexto do chat atual

Paralelo com o Claude Code: o AGENTS.md faz o papel do CLAUDE.md, e o /init e o /compact funcionam de forma parecida nas duas ferramentas.
Revisão06

Revisando o trabalho no editor

Ao terminar, o Codex mostra um resumo e as linhas alteradas ali mesmo, sem painel extra. Você mantém o que quiser e pede ajustes no mesmo chat.

1 · Diff focado

Inspecione

Veja só os arquivos afetados, com a justificativa do agente ao lado do código.

2 · Selecione

Mantenha o que quiser

Aceite as edições que fazem sentido e descarte o resto antes de seguir.

3 · /review

Segunda opinião

Rode o code review nas mudanças não commitadas ou contra um branch base antes de commitar.

Mensagens durante a execução

Por padrão (queue), o que você envia enquanto o Codex trabalha entra na fila para a próxima rodada. No modo steer, a mensagem redireciona a rodada atual. Ctrl/Cmd+Shift+Enter inverte o comportamento só para aquela mensagem.

O /review roda no chat atual quando possível (inline). Para abrir a revisão num chat separado, mude chatgpt.reviewDelivery para detached.
Configuração07

As duas camadas de configuração

A extensão separa o comportamento do agente (compartilhado com a CLI) do comportamento do editor.

Codex settings · config.toml

Modelo, esforço de raciocínio, permissões, sandbox, servidores MCP e personalização. Abra pela engrenagem da barra lateral em Codex Settings → Open config.toml.

# pessoal (vale para CLI e extensão)
~/.codex/config.toml

# por projeto (só em projetos confiáveis)
.codex/config.toml
Ordem de precedência: flags da CLI, depois o .codex/config.toml do projeto e por último o pessoal. Vale a regra mais específica.
Editor settings (chatgpt.*)Padrão
followUpQueueModequeue (ou steer)
composerEnterBehaviorenter envia; opções para exigir Ctrl/Cmd+Enter
reviewDeliveryinline (ou detached)
commentCodeLensEnabledtrue: CodeLens nos TODOs
openOnStartupfalse: foca a barra do Codex ao iniciar
localeOverrideAuto: idioma da interface do Codex
runCodexInWindowsSubsystemForLinuxfalse: só no Windows, para rodar no WSL2

Nas configurações do editor, filtre por @ext:openai.chatgpt.

Produtividade08

Comandos e atalhos de teclado

Todos os comandos da extensão ficam na Command Palette (Ctrl+Shift+P, ou Cmd+Shift+P no macOS), e qualquer um pode ganhar um atalho próprio.

ComandoAtalho padrãoFunção
chatgpt.newChatCtrl+N · Cmd+NNovo chat
chatgpt.openSidebar—Abre a barra lateral
chatgpt.newCodexPanel—Novo painel do Codex
chatgpt.openCommandMenu—Menu de comandos do Codex
chatgpt.addToThread—Seleção → contexto
chatgpt.addFileToThread—Arquivo → contexto
Criar um atalho
  1. Abra a Command Palette.
  2. Rode Preferences: Open Keyboard Shortcuts.
  3. Busque Codex ou o ID (ex.: chatgpt.addToThread).
  4. Clique no lápis e grave a combinação.
Sugestão: dê um atalho ao chatgpt.addToThread. Selecionar código e mandar para o chat vira um gesto só.
Fixação09

Teste rápido

1. Qual é o ID da extensão oficial do Codex no Marketplace do VS Code?

A) openai.codex
B) openai.chatgpt
C) github.copilot
D) openai.codex-cli
B. A extensão é a openai.chatgpt, a mesma no VS Code, Cursor e Windsurf.

2. Você está no meio de uma edição e quer delegar uma tarefa longa sem ocupar a máquina. Qual comando usar?

A) /local
B) /compact
C) /cloud
D) /fork
C. O /cloud envia o chat para o Codex web, usando o environment escolhido com /cloud-environment.

3. Onde ficam o modelo, as permissões e os servidores MCP que a extensão compartilha com a CLI?

A) settings.json do VS Code
B) config.toml
C) AGENTS.md
D) package.json
B. O comportamento do agente fica no config.toml (~/.codex/ ou .codex/ do projeto). As configurações chatgpt.* cuidam só do editor.

4. Com followUpQueueMode no padrão, o que acontece com uma mensagem enviada enquanto o Codex trabalha?

A) Interrompe e descarta a rodada
B) Entra na fila para a próxima rodada
C) É ignorada
D) Abre um novo chat
B. O padrão é queue. Com steer a mensagem redireciona a rodada atual, e Ctrl/Cmd+Shift+Enter inverte o comportamento uma vez.

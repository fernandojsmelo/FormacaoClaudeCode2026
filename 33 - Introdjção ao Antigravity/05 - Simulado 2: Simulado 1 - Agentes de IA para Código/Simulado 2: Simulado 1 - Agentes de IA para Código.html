Qual das seguintes afirmações sobre o uso prático de Agentes de IA para Código é FALSA?
Resposta corretaEles podem sugerir a estrutura de classes e métodos com base em comandos textuais.

Sua resposta está incorretaEles não precisam de acesso ao contexto do código-fonte existente para funcionar corretamente.

Nota do curso · possível erro de gabaritoA pergunta pede a afirmação FALSA. A alternativa marcada como "Resposta correta" (sugerir estrutura de classes e métodos a partir de comandos de texto) é verdadeira. Já a alternativa respondida ("não precisam de acesso ao contexto do código-fonte existente") é a afirmação falsa: agentes como o Claude Code e o Antigravity dependem justamente de ler o projeto para funcionar bem.

Windows03

Instalando no Windows

1 · BaixarAba Windows › Download for x64 (ou ARM64): Antigravity-x64.exe.
2 · ExecutarDois cliques. SmartScreen: Mais informações › Executar assim mesmo.
3 · AceitarContrato de licença e pasta padrão. Avançar.
4 · InstalarAtalho na área de trabalho (opcional) › Instalar. IDE, se quiser.
5 · ConcluirConcluir e abrir pelo menu Iniciar.
Se aparecer "Keep Both" ou "Replace"

A documentação orienta escolher Replace.

No Windows, a segurança é a anterior

O novo sistema de permissões e o sandbox ainda são de macOS e Linux. No Windows, a execução de comandos se configura em Settings (Request Review, Proceed in Sandbox, Always Proceed).

Linux04

Três caminhos no Linux

A · Ubuntu, Debian, Mint

Repositório apt: ícone no menu e atualização com o sistema.

# (depois de cadastrar a # chave e o repositório — # comandos no manual) sudo apt update sudo apt install antigravity
B · Fedora, RHEL, SUSE

Repositório rpm em /etc/yum.repos.d.

# (depois de criar o # antigravity.repo — # comando no manual) sudo dnf makecache sudo dnf install antigravity
C · .tar.gz (qualquer distro)

Versão portátil: não tem instalador, já vem pronta para rodar.

tar -xvzf Antigravity.tar.gz sudo mv Antigravity-x64 \ /opt/antigravity # + ajuste do chrome-sandbox /opt/antigravity/antigravity
Os comandos completos de A, B e C (chave, repositório, permissões do chrome-sandbox e atalho no menu) estão no manual, copiados da página oficial "Download for Linux".
macOS05

Instalando no macOS

1 · BaixarAba macOS › Apple Silicon ou Intel: Antigravity.dmg.
2 · Abrir o .dmgDois cliques no arquivo baixado.
3 · ArrastarO ícone do Antigravity para Aplicativos. "Substituir", se perguntar.
4 · EjetarO disco do instalador, na barra lateral do Finder.
5 · AbrirPor Aplicativos ou Spotlight (⌘+Espaço). Confirme Abrir.
"Desenvolvedor não verificado"? Ajustes do Sistema › Privacidade e Segurança › Abrir Mesmo Assim, só se o arquivo veio do site oficial.
Não rode o app de dentro do .dmg: ele precisa estar em Aplicativos para atualizar sozinho.
Configuração06

Primeiro login e segurança

1
Abra o app e clique para entrar: o navegador abre o login do Google.
2
Escolha a conta pessoal, autorize e volte ao app.
3
Na IDE, se quiser, importe configurações do VS Code ou do Cursor.
4
Em Settings › General, deixe o preset Default.
5
Em Settings › Agent, revisão em Request review.
PresetUse?
DefaultSim. Comandos no sandbox; para sair dele, o agente pede permissão
Request ReviewSe quiser aprovar cada comando
TurboNão, exceto em máquinas descartáveis

O primeiro projeto

1 · PastaCrie projetos/teste-antigravity e rode git init.
2 · ProjetoPasta com + › New Project › Add Folder › Create.
3 · Pedido"Crie um index.html de boas-vindas e abra no navegador."
4 · ModosLocal mode + Planning mode.
5 · RevisarLeia o plano (Artifact), aprove e confira.
Regras do projeto

Crie um AGENTS.md na raiz: idioma, estilo, o que não mexer.

Modelo

Comece com um Gemini Flash; use o Pro em tarefas difíceis.

Navegador

Um perfil separado do Chrome para o agente, longe das suas contas.

Terminal08

O CLI nos três sistemas

LoginComo
LocalUsa o cofre do sistema (Chaveiro, Secret Service, Gerenciador de Credenciais) ou abre o navegador
SSHMostra uma URL; você entra no navegador local e cola o código no terminal
CIChave da API Gemini + modelProvider no settings.json
agy: command not found? A pasta do agy não está no PATH. Correção para cada sistema no manual.
Manutenção09

Atualizar e desinstalar

AtualizarComo
AppAutomático por padrão (opção Update: Mode para manual ou nenhum)
Linux A / Bapt upgrade / dnf upgrade
Linux CNovo .tar.gz em /opt
CLIMesmo script; também se atualiza sozinho
DesinstalarComo
WindowsConfigurações › Aplicativos › Antigravity › Desinstalar
macOSArrastar de Aplicativos para o Lixo
Linuxapt remove / dnf remove / apagar /opt/antigravity
Para "zerar" o Antigravity, apague só as subpastas dele dentro de ~/.gemini (como antigravity e antigravity-cli). Nunca a pasta ~/.gemini inteira: ela guarda regras globais e pode ser usada por outras ferramentas.

Quiz de fixação11

Teste o que ficou

1. Onde descobrir se o seu Windows é x64 ou ARM64?

A) No Painel de Controle de som
B) Configurações › Sistema › Sobre › Tipo de sistema
C) No navegador
D) Não importa
B. E baixe a versão correspondente.

2. No Ubuntu, qual caminho dá atualização automática?

A) O .tar.gz
B) O repositório apt oficial
C) Baixar de um grupo
D) Nenhum
B. Atualiza junto com o sistema.

3. Qual preset de permissões usar no começo?

A) Turbo
B) Default: comandos no sandbox, perguntando para sair dele
C) Nenhum
D) Always Proceed
B. Turbo só em máquinas descartáveis.

4. agy: command not found depois de instalar o CLI. Causa?

A) O CLI não existe
B) A pasta do agy não está no PATH do terminal
C) Falta internet
D) Conta errada
B. Ajuste o PATH e reabra o terminal.

como instalar Antigravity IDE (Standalone)

Para instalar o Google Antigravity IDE (Standalone), acesse o site oficial, baixe o instalador compatível com o seu sistema operacional (Windows, macOS ou Linux) e execute o arquivo seguindo as instruções na tela. Google Antigravity +2

Passo a Passo para Instalação

  • Baixe o instalador: Acesse a página oficial do Google Antigravity Download e escolha a versão desktop autônoma (Standalone) para o seu sistema (ex: Windows x64, Apple Silicon ou Intel para macOS, ou pacote .deb / .tar.gz para Linux).
  • Execute o arquivo: Abra o instalador baixado no seu computador.
  • Aceite os termos: Leia e aceite o contrato de licença e termos de uso.
  • Defina o local: Escolha o diretório de instalação padrão ou personalize se preferir, depois clique em avançar.
  • Conclua a instalação: Selecione tarefas adicionais (como criar atalho na área de trabalho) e clique em Instalar e depois em Concluir. Google Antigravity +6

Configuração Inicial

  • Abra o aplicativo: Inicie o Antigravity IDE após a conclusão.
  • Faça login: Autentique-se com a sua conta Google para ativar os recursos de IA e agentes integrados (como o Gemini).
  • Importe configurações (Opcional): Escolha se deseja iniciar do zero ou importar configurações, extensões e temas de outros editores como o Visual Studio Code ou Cursor. YouTube · Marcio Marq… +3

baixei o arquivo Antigravity IDE.tar.gz amis não encontro o instalador

É perfeitamente normal não encontrar um arquivo executável clássico de instalação (como um .exe ou .deb) dentro do pacote .tar.gz do Google Antigravity IDE.

No Linux, o arquivo .tar.gz disponibilizado pelo Google traz uma versão portátil (portable build em Electron). Isso significa que o próprio programa já está ali dentro, pronto para rodar, sem a necessidade de um assistente de instalação. Reddit · r/google_antigr… +1

Para abrir o IDE e deixá-lo integrado ao seu sistema, siga o passo a passo abaixo pelo terminal:

1. Extraia os arquivos

Abra o terminal na pasta onde você baixou o arquivo (geralmente a pasta Downloads) e execute o comando para extrair:

cd ~/Downloads tar -xvzf Antigravity.tar.gz

(Nota: Substitua Antigravity.tar.gz pelo nome exato do arquivo que você baixou).

2. Mova para a pasta do sistema e execute

A extração vai gerar uma pasta chamada algo como Antigravity-x64. Você pode mover essa pasta para o diretório /opt (onde ficam os softwares adicionais do Linux) e rodar o executável principal: Reddit · r/google_antigr… +1

# Move os arquivos para a pasta do sistema sudo mv Antigravity-x64 /opt/antigravity # Ajusta as permissões do sandbox (necessário por ser baseado em El sudo chown root:root /opt/antigravity/chrome-sandbox sudo chmod 4755 /opt/antigravity/chrome-sandbox # Executa o Antigravity IDE diretamente /opt/antigravity/antigravity

(Caso o nome do executável final mude, liste os arquivos com ls /opt/antigravity para identificar o arquivo executável principal).

Alternativa muito mais simples (Via Repositório Oficial)

Se você usa Ubuntu, Debian, Mint ou derivados, você não precisa sofrer configurando o .tar.gz manualmente. O Google disponibiliza um repositório oficial que cria os ícones no menu e gerencia atualizações automaticamente. Google Antigravity +1

Você pode instalar rodando estes três comandos no terminal: Google Antigravity

# 1. Adiciona a chave e o repositório oficial do Google Antigravity sudo mkdir -p /etc/apt/keyrings curl -fsSL https://us-central1-apt.pkg.dev/doc/repo-signing-key.gpg echo "deb [signed-by=/etc/apt/keyrings/antigravity-repo-key.gpg] ht # 2. Atualiza a lista de pacotes sudo apt update # 3. Instala o programa de forma definitiva sudo apt install antigravity
Nota do curso: no material original, as linhas do curl e do echo aparecem cortadas pela página. Os comandos completos, copiados da página oficial "Download for Linux", estão no Manual de Instalação e Configuração (seção 03, caminho A).

Se preferir manter a versão .tar.gz, me avise se deu tudo certo para rodar o executável ou se você quer ajuda para criar um atalho no menu de aplicativos do seu sistema!

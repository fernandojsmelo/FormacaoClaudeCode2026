Transformação
textual

Transformar é reescrever sem mudar o conteúdo: o mesmo texto em outro formato, outro tom, outro ponto de vista ou para outro público. Nesta aula, com o notebook 11-transformacao_texto.ipynb: um parágrafo que vira receita, uma notícia que vira post, uma frase em primeira pessoa que vai para a terceira e um texto adaptado para empresários, conferindo o que mudou além do pedido.

Os tipos01

Quatro jeitos de reescrever

Formato

Muda a estrutura: parágrafo → lista, receita, tabela, e-mail.

Tom

Muda o estilo: jornalístico → descontraído, formal → informal.

Ponto de vista

Muda quem narra: primeira pessoa → terceira, cliente → empresa.

Público

Muda o leitor: vocabulário e argumentos de quem vai ler.

A regra que vale para todos: os fatos do texto original devem continuar os mesmos. O que muda é a forma.

Conferindo03

A receita ganhou dados

Na receitaNo texto original?
Moer, preparar forte, esfriar, gelo, leite, açúcar/baunilhaSim
2 colheres (sopa) de grãosNão
200 ml de água a 90 °C, 3 a 4 minutosNão
Copo de 300 a 350 ml, 50 a 100 ml de leiteNão
Moagem média-grossa, prensa francesaNão
  • O system pedia "preservação das informações originais"; o modelo preservou, e acrescentou quantidades, tempos e utensílios
  • O formato "receita" tem lacunas típicas (quantidades) e o modelo as preencheu com valores plausíveis
  • Às vezes isso ajuda; num manual técnico ou num documento oficial, é um erro
Se não quer acréscimos, diga: "não acrescente quantidades, tempos ou ingredientes que não estejam no texto; use [a definir] onde faltar".

Múltiplas versões07

Um texto, várias saídas

  • A seção do notebook se chama "Múltiplas Transformações", mas gera só a versão para negócios
  • Com um laço, o mesmo texto vira várias versões, cada uma com o seu público
  • Cada versão é uma chamada à API: 3 públicos = 3 requisições
Mantenha o texto original fora do pedido, entre delimitadores, para o modelo não confundir o que é conteúdo e o que é instrução (aula 06).
Completando a ideia do notebook (não está nele)
publicos = {
    "negócios": "empresários do setor de alimentação",
    "crianças": "crianças de 8 a 10 anos",
    "imprensa": "uma nota oficial para jornalistas",
}
for nome, publico in publicos.items():
    prompt = f"""Reescreva para {publico}.
Não acrescente dados que não estejam no texto.
--- TEXTO ---
{texto_original}
--- FIM ---"""
    r = client.chat.completions.create(
        model="openai/gpt-oss-120b",
        messages=[{"role": "user", "content": prompt}],
    )
    print(f"=== {nome} ===")
    print(r.choices[0].message.content)
Pratique08

Transforme e compare

Exercício: pegue um aviso curto (ex.: "A reunião de segunda foi adiada para quarta às 14h, na sala 3") e transforme em:

  • Tópicos para o Slack
  • E-mail formal para a diretoria
  • Mensagem descontraída para o time
  • Terceira pessoa, como numa ata
Teste de fidelidade: em todas as versões, os fatos são os mesmos? Dia, hora e sala precisam aparecer iguais, e nada novo pode surgir.
Rode com e sem a frase "não acrescente informações" e compare o que surgiu de novo.

Encerramento · Engenharia de Prompts

Muda a forma,
ficam os fatos

Formato, tom, ponto de vista e público são as quatro alavancas da transformação. Diga qual delas mexer, peça para não acrescentar informações e confira a nova versão contra o original, especialmente quando o novo formato tem lacunas que o modelo gosta de preencher.

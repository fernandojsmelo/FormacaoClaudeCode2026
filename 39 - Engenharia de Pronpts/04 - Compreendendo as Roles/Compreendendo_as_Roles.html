Compreendendo
as roles

Toda chamada ao modelo é uma lista de mensagens, e cada mensagem tem um papel (role): system dá as regras, user faz o pedido e assistant guarda o que o modelo já respondeu. Nesta aula, com o notebook 01-roles.ipynb: a mesma pergunta com e sem system, um histórico de conversa montado à mão e um system prompt refinado.

Os papéis02

Uma conversa é uma lista de mensagens

system

Regras de comportamento: persona, tom, formato, limites. Vale para a conversa inteira.

user

O pedido de quem usa: a pergunta, os dados, a tarefa.

assistant

Respostas do modelo. Você as envia de volta para o modelo lembrar o que já disse.

Formato de cada mensagem
messages=[
    {"role": "system", "content": "regras..."},
    {"role": "user", "content": "pergunta..."},
]
  • A ordem importa: o modelo lê a lista de cima para baixo
  • O system costuma vir primeiro e uma vez só
  • Depois, user e assistant se alternam

Saída gravada no notebook
As **LLMs (Large Language Models)** são modelos de inteligência artificial treinados com enormes quantidades de texto para aprender padrões da linguagem humana. Eles usam arquiteturas de redes neurais, geralmente do tipo **Transformer**, que permitem processar e gerar texto de forma coerente e contextualizada. 

- **Escala**: possuem bilhões a trilhões de parâmetros, o que aumenta sua capacidade de capturar nuances linguísticas.  
- **Treinamento**: aprendem de forma não supervisionada, prevendo a próxima palavra em frases de vastos corpora (livros, artigos, sites, etc.).  
- **Uso**: são a base de assistentes de texto, chatbots, tradutores automáticos, resumidores, geradores de código, entre outras aplicações.  

Em resumo, LLMs são “cérebro” de IA que, a partir de muito texto, conseguem entender e produzir linguagem natural de forma impressionante.

As **LLMs (Large Language Models)** são modelos de inteligência artificial baseados em redes neurais muito grandes, treinados com enormes volumes de texto (bilhões de palavras). Esse treinamento permite que eles:

1. **Aprendam padrões linguísticos** – gramática, vocabulário, estilo e relações semânticas.
2. **Entendam contexto** – analisam sequências de palavras para captar o sentido de frases e parágrafos.
3. **Gerem texto** – produzem respostas, resumos, traduções, códigos, entre outros, de forma coerente e fluente.

Em resumo, uma LLM é um modelo de IA que, a partir de vastos dados textuais, consegue compreender e gerar linguagem natural para diversas aplicações.

Respostas de LLM variam a cada execução: compare o estilo, não as palavras.

        }

Início da saída gravada
**Resumo (até 3 linhas)**  
LLMs (Large Language Models) com baixa latência respondem rapidamente, o que melhora a experiência do usuário, permite decisões em tempo real e reduz custos operacionais. Em ambientes críticos, como atendimento ao cliente ou sistemas de controle, a rapidez é tão importante quanto a precisão.

  • Pediu "resumo em até 3 linhas" primeiro: a resposta abre com Resumo (até 3 linhas)

A resposta07

De onde sai o texto da resposta

O caminho até o texto
chat_completion.choices[0].message.content
choiceslista de respostas
[0]a primeira (e única)
message.contento texto
  • choices é uma lista porque o formato da API permite pedir várias respostas
  • No Groq, só n=1 é aceito: sempre há uma resposta, a de índice 0
  • message.role vem como "assistant": é essa mensagem que você guardaria no histórico
  • O texto chega em Markdown (**negrito**, tabelas com |); o print mostra as marcas cruas
Pratique08

Monte o seu tutor

Exercício: numa célula nova, crie um tutor de Python para iniciantes. O system deve exigir respostas curtas, um exemplo de código e uma pergunta no final para checar o entendimento.

Ponto de partida
resp = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[
        {"role": "system", "content": "..."},
        {"role": "user", "content": "O que é uma lista?"},
    ],
)
print(resp.choices[0].message.content)
  • Rode duas vezes e veja se as três regras foram cumpridas
  • Depois acrescente a resposta como assistant e uma nova pergunta do user ("E uma tupla?")
  • Teste tirar o system: o que muda?
Cada execução consome cota do plano gratuito (aula 01). Prefira poucas execuções bem pensadas.

Quem fala o quê
na conversa

O system define as regras, o user faz o pedido e o assistant guarda as respostas anteriores. A API não tem memória: o histórico é a própria lista messages. Um system com instruções concretas muda a forma da resposta de um jeito que dá para conferir.

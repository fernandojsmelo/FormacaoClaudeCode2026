A chave da API do Groq

  1. Acesse console.groq.com e entre na sua conta (ou crie uma).
  2. Abra API Keys em console.groq.com/keys.
  3. Clique em Create API Key, dê um nome (ex.: curso-prompts) e copie a chave.
  4. Guarde a chave: ela vai para o arquivo .env.
A chave funciona como uma senha. Não a cole em código, prints ou repositórios. Se vazar, apague-a no console e crie outra.

Arquivos de apoio

  • requirements.txt: na pasta Eng_prompt/ da aula 01 (contém python-dotenv, jupyterlab e groq).
  • teste_groq.py, .env.exemplo e .gitignore.exemplo: em exemplos/ desta aula.
As versões atuais de groq (1.7.0), jupyterlab (4.6.4) e python-dotenv (1.2.4) exigem Python 3.10 ou mais novo.

WindowsPython Install Manager, comando py e PowerShell

02Windows · passo a passo

Passo 1 · Instalar o Python

Desde o Python 3.14, a forma recomendada no Windows é o Python Install Manager, baixado em python.org/downloads ou na Microsoft Store. Ele instala a versão mais recente e disponibiliza os comandos python e py em qualquer terminal. Depois de instalar, abra um PowerShell novo e confira:

python --version
# Python 3.10 ou mais novo
py list          # versões instaladas
O instalador "completo" antigo (com a opção Add python.exe to PATH) ficou obsoleto no 3.14 e não será mais produzido a partir do 3.16. Se você já tem um Python 3.10+ instalado por ele, pode continuar usando.

Passo 2 · Pasta e ambiente virtual

mkdir $HOME\Eng_prompt
cd $HOME\Eng_prompt
py -m venv .venv
.venv\Scripts\Activate.ps1

Se aparecer um erro dizendo que a execução de scripts está desabilitada, libere-a para o seu usuário (uma vez só) e ative de novo:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.venv\Scripts\Activate.ps1

No Prompt de Comando (cmd), o comando de ativação é .venv\Scripts\activate.bat.

Passo 3 · Bibliotecas

Copie o requirements.txt da aula 01 para a pasta e instale:

pip install -r requirements.txt

Passo 4 · Arquivos .env e .gitignore

Crie o .env pelo PowerShell (troque o texto pela sua chave) e copie o .gitignore de exemplo:

Set-Content -Path .env -Value "GROQ_API=cole_aqui_a_sua_chave"
Copy-Item caminho\para\exemplos\.gitignore.exemplo .gitignore
Se criar o arquivo pelo Bloco de Notas, escolha Todos os arquivos (*.*) ao salvar. Senão, ele vira .env.txt, e o load_dotenv() não o encontra. No Explorador, ative Exibir › Extensões de nomes de arquivos para conferir.

Passo 5 · Teste e JupyterLab

python teste_groq.py
# Chave carregada? sim  +  uma saudação do modelo
jupyter lab
  • (.venv) aparece no início da linha do PowerShell
  • O teste mostrou a resposta do modelo
  • O JupyterLab abriu no navegador mostrando a pasta Eng_prompt

LinuxPython do sistema + pacote python3-venv (Debian/Ubuntu)

03Linux · passo a passo

Passo 1 · Python e venv

A maioria das distribuições já traz o Python 3. No Debian e no Ubuntu, o módulo de ambientes virtuais vem num pacote separado:

python3 --version
sudo apt update
sudo apt install python3-venv python3-pip

No Fedora, o venv já vem com o Python: sudo dnf install python3.

Passo 2 · Pasta e ambiente virtual

mkdir ~/Eng_prompt && cd ~/Eng_prompt
python3 -m venv .venv
source .venv/bin/activate
Se o python3 -m venv reclamar que ensurepip is not available, falta o pacote python3-venv (passo 1). Instale-o, apague a pasta .venv incompleta e crie de novo.

Passo 3 · Bibliotecas

cp caminho/para/Eng_prompt/requirements.txt .
pip install -r requirements.txt

Passo 4 · Arquivos .env e .gitignore

Abra um editor de texto e salve o .env com a linha GROQ_API=sua_chave:

nano .env          # cole GROQ_API=..., salve com Ctrl+O e saia com Ctrl+X
cp caminho/para/exemplos/.gitignore.exemplo .gitignore
Prefira o editor a echo "GROQ_API=..." > .env: o echo deixa a chave gravada no histórico do terminal. Arquivos que começam com ponto ficam ocultos; use ls -a para vê-los.

Passo 5 · Teste e JupyterLab

python teste_groq.py
jupyter lab

  • O teste mostrou a resposta do modelo

05Problemas comuns e checklist

"python" não é reconhecido

Windows: os comandos não foram configurados. Rode py install --configure (Python Install Manager) e abra um terminal novo.

Activate.ps1 bloqueado

Política de execução do PowerShell. Rode Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser.

ensurepip is not available

Linux sem python3-venv. Instale o pacote e recrie o .venv.

No module named 'groq'

O venv não está ativado, ou o pip install rodou fora dele. Ative e instale de novo.

groq.GroqError: The api_key client option must be set…

A chave não foi lida: falta o .env, ele está em outra pasta, virou .env.txt ou a variável não se chama GROQ_API.

Error code: 401 · Invalid API Key

Chave copiada pela metade, com espaço ou apagada no console. Copie de novo ou crie outra.

Error code: 429

Limite do plano (requisições ou tokens por minuto/dia). Espere os segundos de retry-after.

jupyter: command not found

O JupyterLab foi instalado no venv, mas ele não está ativado neste terminal.

Checklist final

  • Python 3.10 ou mais novo
  • Chave criada em console.groq.com/keys
  • Pasta Eng_prompt com o .venv criado e ativado
  • pip install -r requirements.txt sem erros
  • .env com GROQ_API=… e .gitignore ignorando .env e .venv/
  • python teste_groq.py mostrou Chave carregada? sim e a resposta do modelo
  • jupyter lab abriu no navegador

Ajuste 4 · P306

Modo escuro

Print real · v2 em modo escuro, 1280px
Ajuste 4 — modo escuro. Siga o tema do sistema (prefers-color-scheme) e adicione um botão ☀/☾ no cabeçalho que alterna e lembra a escolha (localStorage). Só troque as variáveis CSS; não duplique regras.
Print real · modo escuro em 390px
O review pegou um problema: no escuro, o texto branco sobre o roxo claro do botão ficou em 3,17:1. A correção foi uma variável nova, --on-brand (texto escuro no tema escuro), que subiu para 5,92:1.
Ajuste 5 · P307

Formulário com validação

Ajuste 5 — formulário e SEO. Troque o botão da CTA final por um formulário de e-mail (campo + botão). Valide com JavaScript sem bibliotecas, mostre a mensagem de erro/sucesso num aria-live e marque aria-invalid no campo. Crie script.js e adicione a meta description que o review pediu.
script.js da v2 (trecho real)
const padraoEmail = /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/;

form.addEventListener('submit', (evento) => {
  evento.preventDefault();
  const email = campoEmail.value.trim();
  if (!padraoEmail.test(email)) {
    mensagem.textContent =
      'Digite um e-mail válido, como nome@exemplo.com.';
    campoEmail.setAttribute('aria-invalid', 'true');
    campoEmail.focus();
    return;
  }
  // … mensagem de sucesso e reset do formulário
});
Print real · e-mail inválido: mensagem de erro e borda no campo
O aria-live="polite" faz os leitores de tela anunciarem a mensagem sem roubar o foco. O <label class="sr-only"> dá nome ao campo sem aparecer na tela.

Fixação11

Teste rápido

1. Por que fazer os cinco ajustes em prompts e commits separados?

A) Porque o Codex não aceita prompts longos
B) Para revisar e desfazer cada mudança isoladamente
C) Para gastar menos tokens
D) Porque é obrigatório
B. Ciclos pequenos são fáceis de revisar, e um commit por ajuste permite reverter só o que deu errado.

2. Como voltar à sessão da aula 3 com todo o contexto?

A) codex exec resume
B) /new
C) codex resume (e escolher a sessão nomeada)
D) codex fork --all
C. O codex resume abre o seletor, e o nome dado com /rename facilita encontrar a sessão.

3. Por que a seção de preços já nasceu responsiva sem ninguém pedir no prompt?

A) Sorte
B) O ajuste 1 atualizou o AGENTS.md com a regra mobile first
C) O Codex sempre faz assim
D) Por causa do /compact
B. Regras no AGENTS.md valem para todas as rodadas seguintes: o erro corrigido virou padrão do projeto.

4. No modo escuro, o texto do botão ficou em 3,17:1. Qual foi a correção?

A) Remover o modo escuro
B) Uma variável --on-brand com texto escuro no tema escuro
C) Aumentar a fonte
D) Usar !important
B. Com a variável --on-brand, cada tema define a cor de texto sobre a marca, e o contraste subiu para 5,92:1.

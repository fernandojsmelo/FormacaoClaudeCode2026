IA tradicional (preditiva)

Classifica ou prevê: este e-mail é spam? Este cliente vai cancelar? A saída é um rótulo ou um número.

IA generativa

Produz algo novo a partir de uma instrução: um texto, um resumo, um código, uma imagem. A saída é conteúdo.

Cada círculo está dentro do anterior. Todo modelo de IA generativa de hoje usa deep learning, mas nem todo deep learning gera conteúdo.
Modelos02

LLM e modelo de fundação

  • LLM (Large Language Model, modelo de linguagem de grande porte): modelo com muitos parâmetros, treinado em grande volume de texto, que consegue resumir, responder, traduzir e escrever código (definição do glossário da Anthropic)
  • Parâmetros: os números ajustados no treino; é neles que o "conhecimento" do modelo fica guardado. Um modelo "de 120 bilhões de parâmetros" tem 120 bilhões desses números
  • Modelo de fundação: um modelo treinado de forma ampla, que serve de base para muitas tarefas, em vez de uma tarefa só

Token03

O modelo não lê palavras, lê tokens

tokens.py
# pip install tiktoken
import tiktoken

enc = tiktoken.get_encoding("cl100k_base")

frases = [
    "The cat sat on the mat.",
    "O gato sentou no tapete.",
    "Inteligência artificial generativa",
    "anticonstitucionalissimamente",
]
for f in frases:
    ids = enc.encode(f)
    pedacos = [enc.decode([i]) for i in ids]
    print(f"{len(f):>3} caracteres -> {len(ids):>2} tokens")
    print("   ", pedacos)

 24 caracteres ->  9 tokens
    ['O', ' g', 'ato', ' sent', 'ou', ' no', ' tap', 'ete', '.']
 34 caracteres ->  6 tokens
    ['Int', 'elig', 'ência', ' artificial', ' gener', 'ativa']
 29 caracteres ->  8 tokens
    ['ant', 'icon', 'stit', 'uc', 'ional', 'iss', 'im', 'amente']
  • Token é o menor pedaço que o modelo processa: palavra, parte de palavra, caractere ou byte
  • A frase em português usou 9 tokens contra 7 da equivalente em inglês, neste tokenizador (cl100k_base)
  • Para o Claude, um token vale cerca de 3,5 caracteres em inglês; varia com o idioma (glossário da Anthropic)
Contexto04

Janela de contexto: a memória de trabalho

  • É o quanto de texto o modelo consegue "ter diante de si" ao responder: prompt, histórico, documentos colados e a resposta
  • Não é a base de treino: é uma memória de trabalho, que se esvazia quando a conversa acaba (glossário da Anthropic)
  • A soma de entrada e saída precisa caber na janela (documentação do Groq)
Contexto grande não é de graça: mais tokens enviados significam mais custo e mais tempo por chamada.

Como pedir05

Prompt, system prompt e temperatura

Prompt

A instrução enviada ao modelo, mais o contexto e os exemplos que a acompanham. Escrever bem o prompt é a engenharia de prompt (módulo 39).

System prompt

As regras permanentes da conversa: papel, tom, limites. Fica separado da pergunta do usuário e vale para todas as respostas.

Temperatura

Controla a aleatoriedade: baixa deixa as respostas conservadoras; alta, mais variadas (glossário da Anthropic). No Groq vai de 0 a 2.

Inferência é o nome do ato de usar o modelo já treinado para responder a um prompt. Cada chamada à API é uma inferência (aula 04).
Treinar e adaptar06

Pré-treino, fine-tuning e alinhamento

1

Pré-treino (pretraining)

O modelo aprende a prever a próxima palavra em um corpus enorme de texto. Sozinho, ainda não é bom em seguir instruções (glossário da Anthropic).

2

Fine-tuning

Treino adicional com dados específicos, para o modelo imitar os padrões desse conjunto: um estilo, um formato, um domínio.

3

Alinhamento com feedback humano

Pessoas avaliam respostas e o modelo é ajustado para seguir melhor a intenção do usuário. No estudo do InstructGPT, as respostas de um modelo de 1,3 bilhão de parâmetros foram preferidas às do GPT-3 de 175 bilhões.

Fonte do 3º passo: Ouyang et al., "Training language models to follow instructions with human feedback" (arXiv:2203.02155).

Busca e conhecimento07

Embedding, busca semântica e RAG

  • Embedding: representação de um texto como uma lista de números que codifica o sentido; textos parecidos ficam próximos
  • Busca semântica: achar trechos pelo significado, não só por palavras iguais
  • RAG (retrieval augmented generation): combinar busca de informação com geração, passando os trechos achados na janela de contexto para que a resposta se apoie em evidência (glossário da Anthropic)

O risco central08

Alucinação: plausível, mas falso

  • Alucinação é quando o modelo produz uma afirmação fluente e convincente que não corresponde à realidade: um número, uma citação, um fato
  • O modelo foi treinado para gerar texto plausível, não para consultar uma base de fatos: por isso o erro aparece com a mesma confiança do acerto
  • Reduz com: dar o material (RAG), pedir "use apenas o texto fornecido", temperatura baixa e verificação
Já vimos isso no módulo 39. Num resumo, o modelo escreveu "reclamações ↑ 15%" sem esse número existir no relatório; numa expansão, atribuiu um teste a 2022 que foi divulgado em 2019.
Regra de empresa: tudo que o modelo afirma e que importa para uma decisão tem fonte ou passa por conferência humana.
Ir além do texto09

Ferramenta, agente e multimodal

Ferramenta (tool)

Uma função que o modelo pode pedir para executar: buscar um pedido, consultar um banco, enviar um e-mail. O modelo decide qual e com quais argumentos.

Agente

Sistema em que o LLM usa ferramentas em laço, com base no que observa do ambiente, até concluir a tarefa (definição da Anthropic; aula 10).

Multimodal

Modelo que entende ou gera mais de um tipo de dado: texto, imagem, áudio, vídeo. Ex.: transcrever áudio ou descrever uma foto.

Latência é o tempo entre enviar o prompt e receber a resposta; custo é cobrado por tokens de entrada e de saída. Os dois pesam em qualquer projeto (aulas 02 e 04).

Teste o que ficou

B) Entrada e saída juntas

D) O número de usuários
B.

A) Treinar um modelo do zero
B) Entregar ao modelo trechos relevantes para ele responder
C) Aumentar a temperatura
D) Trocar de idioma

B) Embedding
C) Alucinação

Encerramento · Fundamentos da IA Generativa

A mesma língua,
antes de decidir

IA generativa cria conteúdo; LLMs fazem isso com tokens, dentro de uma janela de contexto limitada; o prompt e a temperatura guiam a resposta; RAG e ferramentas ligam o modelo a dados e ações; e a alucinação é o risco que obriga a conferir. Com esse vocabulário, o resto do módulo fica mais fácil.

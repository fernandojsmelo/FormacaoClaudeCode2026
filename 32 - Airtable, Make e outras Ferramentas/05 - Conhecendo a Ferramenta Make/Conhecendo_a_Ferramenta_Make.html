Passo 101

Conta e organização

1

Crie a conta

Em make.com, com e-mail ou conta Google. A conta Free não pede cartão.

2

Escolha o data center

EUA (US) ou União Europeia (EU). É onde os dados da organização serão guardados e processados.

3

Dê nome à organização

"Formação Claude Code 2026". Plano, cobrança e créditos são por organização.

4

Crie uma equipe

Dentro da organização, equipes (teams) separam cenários e pessoas: "FAQ da Formação".

A região não muda depois. Segundo a central de ajuda, o data center não pode ser trocado depois que a organização é criada. Para mudar, só criando outra organização e refazendo os cenários.
Qual escolher?

A recomendação oficial é o data center mais próximo, pela latência. Do Brasil, os EUA costumam responder mais rápido. Se a sua política de dados exige a Europa, escolha EU.

A região não indica onde você ou seus usuários estão, e sim onde ficam os dados que passam pelos cenários. Isso entra na avaliação de LGPD.

Painel03

De olho no consumo

Créditos do mês

Quanto dos 1.000 do Free já foi usado. Renova a cada ciclo do plano.

Cenários ativos

No Free, no máximo 2 ligados ao mesmo tempo. Cenários desligados não contam.

Execuções incompletas

Execuções que falharam e ficaram guardadas para resolver (página 11).

Próxima execução

O painel mostra quanto falta para a próxima execução agendada.

Organize os cenários em pastas por projeto e use nomes com prefixo: "FAQ · Responder perguntas", "Teste · Primeira automação". Com dois cenários ativos no Free, saber qual está ligado faz diferença.
Limites gerais da central de ajuda: cada equipe pode criar até 100 cenários por dia, e cada cenário tem tamanho máximo de 2 MB. Para um curso, sobra; para geradores automáticos de cenário, importa.

Botão direito no módulo

Renomear, clonar, apagar, adicionar um error handler, desligar temporariamente e escolher Run this module only, ótimo para testar uma parte.

Salvar

Salve com frequência (Ctrl+S). O histórico do cenário registra edições e mudanças de agenda.

Dá para copiar módulos de um cenário e colar em outro, com a configuração junto. Só confira se a conexão existe no destino.

O que é a conexão

Uma autorização guardada no Make e reutilizável por todos os módulos daquele aplicativo. Fica no menu Connections, onde dá para testar, reautorizar ou apagar.

A conexão vale para todos os cenários da equipe. Quem edita cenários pode usá-la. Por isso o token tem só a base FAQ e os escopos mínimos.
Alguns aplicativos (Google, Microsoft) usam OAuth: você é levado à tela de login do serviço e aprova as permissões. Leia o que está aprovando.
Mapeamento06

Levar dados de um módulo ao outro

Ao clicar num campo de um módulo, abre o painel de mapeamento com os dados dos módulos anteriores. Arraste (ou clique) um item para usá-lo. A central de ajuda resume: mapear é dizer ao Make que informação pegar de um app e para onde mandar.

Tipo de dadoExemplo
Texto, número, data, booleanoPergunta, Revisada
Coleção (collection)"Caixa" com vários campos: a resposta do formulário
ArrayLista de itens: as aulas vinculadas
Só aparece o que já rodou

O painel mostra os campos com mais detalhe depois que o módulo anterior rodou ao menos uma vez. Rode o gatilho com um dado de exemplo antes de mapear o resto.

O número do módulo

Cada item mapeado leva o número do módulo de origem, como 2. Pergunta. Mudou a ordem dos módulos? Confira os mapeamentos.

Array mapeado onde se espera um texto vira confusão. Para tratar cada item de uma lista, use um Iterator; para juntar vários num texto, um Aggregator.
Mapeamento07

Funções no meio do caminho

// Data em formato brasileiro {{formatDate(now; "DD/MM/YYYY HH:mm")}} // Valor padrão se o campo vier vazio {{ifempty(1.Categoria; "Sem categoria")}} // Limpar espaços e padronizar para busca {{lower(trim(1.Pergunta))}} // Decisão simples {{if(2.Revisada; "Aprovada"; "Pendente")}} // Primeiros 200 caracteres da resposta {{substring(2.Resposta; 0; 200)}}
Onde ficam

No painel de mapeamento, as abas de funções agrupam texto, números, datas, arrays e funções gerais (como if e ifempty).

Ponto e vírgula

No Make, os argumentos das funções são separados por ponto e vírgula, e não por vírgula.

Funções resolvem pequenas transformações sem módulo extra. Menos módulos, menos créditos.
Testar08

Run once e o inspetor

Bolhas com o número de operações e o inspetor de saída · reprodução ilustrativa
  • Run once executa agora, uma vez, mesmo com o cenário desligado
  • A bolha em cada módulo mostra quantas operações ele fez
  • Clique na bolha: Input, Output e logs de cada operação
  • Erros aparecem em vermelho, com a mensagem do serviço
Na imagem: 1 checagem + 2 linhas + 2 e-mails = 5 créditos. É a conta da aula 04 na prática.
Run once é de verdade: os e-mails são enviados e os registros criados. Teste com seus próprios dados e endereços.
Histórico09

O que aconteceu, registro por registro

Na aba History do cenário, cada execução tem uma linha. Segundo a central de ajuda, ela mostra:

  • Data, hora e tipo de gatilho
  • Status: Success, Warning ou Error
  • Duração, operações e créditos consumidos
  • Tamanho dos dados transferidos
  • As mudanças feitas no cenário (edições, agenda, ativação)
Details

Abre a execução e mostra os bundles de cada módulo. É onde você descobre por que um e-mail saiu com o campo vazio.

Replay

Reexecuta uma execução passada com os mesmos dados de entrada, útil depois de corrigir um erro.

O histórico fica guardado por um número de dias que depende do plano. E ele contém os dados que passaram, inclusive pessoais (página 11).
Agendamento10

Quando o cenário roda

OpçãoUso típico
At regular intervalsA cada N minutos (no Free, no mínimo 15)
OnceUma única vez, numa data e hora
Daily / WeekdaysTodo dia, ou de segunda a sexta, em horários definidos
Weekly / MonthlyRelatórios e lembretes
Specified datesDatas específicas
On demandSó quando chamado: Run once ou API
ImmediatelySó para gatilhos instantâneos (webhooks)
Agenda × ativação

Definir a agenda não liga o cenário: é preciso ativar a chave (ON). Desligado, ele só roda com Run once.

Vários horários por dia

A opção diária aceita vários horários na mesma configuração: 08:00, 13:00 e 18:00, por exemplo.

O padrão do Make é a cada 15 minutos. Para a FAQ, o gatilho instantâneo (Immediately) responde mais rápido e não gasta créditos com checagens vazias.
Configurações11

As configurações do cenário

Opção (engrenagem)O que fazNa FAQ da Formação
Process data in orderProcessa na ordem de chegada; cada execução termina antes da próxima. Também vale para webhooks, que por padrão rodam em paraleloLigar se a ordem das perguntas importar
Keep data confidentialO Make não guarda os dados das execuções nos logs; fica só o registro de que rodouLigar quando estiver estável, por causa dos dados de alunos
Store incomplete executionsGuarda execuções que falharam para você corrigir e retomarLigar: nenhuma pergunta se perde se a IA falhar
Com Keep data confidential ligado, a central de ajuda avisa que as opções para resolver erros ficam muito limitadas. Desenvolva com ele desligado, usando dados de teste, e ligue antes de usar com dados reais.
Com Process data in order e uma execução incompleta pendente, novas execuções ficam paradas até a pendência ser resolvida.
Recursos12

Webhooks, data stores e estruturas

Webhooks

Cada webhook tem um endereço único. A lista mostra os webhooks da equipe, a fila de dados recebidos e o cenário que usa cada um.

Data stores

Tabelas simples do próprio Make para guardar dados entre execuções: o último ID processado, um contador, uma lista de bloqueio.

Data structures

Definem o formato de dados (campos e tipos) para webhooks, JSON e data stores, para o Make entender o que chega.

Data store não substitui o Airtable: não tem views, formulários nem colaboração. Use para controles internos do cenário.
Nas aulas 07 a 10, o webhook da FAQ terá uma estrutura com pergunta e email. Definir a estrutura antes evita bundles bagunçados.
Atalhos13

Templates e assistentes

Templates

Cenários prontos ("salvar respostas de formulário no Airtable", "avisar por e-mail…"). Você copia, cria as conexões e ajusta os mapeamentos.

Maia by Make

Assistente de IA que ajuda a montar cenários a partir de uma descrição em linguagem natural.

A mesma lição dos templates do Agent Builder (módulo 31): o template mostra a arquitetura. Leia cada módulo, rode com Run once e só depois ative.
Cenário criado por template ou por IA também consome créditos e pode enviar e-mails de verdade. Revise filtros e destinatários antes do primeiro Run once.
Armadilhas14

Erros comuns na ferramenta

Escolher a região sem pensar. Não dá para mudar depois.
Achar que Run once é simulação. Envia, cria e apaga de verdade.
Agendar e esquecer de ativar (ou o contrário). Confira a chave ON/OFF.
Mapear antes de rodar o gatilho. O painel fica sem os campos detalhados.
Vírgula nas funções. O Make separa argumentos com ponto e vírgula.
Logs com dados reais para sempre. Ligue Keep data confidential quando o cenário estiver estável.
